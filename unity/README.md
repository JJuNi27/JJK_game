# Unity 전투 MVP

이 폴더는 Python/Pygame 장인 연습장에서 검증한 입력 규칙을 실제 전투로 옮기기 위한 Unity 코드입니다.

저장소에서는 `Assets/`, `Packages/`, `ProjectSettings/`를 관리합니다. Unity가 자동 생성하는 `Library`, `Temp`, `Logs`, `UserSettings` 등은 Git에 올리지 않습니다.

## 권장 에디터

- Unity 6.3 LTS (`6000.3.20f1` 또는 최신 6.3 패치)
- 템플릿: Universal 3D (URP)
- 첫 MVP는 외부 에셋과 별도 서드파티 패키지 없이 진행

이 프로젝트는 최신 기능보다 예측 가능한 환경과 긴 지원 기간을 우선하므로 Unity 6.3 LTS 계열에 고정합니다.

## 최초 프로젝트 준비

1. Unity Hub에서 Unity 6.3 LTS의 `Universal 3D` 프로젝트를 임시 위치에 생성합니다.
2. 최초 가져오기와 인덱싱이 끝난 뒤 에디터를 닫습니다.
3. 임시 프로젝트의 `Assets/`, `Packages/`, `ProjectSettings/`를 저장소의 `unity/` 안으로 병합합니다.
4. `Library/`, `Temp/`, `Logs`, `UserSettings`는 복사하지 않습니다.
5. Unity Hub에서 저장소의 `unity/` 폴더를 프로젝트로 추가해 엽니다.
6. Console에 빨간 오류가 없으면 아래 메뉴로 MVP 장면을 생성할 수 있습니다.

```text
Tools
→ JJK Game
→ Build Combat MVP Scene
```

현재 진행 중인 장면은 대부분 런타임 자동 확장을 사용하므로 매 변경마다 장면을 다시 만들 필요는 없습니다.

## 현재 장면 구조

```text
ArenaGround
GojoPlayer
├─ CharacterController
├─ Health
├─ ThirdPersonPlayerController
├─ BasicAttack
├─ GojoDomainController
├─ TargetLockController (런타임 자동 추가)
├─ GojoTechniqueController (런타임 자동 추가)
├─ GojoTechniqueChainController (런타임 자동 추가)
└─ AttackOrigin

CurseBot A
CurseBot B (런타임 자동 복제)

Main Camera
└─ SimpleCameraFollow

Directional Light
MatchController
```

기존 장면의 바닥은 재생 시 약 `65 × 65` 크기로 확장되고 가장자리에 낮은 프로토타입 안전벽이 생성됩니다.

## 공통 조작 체계

```text
WASD: 이동
SPACE: 짧은 무적 시간이 있는 회피
좌클릭 연속 입력: 1타 → 2타 → 3타 공격 연계
TAB: 가까운 주령 락온 → 다음 주령 전환 → 마지막 뒤 해제
Q: 스킬 1 — 고죠 술식순전 「창」
E: 스킬 2 — 고죠 술식반전 「혁」
R: 상위기/필살기 — 고죠 허식 「자」
V: 영역전개 준비
우클릭 유지 → 좌클릭 → 초록 타이밍에서 우클릭 해제: 무량공처
X: 진행 중인 영역 입력 취소
ENTER: 승패 결정 뒤 장면 재시작
```

키 정의는 `Assets/Scripts/Core/CombatInputBindings.cs` 한곳에서 관리합니다. 원작 조건과 게임용 각색은 저장소 루트의 `docs/CANON_SKILL_RULES.md`를 기준으로 구분합니다.

## 타깃 고정과 조준

- TAB을 누르면 최대 약 42m 안의 가장 가까운 살아 있는 적을 고정합니다.
- 적 발밑의 황금색 회전 링과 화면 오른쪽 문구로 현재 락온 대상을 표시합니다.
- 적이 죽거나 락온 거리 밖으로 나가면 자동으로 해제됩니다.
- 대상이 여러 명이면 거리순으로 다음 대상을 선택한 뒤 마지막에서 해제됩니다.
- 기본 공격 입력 시 고죠가 락온 대상을 먼저 바라봅니다.
- 창, 혁, 허식 「자」는 락온 대상이 있으면 그 방향 또는 대상 주변을 우선 사용합니다.
- 카메라는 멀미 방지를 위해 안정적인 월드 좌표 추적을 유지합니다.

## 공격 연계와 적중 콤보

- `ATTACK CHAIN`은 공격 동작 순서입니다. 허공을 공격해도 1타 → 2타 → 3타로 진행합니다.
- `HIT COMBO`는 실제 적중한 공격 횟수입니다. 공격이 빗나가거나 일정 시간이 지나면 초기화됩니다.
- 3타는 공격 연계 마무리라 피해, 경직, 넉백이 가장 큽니다.

## 술식 프로토타입

### Q · 술식순전 「창」

- 락온 대상이 있으면 대상보다 조금 고죠 쪽에 수렴점을 생성합니다.
- 락온 대상이 없으면 고죠 정면 약 10m 지점에 수렴점을 생성합니다.
- 수렴점 주변 약 4.5m 안의 주령에게 8 피해와 짧은 경직을 주고 수렴점 방향으로 끌어당깁니다.
- 청색 효과도 고죠 몸이 아니라 실제 수렴점 위치에서 나타납니다.
- 기본 재사용 대기시간은 3.2초입니다.

### E · 술식반전 「혁」

- 락온 대상이 있으면 그 방향, 없으면 고죠 정면으로 전방형 반발 판정을 발사합니다.
- 약 11m 길이와 2.3m 반경의 전방 경로 안에 있는 주령에게 18 피해와 경직을 줍니다.
- 적은 고죠의 발사 방향으로 강하게 밀려납니다.
- 적색 효과는 고죠 앞에서 전방을 향하는 형태로 나타납니다.
- 기본 재사용 대기시간은 4.5초입니다.

창과 혁의 방향성, 피해량, 범위, 쿨타임은 아직 `GAME_ORIGINAL` 프로토타입 수치지만, 두 기술을 같은 고죠 중심 원형 판정으로 재사용하지 않도록 분리했습니다.

### 창 → 혁 술식 연계

- 창에 적중한 주령은 약 2.2초 동안 `BLUE MARK` 상태가 됩니다.
- 같은 주령에게 제한시간 안에 혁을 적중시키면 추가 12 피해와 강화된 밀어내기가 적용됩니다.
- 이 적중 연계는 허식 「자」의 원작 발동 조건과 무관한 별도 게임용 보너스입니다.

### R · 허식 「자」

- 창과 혁을 상대에게 먼저 적중시킬 필요는 없습니다.
- Q와 E를 각각 사용하면 적중 여부와 상관없이 준비 상태가 생깁니다.
- 두 준비 상태가 약 8초 안에 함께 존재하면 R로 허식 「자」를 발동합니다.
- 락온 대상이 있으면 해당 방향을 우선하고, 없으면 가장 가까운 살아 있는 주령을 자동 조준합니다.
- 약 18m 길이, 2.2m 반경의 판정으로 55 피해와 강한 넉백을 적용합니다.
- 발동 후 준비 상태를 소비하고 기본 10초 쿨타임이 적용됩니다.
- 보라색 직선 빔은 기능 검증용 임시 VFX입니다.

## 다중 주령 전투

- 주령 두 마리를 동시에 생성합니다.
- 화면 오른쪽에 각 주령 체력바를 따로 표시합니다.
- 중앙 상단의 `CURSES LEFT`가 생존 주령 수를 표시합니다.
- TAB을 반복하면 거리순으로 주령을 전환한 뒤 락온을 해제합니다.
- 한 마리를 처치해도 전투가 끝나지 않고 모든 주령을 처치해야 승리합니다.
- 두 주령이 동시에 공격 준비 중이면 `DODGE! × 2`처럼 공격 수를 표시합니다.

이 다중 적 판정은 이후 스쿠나 화염의 영역 밖 1대1 제한과 영역 안 광역 전환을 구현하는 기반으로 사용합니다.

## 영역전개

- V로 영역전개 입력을 시작합니다.
- 입력 중에는 Q, E, R 술식을 사용할 수 없습니다.
- X로 진행 중인 입력을 취소할 수 있습니다.
- 무량공처가 성공하면 범위 안의 모든 `IDomainStunnable` 대상이 약 3초 동안 행동 불능 상태가 됩니다.

## 맵과 낙사 안전장치

- 기존 약 `30 × 30` 바닥을 재생 시 약 `65 × 65`로 확장합니다.
- 가장자리에 낮은 안전벽을 만들어 일반적인 혁·허식 자 넉백으로 즉시 떨어지는 상황을 줄입니다.
- 플레이어나 주령이 기본 `Y=-12` 아래로 내려가면 즉시 사망하는 최종 안전장치는 유지합니다.

## 현재 성공 기준

- 이동, 회피, 기본 공격 3연계가 동작함
- 실제 적중 콤보와 공격 동작 연계가 구분됨
- 주령 두 마리와 다중 적 체력·승리 조건이 동작함
- TAB으로 A → B → 해제 전환이 동작함
- 창이 지정된 수렴점으로 적을 끌어당김
- 혁이 전방 경로의 적을 밀어냄
- 창 적중 뒤 혁 적중 시 게임용 연계 보너스가 적용됨
- 적중 여부와 관계없이 Q/E 사용으로 허식 「자」 준비가 진행됨
- 허식 「자」가 락온 방향을 우선함
- 무량공처가 범위 안의 주령들을 일시 정지시킴
- 확장된 바닥과 안전벽이 일반 넉백 낙사를 줄임
- 모든 주령 처치 시 승리, 플레이어 사망 시 패배함

## 아직 포함하지 않는 기능

- 음성인식 연결
- 캐릭터 모델과 애니메이션
- 정교한 카메라 조작과 수동 조준
- 완성형 술식·영역 VFX와 후처리
- NavMesh 기반 장애물 경로 탐색
- 캐릭터 선택
- 실제 키 설정 UI와 새 Input System 전환

먼저 캡슐 형태로 전투 루프를 검증한 뒤 단계적으로 추가합니다.
