# Unity 전투 MVP

이 폴더는 Python/Pygame 장인 연습장에서 검증한 입력 규칙을 실제 전투로 옮기기 위한 Unity 코드입니다.

저장소에서는 `Assets/`, `Packages/`, `ProjectSettings/`를 관리합니다. Unity가 자동 생성하는 `Library`, `Temp`, `Logs`, `UserSettings` 등은 Git에 올리지 않습니다.

## 권장 에디터

- Unity 6.3 LTS (`6000.3.20f1` 또는 최신 6.3 패치)
- 템플릿: Universal 3D (URP)
- 첫 MVP는 외부 에셋과 별도 서드파티 패키지 없이 진행

Unity 6.5 Supported도 정식 제작용 버전이지만, 이 프로젝트는 최신 기능보다 예측 가능한 환경과 긴 지원 기간을 우선합니다. 따라서 Unity 6.3 LTS 계열에 고정하고 같은 6.3 안의 패치 버전만 필요할 때 갱신합니다.

렌더링 파이프라인은 Unity 6의 `Universal 3D` 템플릿이 제공하는 URP로 고정합니다. 이후 영역전개 화면 효과, 셰이더, 후처리 효과도 같은 파이프라인에서 확장합니다.

## 최초 프로젝트 준비

현재 저장소의 `unity/Assets`에 있는 게임 코드를 유지하면서 URP 프로젝트 설정을 합치는 절차입니다.

1. Unity Hub에서 Unity 6.3 LTS의 `Universal 3D` 프로젝트를 임시 위치에 생성합니다.
2. 최초 가져오기와 인덱싱이 끝난 뒤 에디터를 닫습니다.
3. 임시 프로젝트의 `Assets/`, `Packages/`, `ProjectSettings/`를 이 저장소의 `unity/` 안으로 복사합니다.
4. `Assets/`는 기존 폴더를 삭제하지 말고 폴더 병합으로 복사합니다.
5. `Library/`, `Temp/`, `Logs`, `UserSettings/`는 복사하지 않습니다.
6. Unity Hub에서 저장소의 `unity/` 폴더를 프로젝트로 추가해 엽니다.
7. 스크립트 컴파일이 끝나고 Console에 빨간 오류가 없으면 아래 메뉴를 실행합니다.

```text
Tools
→ JJK Game
→ Build Combat MVP Scene
```

자동으로 `Assets/Scenes/CombatMVP.unity`가 생성되고 빌드 목록에 등록됩니다.

기존 장면의 바닥은 재생 시 약 `65 × 65` 크기로 확장되고 가장자리에 낮은 프로토타입 안전벽이 생성됩니다. 장면 파일을 다시 만들 필요는 없습니다.

## 공통 조작 체계

```text
WASD: 이동
SPACE: 짧은 무적 시간이 있는 회피
좌클릭 연속 입력: 1타 → 2타 → 3타 공격 연계
TAB: 가까운 주령부터 타깃 고정, 다음 주령 전환, 마지막 뒤 해제
Q: 스킬 1 — 고죠 술식순전 「창」
E: 스킬 2 — 고죠 술식반전 「혁」
R: 상위기/필살기 — 고죠 허식 「자」
V: 영역전개 준비
우클릭 유지 → 좌클릭 → 초록 타이밍 구간에서 우클릭 해제: 무량공처
X: 진행 중인 영역 입력 취소
ENTER: 승패 결정 뒤 장면 재시작
```

키 정의는 `Assets/Scripts/Core/CombatInputBindings.cs` 한곳에서 관리합니다. 이후 Input System과 키 설정 화면을 연결할 때 이 임시 정의를 교체할 예정입니다.

원작 조건과 게임용 각색의 구분은 저장소 루트의 `docs/CANON_SKILL_RULES.md`를 기준으로 합니다.

## 타깃 고정과 조준

- TAB을 누르면 최대 약 30m 안의 가장 가까운 살아 있는 적을 고정합니다.
- 적 발밑의 황금색 회전 링과 화면 오른쪽 문구로 현재 락온 대상을 표시합니다.
- 적이 죽거나 락온 거리 밖으로 나가면 자동으로 해제됩니다.
- 대상이 여러 명이면 거리순으로 다음 대상을 선택한 뒤 마지막에서 해제됩니다.
- 기본 공격 입력 시 고죠가 락온 대상을 먼저 바라봅니다.
- 허식 「자」는 락온 대상이 있으면 그 방향을 우선 사용하고, 락온이 없을 때만 가장 가까운 적을 자동 조준합니다.
- 현재 카메라는 멀미 방지를 위해 기존의 안정적인 월드 좌표 추적을 유지합니다.

## 공격 연계와 적중 콤보

- `ATTACK CHAIN`은 공격 동작의 순서입니다. 허공을 공격해도 1타 → 2타 → 3타로 진행합니다.
- `HIT COMBO`는 실제 적중한 공격 횟수입니다. 공격이 빗나가거나 일정 시간이 지나면 초기화됩니다.
- 3타는 공격 연계의 마무리 동작이므로 피해, 경직, 넉백이 가장 큽니다.

## 술식 프로토타입

### Q · 술식순전 「창」

- 고죠 주변 약 8m 범위에 청색 원형 효과가 펼쳐집니다.
- 범위 안의 주령에게 8 피해와 짧은 경직을 주고 고죠 쪽으로 끌어당깁니다.
- 기본 재사용 대기시간은 3.2초입니다.

### E · 술식반전 「혁」

- 고죠 주변 약 7m 범위에 적색 폭발 효과가 펼쳐집니다.
- 범위 안의 주령에게 18 피해와 강한 경직을 주고 고죠 반대쪽으로 밀어냅니다.
- 기본 재사용 대기시간은 4.5초입니다.

### 창 → 혁 술식 연계

- 창에 적중한 주령은 약 2.2초 동안 `BLUE MARK` 상태가 됩니다.
- 마크가 유지되는 동안 같은 주령에게 혁을 적중시키면 추가 12 피해와 강화된 밀어내기가 적용됩니다.
- 성공하면 중앙에 `BLUE → RED CHAIN` 문구가 표시됩니다.
- 이 적중 연계는 허식 「자」의 원작 발동 조건과 무관한 `GAME_ORIGINAL` 전투 보너스입니다.

### R · 허식 「자」

- `OFFICIAL_CONFIRMED`: 허식 「자」는 술식순전 「창」과 술식반전 「혁」 자체를 결합하는 기술이며, 두 술식을 상대에게 먼저 적중시킬 필요는 없습니다.
- 따라서 Q와 E를 각각 사용하면 적중 여부와 상관없이 해당 술식의 준비 상태가 생깁니다.
- `GAME_ORIGINAL`: 두 준비 상태는 약 8초 동안 유지되며, 모두 있을 때 R을 누르면 전방형 허식 「자」가 발사됩니다.
- 타깃 고정 상태에서는 고정된 주령 방향을 우선하고, 고정 대상이 없으면 가장 가까운 살아 있는 주령을 자동 조준합니다.
- 기본 판정은 약 18m 길이, 2.2m 반경의 캡슐이며 55 피해와 강한 넉백을 적용합니다.
- 발동 후 두 준비 상태를 소비하고 기본 10초 쿨타임이 적용됩니다.
- 현재 보라색 직선 빔은 기능 검증용 임시 VFX입니다.

피해량, 범위, 쿨타임, 키 배치, 준비 유지시간은 `GAME_ORIGINAL` 전투 프로토타입 수치입니다.

## 다중 주령 전투

- 현재 프로토타입은 주령 두 마리를 동시에 생성합니다.
- 화면 오른쪽에 각 주령의 체력바가 따로 표시됩니다.
- 중앙 상단의 `CURSES LEFT`가 생존한 주령 수를 표시합니다.
- TAB을 반복하면 거리순으로 주령을 전환한 뒤 락온을 해제합니다.
- 한 마리를 처치해도 전투가 끝나지 않으며 모든 주령을 처치해야 승리합니다.
- 두 주령이 동시에 공격 준비 중이면 경고에 공격 수가 함께 표시됩니다.

이 다중 적 판정은 이후 스쿠나 화염의 영역 밖 1대1 제한, 영역 안 광역 전환 같은 원작 조건을 구현하는 기반으로 사용합니다.

## 영역전개

- V로 영역전개 입력을 시작합니다.
- 입력 중에는 Q, E, R 술식을 사용할 수 없습니다.
- X로 진행 중인 입력을 취소할 수 있습니다.
- 무량공처가 성공하면 범위 안의 모든 `IDomainStunnable` 대상이 약 3초 동안 행동 불능 상태가 됩니다.

## 맵과 낙사 안전장치

- 기존 약 `30 × 30` 바닥을 재생 시 약 `65 × 65`로 확장합니다.
- 가장자리에 낮은 안전벽을 만들어 일반적인 혁·허식 자 넉백으로 즉시 떨어지는 상황을 줄입니다.
- 플레이어나 주령의 Y 좌표가 기본 `-12` 아래로 내려가면 체력이 즉시 0이 되는 최종 안전장치는 유지합니다.
- 정식 맵 단계에서는 낙사 구역, 벽, 파괴 가능한 지형과 리스폰 규칙을 별도로 설계할 예정입니다.

## 현재 전투 피드백

- 공격 연계와 실제 적중 콤보를 별도로 표시
- 기본 공격 적중 시 점멸, 경직, 넉백 적용
- 주령 공격 직전에 주황색 점멸과 `DODGE!` 경고 표시
- SPACE 회피 중 짧은 무적 시간 적용
- TAB 락온 링과 현재 대상 표시
- Q, E, R별 상태와 쿨타임을 화면 왼쪽에 표시
- 창 → 혁 연계 가능 상태와 성공 문구 표시
- 주령별 체력과 생존 주령 수 표시
- 무량공처 타이밍 바와 임시 영역 시각효과 표시
- 낙사 또는 체력 0에서 승패 결정

## 현재 성공 기준

- 플레이어가 이동하고 SPACE로 회피할 수 있음
- TAB으로 첫 번째 주령, 두 번째 주령, 락온 해제 순서가 동작함
- 락온한 주령 발밑에 황금색 링이 표시됨
- 락온 상태의 기본 공격과 허식 「자」가 해당 대상 방향을 우선함
- 허공 공격은 `ATTACK CHAIN`, 실제 적중은 `HIT COMBO`로 구분됨
- 주령 두 마리가 플레이어를 추적하고 공격 전에 경고를 표시함
- Q는 끌어당기고 E는 밀어냄
- Q 적중 뒤 제한 시간 안에 E를 맞히면 게임용 연계 보너스가 적용됨
- 적중 여부와 관계없이 Q와 E를 각각 사용하면 R 허식 「자」 준비가 진행됨
- 한 주령만 처치했을 때 전투가 계속되고 두 주령 모두 처치하면 승리함
- 확장된 바닥과 안전벽이 일반 넉백 낙사를 줄임
- V 영역 입력 중 Q/E/R이 차단되고 X로 입력을 취소할 수 있음
- 무량공처 입력 성공 시 범위 안의 주령들이 일시 정지함
- 낙사와 체력 0에서 승패 화면이 표시됨
- ENTER로 장면을 다시 시작할 수 있음

## 폴더 역할

```text
Assets/Scripts/Core/
- 체력, 무적, 낙사, 전투 HUD, 다중 적 승패, 런타임 맵 확장, 공통 입력 정의

Assets/Scripts/Player/
- 이동, 회피, 공격 연계, 타깃 고정, 고죠 창·혁·자, 영역 입력과 임시 시각효과

Assets/Scripts/Enemy/
- 주령 상태 머신, 공격 예고, 경직·넉백·점멸 반응

Assets/Scripts/Camera/
- 플레이어 추적 카메라

Assets/Editor/
- MVP 장면 자동 생성 도구
```

## 아직 포함하지 않는 기능

- 음성인식 연결
- 캐릭터 모델과 애니메이션
- 정교한 카메라 조작과 수동 조준
- 완성형 술식·영역 VFX와 후처리
- NavMesh 기반 장애물 경로 탐색
- 캐릭터 선택
- 실제 키 설정 UI와 새 Input System 전환

먼저 캡슐 형태로 전투 루프를 검증한 뒤 단계적으로 추가합니다.
