# Unity 전투 MVP

이 폴더는 Python/Pygame 장인 연습장에서 검증한 입력 규칙을 실제 전투로 옮기기 위한 Unity 코드입니다.

저장소에서는 `Assets/`, `Packages/`, `ProjectSettings/`를 관리합니다. Unity가 자동 생성하는 `Library`, `Temp`, `Logs`, `UserSettings` 등은 Git에 올리지 않습니다.

## 권장 에디터

- Unity 6.3 LTS (`6000.3.20f1` 또는 최신 6.3 패치)
- 템플릿: Universal 3D (URP)
- 첫 MVP는 외부 에셋과 별도 서드파티 패키지 없이 진행

Unity 6.5 Supported도 정식 제작용 버전이지만, 이 프로젝트는 최신 기능보다 예측 가능한 환경과 긴 지원 기간을 우선합니다. 따라서 Unity 6.3 LTS 계열에 고정하고 같은 6.3 안의 패치 버전만 필요할 때 갱신합니다.

렌더링 파이프라인은 Unity 6의 `Universal 3D` 템플릿이 제공하는 URP로 고정합니다. 이후 영역전개 화면 효과, 셰이더, 후처리 효과도 같은 파이프라인에서 확장합니다.

## 최초 프로젝트 준비

현재 저장소의 `unity/Assets`에 있는 게임 코드를 유지하면서 URP 프로젝트 설정을 합치는 절차입니다.

1. Unity Hub에서 Unity 6.3 LTS의 `Universal 3D` 프로젝트를 임시 위치에 생성합니다.
2. 최초 가져오기와 인덱싱이 끝난 뒤 에디터를 닫습니다.
3. 임시 프로젝트의 `Assets/`, `Packages/`, `ProjectSettings/`를 이 저장소의 `unity/` 안으로 복사합니다.
4. `Assets/`는 기존 폴더를 삭제하지 말고 폴더 병합으로 복사합니다.
5. `Library/`, `Temp/`, `Logs`, `UserSettings/`는 복사하지 않습니다.
6. Unity Hub에서 저장소의 `unity/` 폴더를 프로젝트로 추가해 엽니다.
7. 스크립트 컴파일이 끝나고 Console에 빨간 오류가 없으면 아래 메뉴를 실행합니다.

```text
Tools
→ JJK Game
→ Build Combat MVP Scene
```

자동으로 `Assets/Scenes/CombatMVP.unity`가 생성되고 빌드 목록에 등록됩니다.

## 공통 조작 체계

```text
WASD: 이동
SPACE: 짧은 무적 시간이 있는 회피
좌클릭 연속 입력: 1타 → 2타 → 3타 공격 연계
Q: 스킬 1 — 고죠 술식순전 「창」
E: 스킬 2 — 고죠 술식반전 「혁」
R: 상위기/필살기 — 고죠 허식 「자」
V: 영역전개 준비
우클릭 유지 → 좌클릭 → 초록 타이밍 구간에서 우클릭 해제: 무량공처
X: 진행 중인 영역 입력 취소
ENTER: 승패 결정 뒤 장면 재시작
```

키 정의는 `Assets/Scripts/Core/CombatInputBindings.cs` 한곳에서 관리합니다. 이후 Input System과 키 설정 화면을 연결할 때 이 임시 정의를 교체할 예정입니다.

## 공격 연계와 적중 콤보

- `ATTACK CHAIN`은 공격 동작의 순서입니다. 허공을 공격해도 1타 → 2타 → 3타로 진행합니다.
- `HIT COMBO`는 실제 적중한 공격 횟수입니다. 공격이 빗나가거나 일정 시간이 지나면 초기화됩니다.
- 3타는 공격 연계의 마무리 동작이므로 피해, 경직, 넉백이 가장 큽니다.

## 술식 프로토타입

### Q · 술식순전 「창」

- 고죠 주변 약 8m 범위에 청색 원형 효과가 펼쳐집니다.
- 범위 안의 주령에게 8 피해와 짧은 경직을 주고 고죠 쪽으로 끌어당깁니다.
- 기본 재사용 대기시간은 3.2초입니다.

### E · 술식반전 「혁」

- 고죠 주변 약 7m 범위에 적색 폭발 효과가 펼쳐집니다.
- 범위 안의 주령에게 18 피해와 강한 경직을 주고 고죠 반대쪽으로 밀어냅니다.
- 기본 재사용 대기시간은 4.5초입니다.

### 창 → 혁 술식 연계

- 창에 적중한 주령은 약 2.2초 동안 `BLUE MARK` 상태가 됩니다.
- 마크가 유지되는 동안 같은 주령에게 혁을 적중시키면 추가 12 피해와 강화된 밀어내기가 적용됩니다.
- 성공하면 중앙에 `BLUE → RED CHAIN` 문구가 표시됩니다.

### R · 허식 「자」

- 창과 혁을 각각 한 번 이상 적중시키면 약 8초 동안 해당 술식의 준비 자원이 유지됩니다.
- 두 준비 자원이 모두 있을 때 R을 누르면 가장 가까운 살아 있는 적 방향으로 전방형 허식 「자」가 발사됩니다.
- 기본 판정은 약 18m 길이, 2.2m 반경의 캡슐이며 55 피해와 강한 넉백을 적용합니다.
- 발동 후 두 준비 자원을 소비하고 기본 10초 쿨타임이 적용됩니다.
- 현재 보라색 직선 빔은 기능 검증용 임시 VFX입니다.

원작 기술명을 사용하지만 피해량, 범위, 쿨타임, 키 배치, 연계 자원 규칙은 `GAME_ORIGINAL` 전투 프로토타입입니다.

## 영역전개

- V로 영역전개 입력을 시작합니다.
- 입력 중에는 Q, E, R 술식을 사용할 수 없습니다.
- X로 진행 중인 입력을 취소할 수 있습니다.
- 무량공처가 성공하면 범위 안의 `IDomainStunnable` 대상이 약 3초 동안 행동 불능 상태가 됩니다.

## 낙사 안전장치

- 플레이어나 주령의 Y 좌표가 기본 `-12` 아래로 내려가면 체력이 즉시 0이 됩니다.
- 주령이 떨어지면 승리, 플레이어가 떨어지면 패배 처리됩니다.
- 정식 맵 단계에서는 낙사 구역, 리스폰, 벽과 맵 경계를 별도로 설계할 예정입니다.

## 현재 전투 피드백

- 공격 연계와 실제 적중 콤보를 별도로 표시
- 기본 공격 적중 시 점멸, 경직, 넉백 적용
- 주령 공격 직전에 주황색 점멸과 `DODGE!` 경고 표시
- SPACE 회피 중 짧은 무적 시간 적용
- Q, E, R별 상태와 쿨타임을 화면 왼쪽에 표시
- 창 → 혁 연계 가능 상태와 성공 문구 표시
- 무량공처 타이밍 바와 임시 영역 시각효과 표시
- 낙사 또는 체력 0에서 승패 결정

## 현재 성공 기준

- 플레이어가 이동하고 SPACE로 회피할 수 있음
- 허공 공격은 `ATTACK CHAIN`, 실제 적중은 `HIT COMBO`로 구분됨
- 주령이 추적하고 공격 전에 경고를 표시함
- Q는 끌어당기고 E는 밀어냄
- Q 적중 뒤 제한 시간 안에 E를 맞히면 연계 보너스가 적용됨
- Q와 E를 모두 적중시킨 뒤 R로 허식 「자」를 사용할 수 있음
- R 사용 후 준비 자원과 쿨타임이 정상적으로 갱신됨
- V 영역 입력 중 Q/E/R이 차단되고 X로 입력을 취소할 수 있음
- 무량공처 입력 성공 시 주령이 일시 정지함
- 낙사와 체력 0에서 승패 화면이 표시됨
- ENTER로 장면을 다시 시작할 수 있음

## 폴더 역할

```text
Assets/Scripts/Core/
- 체력, 무적, 낙사, 전투 HUD, 승패, 공통 입력 정의와 인터페이스

Assets/Scripts/Player/
- 이동, 회피, 공격 연계, 고죠 창·혁·자, 영역 입력과 임시 시각효과

Assets/Scripts/Enemy/
- 주령 상태 머신, 공격 예고, 경직·넉백·점멸 반응

Assets/Scripts/Camera/
- 플레이어 추적 카메라

Assets/Editor/
- MVP 장면 자동 생성 도구
```

## 아직 포함하지 않는 기능

- 음성인식 연결
- 캐릭터 모델과 애니메이션
- 정교한 카메라 조작과 조준
- 완성형 술식·영역 VFX와 후처리
- 여러 주령과 경로 탐색
- 캐릭터 선택
- 실제 키 설정 UI와 새 Input System 전환

먼저 캡슐 형태로 전투 루프를 검증한 뒤 단계적으로 추가합니다.
