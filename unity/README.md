# Unity 전투 MVP

이 폴더는 Python/Pygame 장인 연습장에서 검증한 입력 규칙을 실제 전투로 옮기기 위한 Unity 코드입니다.

저장소에서는 `Assets/`, `Packages/`, `ProjectSettings/`를 관리합니다. Unity가 자동 생성하는 `Library`, `Temp`, `Logs`, `UserSettings` 등은 Git에 올리지 않습니다.

## 권장 에디터

- Unity 6.3 LTS (`6000.3.20f1` 또는 최신 6.3 패치)
- 템플릿: Universal 3D (URP)
- 외부 에셋과 별도 서드파티 패키지 없이 전투 루프를 우선 검증

## 최초 프로젝트 준비

1. Unity Hub에서 Unity 6.3 LTS의 `Universal 3D` 프로젝트를 임시 위치에 생성합니다.
2. 최초 가져오기와 인덱싱이 끝난 뒤 에디터를 닫습니다.
3. 임시 프로젝트의 `Assets/`, `Packages/`, `ProjectSettings/`를 저장소의 `unity/` 안으로 병합합니다.
4. `Library/`, `Temp/`, `Logs`, `UserSettings`는 복사하지 않습니다.
5. Unity Hub에서 저장소의 `unity/` 폴더를 프로젝트로 추가해 엽니다.
6. Console에 빨간 오류가 없으면 아래 메뉴로 MVP 장면을 생성할 수 있습니다.

```text
Tools
→ JJK Game
→ Build Combat MVP Scene
```

현재 진행 중인 장면은 대부분 런타임 자동 확장을 사용하므로 매 변경마다 장면을 다시 만들 필요는 없습니다.

## 공통 조작 체계

```text
WASD: 이동
SPACE: 짧은 무적 시간이 있는 회피
좌클릭 연속 입력: 1타 → 2타 → 3타 공격 연계
TAB: 가까운 주령 락온 → 다음 주령 전환 → 마지막 뒤 해제
Q: 스킬 1 — 고죠 술식순전 「창」
E: 스킬 2 — 고죠 술식반전 「혁」
R: 상위기/필살기 — 고죠 허식 「자」
V: 영역전개 준비
우클릭 유지 → 좌클릭 → 초록 타이밍에서 우클릭 해제: 무량공처
X: 진행 중인 영역 입력 취소
ENTER: 승패 결정 뒤 장면 재시작
```

키 정의는 `Assets/Scripts/Core/CombatInputBindings.cs` 한곳에서 관리합니다. 원작 조건과 게임용 각색은 `docs/CANON_SKILL_RULES.md`, 공식 게임 연출 참고 기준은 `docs/ADAPTATION_REFERENCES.md`를 따릅니다.

## 공통 행동 상태

`CombatActionGate`가 다음 상태를 한곳에서 판정합니다.

```text
Normal
Dodging
TechniqueCasting
DomainInput
DomainActive
Disabled
```

현재 규칙:

- Q/E 시전 중 좌클릭, 새 회피, V와 R 시작 차단
- 회피 중 좌클릭, Q/E/R/V 시작 차단
- 영역 입력·전개 중 일반 술식과 기본 공격 차단
- Q/E 시전 중 이동은 기본 속도의 약 35%로 감소
- 술식 번아웃 중 Q/E/R/V 차단, 기본 공격·이동·회피는 허용

## 캐릭터별 주력 프로필

`CursedEnergyController`가 최대치, 소비 효율, 자동 회복과 HUD를 관리합니다.

### 현재 고죠

```text
프로필: SIX EYES · 육안 효율
최대 주력: 100
자동 회복: 초당 12
기술 사용 뒤 회복 지연: 0.8초

Q · 창 실제 소비: 1
E · 혁 실제 소비: 1
R · 허식 「자」 실제 소비: 1
V · 무량공처 실제 소비: 1
```

내부 밸런스 기본값은 Q 16, E 24, R 45, V 60이지만 육안 효율 프로필이 0에 가까운 손실을 표현하도록 실제 소비를 최소 1로 보정합니다.

준비된 공통 프로필:

- `SixEyesEfficiency`: 고죠 효율형, 최대 100
- `SukunaVastReserve`: 스쿠나 대용량형 예정, 최대 300
- `YutaLargeReserve`: 유타 대용량형 예정, 최대 150
- `Standard`: 일반형, 최대 100

정확한 최대치와 회복 수치는 `GAME_ORIGINAL` 출발점이며 캐릭터 구현 때 원작과 팬텀 퍼레이드의 전투게임식 번역을 다시 비교합니다.

## 타깃 고정과 조준

- TAB을 누르면 최대 약 42m 안의 가장 가까운 살아 있는 적을 고정합니다.
- 적 발밑의 황금색 회전 링과 화면 오른쪽 문구로 현재 락온 대상을 표시합니다.
- 적이 죽거나 락온 거리 밖으로 나가면 자동으로 해제됩니다.
- 대상이 여러 명이면 거리순으로 다음 대상을 선택한 뒤 마지막에서 해제됩니다.
- 기본 공격, 창, 혁과 허식 「자」가 락온 대상을 우선합니다.

## 공격 연계와 적중 콤보

- `ATTACK CHAIN`은 공격 동작 순서이며 허공을 공격해도 진행됩니다.
- `HIT COMBO`는 실제 적중 횟수이며 빗나가거나 시간이 지나면 초기화됩니다.
- 3타는 피해, 경직과 넉백이 가장 큽니다.
- 사용자 테스트에서 3타 소리 차이가 약해 별도 저음 충격음, 더 강한 흔들림과 플래시를 추가했습니다.

## 술식 프로토타입

### Q · 술식순전 「창」

- 약 0.24초 시전 후 생성됩니다.
- 락온 대상 근처 또는 고죠 정면 약 10m에 수렴장을 생성합니다.
- 약 0.95초 유지되며 범위 안의 적을 중심으로 반복해서 끌어당깁니다.
- 대상별 피해는 한 번만 적용됩니다.
- 기본 쿨타임 3.2초, 육안 적용 실제 주력 소비 1입니다.

### E · 술식반전 「혁」

- 약 0.30초 시전 후 실제 이동하는 적색 발사체를 생성합니다.
- 락온 방향 또는 고죠 정면으로 약 11m 이동합니다.
- 경로의 적을 대상별 한 번 타격하며 여러 적을 관통할 수 있습니다.
- 기본 쿨타임 4.5초, 육안 적용 실제 주력 소비 1입니다.

### 창 → 혁 술식 연계

- 창에 적중한 주령은 약 2.2초 동안 `BLUE MARK` 상태가 됩니다.
- 같은 주령에게 제한시간 안에 혁을 맞히면 추가 12 피해와 강화 넉백이 적용됩니다.
- 허식 「자」의 원작 준비 조건과 무관한 별도 게임용 보너스입니다.

### R · 허식 「자」

- 창과 혁을 상대에게 먼저 적중시킬 필요는 없습니다.
- Q와 E를 각각 사용하면 적중 여부와 무관하게 준비 상태가 생깁니다.
- 두 상태가 약 8초 안에 함께 존재할 때 R로 발동합니다.
- 기본 쿨타임 10초, 육안 적용 실제 주력 소비 1입니다.
- 현재 보라색 직선 빔은 기능 검증용 임시 VFX입니다.

## 영역전개와 술식 번아웃

- V로 무량공처 장인 입력을 시작합니다.
- 시작 시 실제 필요 주력 1을 확인하고 성공 발동 시 소비합니다.
- X로 진행 중인 입력을 취소할 수 있습니다.
- 성공하면 범위 안의 `IDomainStunnable` 대상이 약 3초간 행동 불능 상태가 됩니다.
- 무량공처 종료 후 약 5초 동안 술식 번아웃이 발생해 Q/E/R/V가 봉인됩니다.
- 번아웃 중 화면 왼쪽에 남은 시간이 표시됩니다.
- `RestoreTechniqueEarly()`는 향후 반전술식으로 번아웃을 조기 회복하기 위한 훅입니다.

## 전투 오디오와 화면 피드백

외부 파일 없이도 다음 사건에 런타임 합성 효과음이 재생됩니다.

- 기본 공격 휘두름·적중·3타 마무리
- 플레이어 피격과 회피
- 창·혁 시전과 적중
- 허식 자와 무량공처 실제 발동
- 승리와 패배

공격 적중과 기술 발동에는 짧은 카메라 위치 흔들림과 화면 플래시가 적용됩니다. 카메라 회전은 건드리지 않습니다. 개인용 음원 교체 방법은 `docs/AUDIO_SETUP.md`를 따릅니다.

## 다중 주령 전투

- 주령 두 마리를 동시에 생성합니다.
- 주령별 체력바와 `CURSES LEFT`를 표시합니다.
- 한 마리를 처치해도 전투가 계속되며 모두 처치해야 승리합니다.
- 두 주령이 동시에 공격을 준비하면 `DODGE! × 2`처럼 표시합니다.

## 맵과 낙사 안전장치

- 기존 약 `30 × 30` 바닥을 재생 시 약 `65 × 65`로 확장합니다.
- 가장자리에 낮은 안전벽을 생성합니다.
- 플레이어나 주령이 기본 `Y=-12` 아래로 내려가면 즉시 사망합니다.

## 아직 포함하지 않는 기능

- Python 음성인식과 Unity 연결
- 캐릭터 모델과 애니메이션
- 정교한 카메라 조작과 수동 조준
- 완성형 술식·영역 VFX와 후처리
- NavMesh 기반 장애물 경로 탐색
- 캐릭터 선택
- 반전술식에 의한 번아웃 조기 회복 입력
- 실제 키 설정 UI와 새 Input System 전환

먼저 캡슐 형태로 전투 루프를 검증한 뒤 단계적으로 추가합니다.
