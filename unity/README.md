# Unity 전투 MVP

이 폴더는 Python/Pygame 장인 연습장에서 검증한 입력 규칙을 실제 전투로 옮기기 위한 Unity 코드입니다.

저장소에서는 `Assets/`, `Packages/`, `ProjectSettings/`를 관리합니다. Unity가 자동 생성하는 `Library`, `Temp`, `Logs`, `UserSettings` 등은 Git에 올리지 않습니다.

## 권장 에디터

- Unity 6.3 LTS (`6000.3.20f1` 또는 최신 6.3 패치)
- 템플릿: Universal 3D (URP)
- 첫 MVP는 외부 에셋과 별도 서드파티 패키지 없이 진행

Unity 6.5 Supported도 정식 제작용 버전이지만, 이 프로젝트는 초보 사용자와 장기간 함께 유지하며 최신 기능보다 예측 가능한 환경, 긴 지원 기간, 축적된 문제 해결 자료를 우선합니다. 따라서 2027년 12월까지 지원되는 Unity 6.3 LTS 계열에 고정하고, 같은 6.3 안의 패치 버전만 필요할 때 갱신합니다.

렌더링 파이프라인은 Unity 6의 `Universal 3D` 템플릿이 제공하는 URP로 고정합니다. 현재 전투 MVP뿐 아니라 이후 영역전개 화면 효과, 셰이더, 후처리 효과를 확장하기 쉽도록 프로젝트 시작 단계부터 동일한 파이프라인을 유지합니다.

## 최초 프로젝트 준비

현재 저장소의 `unity/Assets`에 있는 게임 코드를 유지하면서 URP 프로젝트 설정을 합치는 절차입니다.

1. Unity Hub에서 Unity 6.3 LTS의 `Universal 3D` 프로젝트를 임시 위치에 생성합니다.
2. 최초 가져오기와 인덱싱이 끝난 뒤 에디터를 닫습니다.
3. 임시 프로젝트의 `Assets/`, `Packages/`, `ProjectSettings/`를 이 저장소의 `unity/` 안으로 복사합니다.
4. `Assets/`는 기존 폴더를 삭제하거나 덮어쓰지 말고 폴더 병합으로 복사합니다. URP 설정 파일과 기존 게임 스크립트가 함께 남아야 합니다.
5. `Library/`, `Temp/`, `Logs`, `UserSettings/`는 복사하지 않습니다.
6. Unity Hub에서 저장소의 `unity/` 폴더를 프로젝트로 추가해 엽니다.
7. 스크립트 컴파일이 끝나고 Console에 빨간 오류가 없으면 상단 메뉴에서 아래 항목을 실행합니다.

```text
Tools
→ JJK Game
→ Build Combat MVP Scene
```

자동으로 `Assets/Scenes/CombatMVP.unity`가 생성되고 빌드 목록에 등록됩니다.

## 조작

```text
WASD: 이동
SPACE: 짧은 무적 시간이 있는 회피
좌클릭 연속 입력: 1타 → 2타 → 3타 공격 연계
Q: 술식순전 「창」
E: 술식반전 「혁」
V: 영역전개 준비
우클릭 유지 → 좌클릭 → 초록 타이밍 구간에서 우클릭 해제: 무량공처
R: 영역 입력 초기화
ENTER: 승패 결정 뒤 장면 재시작
```

무량공처가 성공하면 영역 반경 안의 `IDomainStunnable` 대상이 일정 시간 행동 불능 상태가 됩니다. 현재 주령 봇이 이 인터페이스를 구현합니다.

## 공격 연계와 적중 콤보

- `ATTACK CHAIN`은 공격 동작의 순서입니다. 허공을 공격해도 1타 → 2타 → 3타로 진행합니다.
- `HIT COMBO`는 실제 적중한 공격 횟수입니다. 공격이 빗나가거나 일정 시간이 지나면 초기화됩니다.
- 3타는 공격 연계의 마무리 동작이므로 피해, 경직, 넉백이 가장 큽니다.

## 술식 프로토타입

### Q · 술식순전 「창」

- 고죠 주변 약 8m 범위에 청색 원형 효과가 펼쳐집니다.
- 범위 안의 주령에게 8 피해와 짧은 경직을 주고 고죠 쪽으로 끌어당깁니다.
- 기본 재사용 대기시간은 3.2초입니다.

### E · 술식반전 「혁」

- 고죠 주변 약 7m 범위에 적색 폭발 효과가 펼쳐집니다.
- 범위 안의 주령에게 18 피해와 강한 경직을 주고 고죠 반대쪽으로 밀어냅니다.
- 기본 재사용 대기시간은 4.5초입니다.

두 술식은 화면 왼쪽에 별도의 쿨타임 막대가 표시되며 영역전개 입력 및 발동 중에는 사용할 수 없습니다. 원작 기술명을 사용하지만 피해량, 범위, 쿨타임, 키 배치는 `GAME_ORIGINAL` 전투 프로토타입입니다.

## 현재 전투 피드백

- 공격 연계 시 화면 상단 중앙에 `ATTACK CHAIN` 단계 표시
- 두 번 이상 연속 적중하면 별도의 `HIT COMBO` 표시
- 기본 공격 적중 시 주령이 흰색으로 짧게 점멸
- 기본 공격 적중 시 짧은 경직과 넉백 적용
- 주령 공격 직전에 몸이 주황색으로 점멸하고 중앙에 `DODGE!` 경고 표시
- SPACE 회피 중 짧은 무적 시간 적용
- Q 사용 시 청색 범위 효과, 피해, 경직, 끌어당김 적용
- E 사용 시 적색 범위 효과, 피해, 강한 경직, 밀어내기 적용
- 영역 해제 타이밍에는 화면 하단에 초록 성공 구간과 이동하는 흰색 커서 표시
- 무량공처 성공 시 청색·보라색 원형 효과와 조명이 약 3초간 표시
- 무량공처 범위 안의 주령은 효과 지속 중 행동 불능
- 화면 상단에 고죠와 주령의 체력바 표시
- 화면 하단에 현재 영역전개 입력 상태와 조작 안내 표시
- 승패 결정 시 전투 입력을 멈추고 중앙 결과 화면 표시

## 현재 성공 기준

- 플레이어가 이동하고 SPACE로 회피할 수 있음
- 허공을 공격해도 `ATTACK CHAIN`은 1타 → 2타 → 3타로 진행됨
- 실제 적중했을 때만 `HIT COMBO`가 누적됨
- 공격이 빗나가면 적중 콤보가 끊김
- 공격 연계 입력을 늦게 하면 다시 1타부터 시작됨
- 주령이 플레이어를 추적하고 공격 전에 경고를 표시함
- 경고에 맞춰 회피하면 피해를 받지 않을 수 있음
- Q 사용 시 범위 안의 주령이 고죠 쪽으로 끌려오고 쿨타임이 표시됨
- E 사용 시 범위 안의 주령이 고죠 반대쪽으로 밀려나고 쿨타임이 표시됨
- 승패 결정 뒤 Q와 E가 더 이상 발동하지 않음
- 어느 한쪽의 체력이 0이 되면 승리 또는 패배 표시
- 영역 타이밍 바의 흰색 선을 초록 구간에서 놓으면 무량공처가 발동함
- 고죠 장인 입력 성공 시 주령이 일시 정지
- 장인 입력 중 좌클릭이 기본 공격으로 중복 처리되지 않음
- 기본 공격 적중 시 시각 피드백과 넉백이 보임
- 무량공처 성공 시 임시 영역 시각효과가 보임
- 체력바가 피해량에 맞춰 줄어듦
- 승패 화면에서 ENTER로 장면을 다시 시작할 수 있음

## 폴더 역할

```text
Assets/Scripts/Core/
- 체력, 무적 시간, 전투 HUD, 승패, 공통 인터페이스

Assets/Scripts/Player/
- 이동, 회피, 3단 공격 연계, 적중 콤보, 고죠 창·혁, 영역 입력, 무량공처 임시 시각효과

Assets/Scripts/Enemy/
- 주령 상태 머신, 공격 예고, 경직·넉백·점멸 반응

Assets/Scripts/Camera/
- 플레이어 추적 카메라

Assets/Editor/
- MVP 장면 자동 생성 도구
```

## 아직 포함하지 않는 기능

- 음성인식 연결
- 캐릭터 모델과 애니메이션
- 허식 「자」
- 정교한 카메라 조작
- 완성형 영역 배경과 후처리
- 여러 주령과 경로 탐색
- 캐릭터 선택

먼저 캡슐 형태로 전투 루프를 검증한 뒤 단계적으로 추가합니다.
