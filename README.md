# JJK Game

주술회전의 **장인(손동작), 술식 선언, 영역전개 연출**을 게임 입력 시스템으로 옮기는 개인 프로젝트입니다.

> 새 ChatGPT 대화나 새로운 개발 환경에서 이어서 작업할 때는 [`docs/HANDOFF.md`](docs/HANDOFF.md)를 먼저 읽어주세요.

## 현재 목표

고죠 사토루의 무량공처와 스쿠나(이타도리)의 복마어주자 장인 프로토타입은 로컬 기본 동작 확인을 마쳤습니다.

현재 다음 목표는 **후시구로 메구미의 설정 카드 검토와 감합암예정 장인 커맨드 설계**입니다.

메구미는 미완성 영역이라는 특성을 살려, 스쿠나와 다른 **그림자 마우스 궤적 입력**을 우선 검토합니다.

## 현재 실행 가능한 기능

- 캐릭터 선택 화면과 연습 화면 전환
- 고죠 사토루와 스쿠나(이타도리) 선택 가능
- 후시구로 메구미는 설정 카드 검토 중인 잠금 슬롯으로 표시
- 캐릭터별 컨트롤러·장인 입력·임시 이펙트 분리
- 고죠: 한 손 마우스 장인과 무량공처
- 스쿠나: E 키 + 마우스 양 버튼 장인과 복마어주자
- 캐릭터별 장인 안내 문구를 데이터로 관리
- 캐릭터 카드 자동 줄바꿈
- 일본어 음성 `료이키 텐카이`
- V 키 음성 대체 입력
- 성공·실패 판정과 연습 통계
- R 현재 시도 초기화, T 통계 초기화, B 캐릭터 선택 복귀
- Python 파일 문법 검사용 GitHub Actions

## 캐릭터 설정 카드

- [료멘 스쿠나 v1.0](docs/characters/sukuna.md): 이타도리 몸 기준 사용자 검토 완료
- [후시구로 메구미 v0.1](docs/characters/megumi.md): 사용자 검토 전 초안

확정 원칙:

- 몸 형태별 스쿠나는 별도 캐릭터로 추가
- 스쿠나(이타도리): 해·팔·푸가, 복마어주자
- 스쿠나(이타도리): 십종영법술과 세계참 미포함
- 모든 영역전개 캐릭터의 음성은 `료이키 텐카이`까지만 요구
- 실제 발동 영역은 선택 캐릭터와 장인 커맨드로 결정
- 캐릭터 구현 전 설정 카드를 작성하고 사용자 검토를 받음

## 실행 방법

```bash
git pull origin master
python -m pip install -r requirements.txt
python main.py
```

처음 음성 모델을 설치하는 경우에만:

```bash
python scripts/setup_voice_model.py
```

음성 모델이나 마이크가 없어도 V 키는 정상 사용 가능합니다.

## 조작법

### 캐릭터 선택

```text
1 / ENTER / 고죠 카드 클릭: 고죠 사토루
2 / 스쿠나 카드 클릭: 스쿠나(이타도리)
3 / 메구미 카드: 설정 검토 중이라 선택 불가
ESC: 종료
```

### 고죠 · 무량공처

```text
V 또는 음성 "료이키 텐카이"
→ 우클릭 유지
→ 우클릭 유지 중 좌클릭
→ 초록색 구간에서 우클릭 해제
```

판정값:

```text
목표 해제: 0.90초
허용 오차: ±0.22초
```

사용자 1차 결과:

```text
10회 중 8회 성공
평균 해제 오차 0.123초
```

### 스쿠나(이타도리) · 복마어주자

```text
V 또는 음성 "료이키 텐카이"
→ E 키 누르고 유지
→ E 유지 중 좌·우클릭을 거의 동시에 누르고 유지
→ 초록색 구간에서 좌·우클릭을 거의 동시에 해제
```

초기 판정값:

```text
E 입력 후 양쪽 마우스 완성 제한: 0.70초
좌·우클릭 누름 동시 인정: 0.18초
목표 유지 시간: 0.85초
유지 시간 허용 오차: ±0.22초
좌·우클릭 해제 동시 인정: 0.18초
```

사용자가 로컬에서 기본 입력과 발동이 정상 작동한다고 확인했습니다. 세부 난이도 통계는 추후 추가 조절합니다.

### 공통 연습 조작

```text
R: 현재 장인 시도 초기화
T: 누적 통계 초기화
B: 캐릭터 선택으로 복귀
ESC: 종료
```

## 음성인식

- Vosk + sounddevice
- 일본어 소형 모델 `vosk-model-small-ja-0.22`
- 확정 결과만 사용
- 전체 문구 정확히 일치
- 평균 신뢰도 88% 이상
- 한자·히라가나·가타카나 표기 허용

## 현재 구조

```text
main.py

game/character.py

game/domain_protocol.py
- 캐릭터별 컨트롤러 공통 규약

game/domain_controller.py
- 고죠 무량공처 판정

game/sukuna_domain_controller.py
- 스쿠나 복마어주자 양손 판정

game/runtime.py
- 선택 캐릭터에 맞는 컨트롤러·입력·이펙트 생성

game_input/mouse_seal_input.py
- 고죠 마우스 한 손 장인

game_input/sukuna_two_hand_input.py
- 스쿠나 E 키 + 마우스 양손 장인

ui/common.py
- 한글 폰트, 텍스트, 줄바꿈 공통 기능

ui/character_select_screen.py
- 캐릭터 선택 화면과 선택 이벤트

ui/practice_screen.py
- 장인 안내, 타이밍 바, 연습 통계 화면

effects/muryang_effect.py
- 임시 무량공처

effects/fukuma_effect.py
- 임시 복마어주자

docs/characters/gojo.md
docs/characters/sukuna.md
docs/characters/megumi.md
```

```text

└─ VoiceDomainTrigger

├─ SukunaTwoHandSealInput
```
