# JJK Game

주술회전의 **장인(손동작), 술식 선언, 영역전개 연출**을 게임 입력 시스템으로 옮기는 개인 프로젝트입니다.

> 새 ChatGPT 대화나 새로운 개발 환경에서 이어서 작업할 때는 [`docs/HANDOFF.md`](docs/HANDOFF.md)를 먼저 읽어주세요.

## 현재 목표

첫 MVP인 고죠 사토루의 **무량공처 장인 커맨드 프로토타입**은 정상 작동과 1차 난이도 검증을 마쳤습니다.

현재 다음 목표는 **스쿠나(이타도리)의 복마어주자 양손 장인 커맨드**입니다.

```text
료이키 텐카이 또는 V
→ 왼손 E 키 유지
→ 오른손으로 좌·우클릭을 거의 동시에 누르고 유지
→ 목표 타이밍에 좌·우클릭을 거의 동시에 해제
→ 복마어주자 발동
```

## 현재 실행 가능한 기능

- 캐릭터 선택 화면과 연습 화면 전환
- 고죠 사토루 선택 가능
- 스쿠나(이타도리)는 설정 확정·커맨드 구현 중인 잠금 슬롯으로 표시
- 긴 캐릭터 설명을 카드 안에서 자동 줄바꿈
- `NORMAL`, `DOMAIN_READY`, `WAIT_LEFT_CLICK`, `RELEASE_TIMING`, `DOMAIN_ACTIVE`, `FAILED` 상태 머신
- 고죠 마우스 장인 입력 성공/실패 판정
- 타이밍 연습 UI
- 성공 시 코드로 그린 임시 무량공처 이펙트
- 한국어 UI 및 실패 사유 표시
- 키보드·마우스 입력 모듈 분리
- 선택형 오프라인 일본어 음성인식 모듈
- 음성 확정 결과·정확한 문구 일치·신뢰도 기준을 사용한 오발동 방지
- 시도 횟수, 성공률, 연속 성공, 해제 타이밍 오차 통계

## 캐릭터 설정 카드

- [고죠 사토루 v1.0](docs/characters/gojo.md): 사용자 검토 완료, 현재 플레이 가능
- [료멘 스쿠나 v1.0](docs/characters/sukuna.md): 이타도리 몸 기준 사용자 검토 완료, 커맨드 구현 중

캐릭터 구현 원칙:

- 몸 형태별 스쿠나는 별도 캐릭터로 추가
- 스쿠나(이타도리): 해·팔·푸가, 복마어주자
- 스쿠나(이타도리): 십종영법술과 세계참 미포함
- 모든 영역전개 캐릭터의 음성은 `료이키 텐카이`까지만 요구
- 실제 발동 영역은 선택 캐릭터와 장인 커맨드로 결정

## 실행 방법

### 1. 저장소 내려받기

```bash
git clone https://github.com/JJuNi27/JJK_game.git
cd JJK_game
```

이미 내려받았다면 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
git pull origin master
```

### 2. 가상환경 만들기

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

PowerShell 실행 정책 때문에 활성화되지 않으면 VS Code 터미널 프로필을 `Command Prompt`로 바꾸고 다음을 실행합니다.

```bat
.venv\Scripts\activate.bat
```

### 3. 패키지 설치

```bash
python -m pip install -r requirements.txt
```

### 4. 일본어 음성 모델 설치

음성인식을 사용할 경우 한 번만 실행합니다.

```bash
python scripts/setup_voice_model.py
```

공식 Vosk 일본어 소형 모델을 `models/vosk-model-small-ja-0.22`에 내려받습니다. 모델은 용량이 커서 GitHub에는 저장하지 않습니다.

기존에 설치한 한국어 모델이 남아 있어도 문제는 없지만, 현재 프로토타입은 일본어 모델을 기본으로 사용합니다.

음성 모델 설치가 실패하거나 마이크가 없어도 프로그램은 종료되지 않으며 `V` 키 입력은 그대로 사용할 수 있습니다.

### 5. 실행

```bash
python main.py
```

## 현재 조작법

```text
캐릭터 선택 화면
1 / ENTER / 고죠 카드 클릭: 고죠 사토루 선택
ESC: 종료

고죠 장인 연습 화면
V 또는 음성 "료이키 텐카이": 영역 준비
우클릭 유지: 장인 준비
우클릭 유지 중 좌클릭: 장인 결합
초록색 구간에서 우클릭 해제: 발동 판정
R: 현재 장인 시도만 초기화
T: 누적 연습 통계 초기화
B: 캐릭터 선택 화면으로 돌아가기
ESC: 종료
```

화면 아래에서 음성인식 준비 여부, 마지막 확정 인식 결과와 신뢰도를 확인할 수 있습니다. 현재 음성 명령 최소 신뢰도는 88%입니다.

현재 음성 발동의 주 문구는 일본어 `領域展開`입니다. 일본어 모델이 출력할 수 있는 한자·히라가나·가타카나 표기를 허용하며, 띄어쓰기를 제거한 전체 문구가 정확히 일치해야 발동합니다.

## 고죠 판정 수치

```text
목표 해제 시점: 0.90초
허용 오차: ±0.22초
```

사용자 1차 테스트에서 10회 중 8회 성공, 평균 해제 오차 0.123초가 기록되어 현재 수치를 유지합니다.

## 스쿠나 양손 커맨드 판정 후보

```text
E 입력 후 양쪽 마우스 버튼 완성 제한: 0.70초
좌·우클릭 누름 동시 인정 간격: 0.18초
목표 유지 시간: 0.85초
유지 시간 허용 오차: ±0.22초
좌·우클릭 해제 동시 인정 간격: 0.18초
```

이 값은 아직 구현·테스트 전인 프로토타입 후보입니다.

## 프로젝트 방향

- 메인 전투 모드: 선택한 캐릭터의 술식과 영역만 사용
- 자유 연습장: 캐릭터 제한 없이 장인 커맨드와 이펙트 연습
- 캐릭터를 추가하기 전 설정 카드를 작성하고 사용자 검토를 받음
- 향후 일반 술식, 영역 충돌, 술식 번아웃 추가
- 웹캠이 생기면 마우스 장인 입력을 실제 손동작 인식 모듈로 교체 가능하게 설계
- 장기적으로 Unity에서 봇과 싸우는 전투 게임으로 확장

## 현재 구조

```text
game/app_scene.py
└─ 캐릭터 선택과 연습 화면의 상위 상태

game/character.py
└─ 캐릭터 프로필과 선택 슬롯 데이터

game_input/
├─ keyboard_domain_trigger.py
│  └─ V 키 영역 준비, R 현재 시도 초기화, T 통계 초기화 요청
├─ voice_domain_trigger.py
│  └─ 일본어 "료이키 텐카이" 감지 후 영역 준비 요청
└─ mouse_seal_input.py
   └─ 고죠 우클릭·좌클릭·해제 장인 입력

game/domain_controller.py
└─ 현재 고죠 장인 상태 전이와 성공/실패 판정

game/practice_stats.py
└─ 시도·성공·실패·연속 성공·타이밍 오차 통계

docs/characters/gojo.md
└─ 고죠 사토루 설정 카드 v1.0

docs/characters/sukuna.md
└─ 스쿠나(이타도리) 설정 카드 v1.0과 양손 커맨드 설계안
```

향후 입력 확장:

```text
DomainIntentTrigger
├─ KeyboardDomainTrigger
└─ VoiceDomainTrigger

SealInput
├─ GojoMouseSealInput
├─ SukunaTwoHandSealInput

```

## 기술 스택

첫 프로토타입은 빠르게 검증하기 위해 **Python + Pygame**을 사용합니다. 음성인식은 **Vosk + sounddevice**와 일본어 소형 모델을 사용하며, 화면·입력·판정·캐릭터 데이터·연습 통계를 단계적으로 분리해 카메라 입력 추가와 Unity 이전이 쉽도록 구성합니다.
