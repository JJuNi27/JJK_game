# JJK Game

주술회전의 **술식 선언, 장인(손동작), 영역전개 연출**을 게임 입력 시스템으로 옮기는 개인 프로젝트입니다.

> 새 ChatGPT 대화나 새로운 개발 환경에서 이어서 작업할 때는 [`docs/HANDOFF.md`](docs/HANDOFF.md)를 먼저 읽어주세요.  
> 구조 기준은 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)에 정리되어 있습니다.

## 현재 목표

Python + Pygame 자유 연습장에서 캐릭터마다 서로 다른 영역전개 입력을 검증하고 있습니다.

현재 플레이 가능:

```text
고죠 사토루
→ 한 손 마우스 타이밍 장인
→ 무량공처

스쿠나(이타도리)
→ E 키 + 마우스 양 버튼 동시 장인
→ 복마어주자

후시구로 메구미
→ Q 키 + 마우스 그림자 궤적 장인
→ 감합암예정

옷코츠 유타(본편 2학년)
→ C 키 반지 연결 + 위쪽 검 뽑기 궤적
→ 진안상애
```

`주술회전 0`의 1학년 유타는 추후 별도 캐릭터로 추가합니다.

장기적으로는 Unity에서 선택한 캐릭터로 봇과 싸우는 전투 게임으로 확장합니다.

## 실행 방법

```bash
git pull origin master
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python main.py
```

처음 음성 모델을 설치하는 경우에만:

```bash
python scripts/setup_voice_model.py
```

음성 모델이나 마이크가 없어도 V 키를 사용할 수 있습니다.

## 공통 조작

```text
V 또는 음성 "료이키 텐카이": 영역 준비
R: 현재 시도 초기화
T: 누적 통계 초기화
B: 캐릭터 선택으로 복귀
ESC: 종료
```

## 캐릭터 선택

선택 화면은 네 캐릭터를 볼 수 있는 2×2 카드 구조입니다.

```text
1 / ENTER / 고죠 카드 클릭: 고죠 사토루
2 / 스쿠나 카드 클릭: 스쿠나(이타도리)
3 / 메구미 카드 클릭: 후시구로 메구미
4 / 유타 카드 클릭: 옷코츠 유타(본편 2학년)
```

## 고죠 · 무량공처

```text
V 또는 "료이키 텐카이"
→ 우클릭 유지
→ 우클릭 유지 중 좌클릭
→ 초록색 구간에서 우클릭 해제
```

```text
목표 해제: 0.90초
허용 오차: ±0.22초
```

사용자 1차 결과:

```text
10회 중 8회 성공
평균 해제 오차 0.123초
```

## 스쿠나(이타도리) · 복마어주자

```text
V 또는 "료이키 텐카이"
→ E 키 누르고 유지
→ E 유지 중 좌·우클릭을 거의 동시에 누르고 유지
→ 초록색 구간에서 좌·우클릭을 거의 동시에 해제
→ 영역 발동 뒤 E 해제
```

```text
E 입력 후 양쪽 마우스 완성 제한: 0.70초
좌·우클릭 누름 동시 인정: 0.18초
목표 유지 시간: 0.85초
유지 시간 허용 오차: ±0.22초
좌·우클릭 해제 동시 인정: 0.18초
```

## 메구미 · 감합암예정

```text
V 또는 "료이키 텐카이"
→ Q 키 누르고 유지
→ 좌클릭을 누른 채 마우스를 아래로 드래그
→ 이어서 왼쪽 또는 오른쪽으로 충분히 펼치기
→ Q를 유지한 채 좌클릭 해제
→ 영역 발동 뒤 Q 해제
```

```text
Q 입력 후 드래그 시작 제한: 0.80초
아래 방향 최소 이동: 130px
아래 방향 좌우 흔들림 허용: 80px
수평 펼침 최소 이동: 180px
수평 구간 상하 흔들림 허용: 100px
전체 궤적 제한시간: 1.80초
```

메구미는 타이밍형이 아니라 방향·거리·궤적 완성도를 판정합니다. 감합암예정은 미완성 영역이며, 전투 구현에서는 실내 또는 기존 구조물이 있을 때만 사용할 계획입니다. 연습장에서는 환경 제한을 적용하지 않습니다.

## 유타 · 진안상애

첫 구현은 **본편 2학년 유타**입니다. `주술회전 0` 버전은 추후 별도 캐릭터로 분리합니다.

```text
V 또는 "료이키 텐카이"
→ C 키를 누르고 반지 연결 유지
→ 화면 아래쪽을 좌클릭
→ 검을 뽑듯 마우스를 위로 드래그
→ C를 유지한 채 좌클릭 해제
→ 영역 발동 뒤 C 해제
```

```text
C 입력 후 드래그 시작 제한: 0.80초
위쪽 최소 이동: 190px
좌우 흔들림 허용: 100px
전체 검 뽑기 제한시간: 1.60초
```

유타도 타이밍형이 아니라 방향·거리·궤적 완성도를 판정합니다. 임시 진안상애 연출에는 십자형 구조물과 여러 검을 표시합니다.

향후 진안상애 전투에서는 다음 정체성을 유지합니다.

```text
필중 복사 술식 1개 선택
+
나머지 복사 술식은 무작위 검에 배정
+
검을 뽑아야 술식 확인
+
한 검은 1회 사용
```

- 모든 영역 음성은 `료이키 텐카이`까지만 요구
- 실제 영역은 선택 캐릭터와 고유 장인 커맨드로 결정
- 공식 설정과 게임 각색을 구분
- 설정 카드 승인 후 캐릭터 구현·해금

## 모듈 구조

모든 구현 캐릭터는 같은 구조를 사용합니다.

```text
characters/<character_id>/
├─ definition.py   # 프로필과 런타임 조립
├─ controller.py   # 상태와 성공·실패 판정
├─ input.py        # 키·마우스 입력 변환
└─ effect.py       # 임시 영역 연출
```

현재:

```text
characters/
├─ gojo/
├─ sukuna_itadori/
├─ megumi/
└─ yuta/
```

`main.py`는 캐릭터별 조건을 알지 않으며, `characters/registry.py`가 카드 순서와 런타임 builder를 연결합니다. 실제 캐릭터 로직은 각 캐릭터 패키지에만 존재합니다.

## 음성인식

- Vosk + sounddevice
- 일본어 소형 모델 `vosk-model-small-ja-0.22`
- 말이 끝난 뒤 확정 결과만 사용
- 전체 문구 정확히 일치
- 평균 신뢰도 88% 이상
- 한자·히라가나·가타카나 표기 허용
