# JJK Game

주술회전의 **장인(손동작), 술식 선언, 영역전개 연출**을 게임 입력 시스템으로 옮기는 개인 프로젝트입니다.

## 현재 목표

첫 MVP는 고죠 사토루의 **무량공처 장인 커맨드 프로토타입**입니다.

1. 고죠 캐릭터 선택
2. `V` 키 또는 추후 음성인식으로 `DOMAIN_READY` 상태 진입
3. 한 손 마우스 장인 입력
   - 우클릭 유지
   - 제한 시간 안에 좌클릭 1회
   - 수렴 타이밍에 우클릭 해제
4. 성공/실패 판정
5. 성공 시 임시 무량공처 이펙트 실행

## 프로젝트 방향

- 메인 전투 모드: 선택한 캐릭터의 술식과 영역만 사용
- 자유 연습장: 캐릭터 제한 없이 장인 커맨드와 이펙트 연습
- 향후 일반 술식, 음성인식, 영역 충돌, 술식 번아웃 추가
- 웹캠이 생기면 마우스 장인 입력을 실제 손동작 인식 모듈로 교체 가능하게 설계

## 입력 모듈 구조

```text
DomainIntentTrigger
├─ KeyboardDomainTrigger
└─ VoiceDomainTrigger        # 추후

SealInput
├─ MouseSealInput
└─ CameraSealInput           # 추후

DomainController
EffectPlayer
```

## 1차 개발 순서

- [ ] 프로젝트 실행 환경 구성
- [ ] 상태 머신 구현 (`NORMAL`, `DOMAIN_READY`, `SEAL_COMPLETED`, `DOMAIN_ACTIVE`, `FAILED`)
- [ ] 마우스 장인 입력 판정
- [ ] 자유 연습장 UI
- [ ] 임시 무량공처 이펙트 연결
- [ ] 음성인식 모듈 추가
- [ ] 카메라 장인 모듈 확장

## 예정 기술 스택

첫 프로토타입은 빠르게 검증하기 위해 **Python + Pygame**을 우선 사용합니다. 입력과 이펙트 모듈을 분리해, 필요할 경우 이후 게임 엔진으로 옮길 수 있도록 구성합니다.
