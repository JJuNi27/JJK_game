# 전투 오디오 설정

## 현재 상태

`PrototypeCombatAudio`가 외부 음원 없이도 실행되도록 창·혁의 시전음과 적중음을 런타임에서 간단한 합성음으로 생성합니다.

현재 연결된 소리:

- Q 술식순전 「창」 시전
- 창이 처음 적중했을 때 수렴 충격음
- E 술식반전 「혁」 시전
- 혁이 처음 적중했을 때 반발 충격음

허식 「자」, 무량공처, 기본 공격, 피격, 승패와 UI 사운드는 다음 오디오 작업 묶음에서 연결합니다.

## 개인 로컬 BGM·대사 덮어쓰기

아래 폴더는 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

```text
unity/Assets/Resources/LocalAudio/
```

폴더가 없다면 직접 생성하고 아래 이름으로 오디오 파일을 넣습니다. Unity가 지원하는 `wav`, `ogg`, `mp3` 등을 사용할 수 있습니다.

```text
BGM.wav 또는 BGM.mp3
Gojo_Blue.wav
Gojo_Red.wav
Gojo_Purple.wav
Gojo_Domain.wav
```

확장자를 제외한 파일 이름이 정확히 일치해야 합니다.

- `BGM`: 전투 시작 시 반복 재생
- `Gojo_Blue`: Q 사용 시 재생되는 대사
- `Gojo_Red`: E 사용 시 재생되는 대사
- `Gojo_Purple`: R용 예약 슬롯
- `Gojo_Domain`: V 영역전개용 예약 슬롯

현재 R과 V의 대사 슬롯은 로딩 구조만 준비되어 있고 실제 발동 이벤트 연결은 아직 남아 있습니다.

## 저장소 원칙

- 저작권이 있는 원본 BGM·성우 음성 파일은 저장소에 커밋하지 않습니다.
- 개인 테스트용 파일은 `LocalAudio`에만 둡니다.
- 배포 가능한 빌드를 만들 때는 직접 제작하거나 정식 사용 허가를 받은 음원으로 교체합니다.
- 코드와 씬은 오디오 파일이 없어도 오류 없이 실행되어야 합니다.
