## 3. 정지 프레임 위주 분석에서 놓친 점

REV1은 한 프레임의 긴 검은 획을 연결된3D 가지로 만들고 뿌리→끝의 성장으로 해석했다. 그러나 연속 표본에서는 넓은 면이 갑자기 생기거나 사라지고, 큰 면과 작은 방전이 서로 다른 리듬으로 바뀐다. 동시에 원본에는 짧은 hold도 있다. 따라서 단순 연속 성장과 매 프레임 무조건 랜덤화 모두 완전한 설명이 아니다.

검은색이 주인공이라는 가설은 지지되지만, 붉은색은 경계뿐 아니라 별도의 발광 방전에도 존재한다. 기존의 가느다란 가지를 모두 없애는 대신 본체 실루엣과 잔여 방전의 역할을 구분해야 한다. 이번 R&D는 이 중 **주 실루엣·시간 변화·각도 가독성**만 비교하며 전체 흑섬을3번 완성하지 않는다.

## 5. 비교 조건과 공정성

타격점은 같은 더미 위치+상단1m, 방향 world +Z, seed71, 공통 nominal지름4m, 카메라 수평 거리6m/높이2m다. 정면0°/측면90°/45°/회전0→180°를 사용했다. 회전1초 동안 후반은 잔류/소멸 상태이므로 모든 각도에서 peak가 보인다는 뜻은 아니며, 정면·측면·45도의 별도 고정 영상이 이를 보완한다.

A는 실제 mesh 외곽을 단위 반경으로 정규화했다. B/C는 투명 quad 크기가 아닌 atlas의 alpha>128 범위를 샘플링해 표시 반경을 맞췄고, C는 곡률·회전·깊이 오프셋도 포함했다. Shader 변형·소거·투영 때문에 **매 프레임 화면상 불투명 픽셀 면적까지 같지는 않다.** 이것은 비교 관찰 대상이며 같은 화면 점유율이라고 주장하지 않는다.

ABC 공통 black RGB(.003,.001,.004), 기존 프로필의 붉은 색, .015초 이후 검은 본체/.30초 본체 상한/.75초 전체 상한을 사용한다. 작은 접촉광과6개 smoke proxy는 공통이다. C는 비교 목적상 추가 깊이 레이어와3D 파편을 가진다. 단순히 B 위에 파편만 얹은 구성은 아니다. A는30Hz 정점 윤곽 변화, B/C는16단계를 .30초에 배치하므로 내부 교체 간격까지 동일하지 않다. C에는 레이어 위상 차이도 있다. 따라서 같은 완성 작화를 세 renderer로 바꾼 엄밀한 성능 실험과는 구분한다.

REV1은 기존 시간/레이어를 보존한 기준이고 QA parent scale만 실제 중심/가지 외곽 기준으로 정규화했다. 실제 전투 profile scale은 변경하지 않았다. REV1의 모든 타이밍을 ABC와 강제로 일치시키지 않았다.

## 7. 영상 평가 — 실제 수행한 것과 남은 것

### 평가 A: 설명 없는 독립 평가

**AI 독립 블라인드 평가는 미실행이다.** 같은 AI가 레퍼런스/알고리즘을 알고 있으므로 결과만 봤다는 자기주장을 만들지 않았다. 사용자용 P/Q/R 영상은 제작 의도 없이 먼저 보고 물질/현상·이동 방향·가장 강한 순간을 기록할 수 있게 제공했다. 다른 평가자에게 전달하거나 메시지를 보내지는 않았다.

### 평가 B: 시간순 전체 프레임과 레퍼런스 비교

정면·회전 전체 프레임을 확인했다. A는 이미 넓어진 검은 면이 갑자기 나타나 형태가 휘거나 교체되고, 후반에 구멍이 생겨 없어진다. 뿌리부터 긴 가지를 키우는 움직임은 줄지만 면 자체가 날개/금속 조각처럼 남는다. B는 넓은 윤곽이 통째로 바뀌어 먹물 도장/방사형 splash에 가깝고, camera-facing 때문에 각도 변화에 따른 부피 반응이 적다. C는 여러 깊이의 경계와 조각이 서로 다른 가림을 만들지만, 인쇄된 면의 교차와 겹침도 보인다.

세 후보 모두 원본의 넓은 찢김·가는 잔류가 섞인 작화와 차이가 크다. B/C의 방사 함수는 아직 꽃/별 모양 규칙성이 있고, A의 붉은 rim은 두꺼운 물체의 가장자리로 읽힐 수 있다. 작은 공통 smoke는 비교를 돕는 proxy 수준이며 원본처럼 풍부한 잔류가 아니다.

**1배속 지각 평가와 0.5배속 실시간 시청 평가는 사용자 대기다.** AI의 세부 분석은 같은 타임라인의 실제 프레임 순서와 메타데이터에 근거한다. 느린 파일의 존재를 실제 연속 시청 완료로 표현하지 않는다. 원속도에서 어느 후보가 주력 파열로 읽히는지에 대한 최종 승인은 없다.

### 판단

이번 R&D로 A/B/C의 장단점을 비교할 근거는 확보했지만 최종 기술 선택은 하지 않는다. C는 깊이 대응을 확인할 수 있고 B는 윤곽 저작성을 확인할 수 있으나, 현재 시제품의 작화·리듬 차이가 커서 하나를 승자로 선언할 근거가 부족하다. 사용자 영상 평가 후에야 제작 방식/추가 작화 필요성을 결정한다. 후속 작업을 자동 시작하지 않는다.
