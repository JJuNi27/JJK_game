# 팬텀 퍼레이드 참고 워크플로

이 문서는 「주술회전 팬텀 퍼레이드」와 GameWith 공략 데이터를 프로젝트 설계에 활용하는 방법을 고정합니다.

## 핵심 원칙

```text
원작 만화·공식 애니
→ 기술 원리, 실제 발동 조건, 시기별 습득 상태의 최우선 기준

팬텀 퍼레이드·GameWith
→ 원작 설정을 게임 시스템, 자원, 상태 변화, 모션과 연출로 번역한 참고자료

우리 프로젝트
→ 실시간 액션에 맞게 다시 설계한 GAME_ORIGINAL 수치와 조작
```

팬텀 퍼레이드의 조건과 수치를 그대로 복사하는 것이 아니라, 해당 캐릭터의 정체성을 어떤 전투 규칙으로 표현했는지 적극적으로 참고합니다.

## 고정 참고 사이트

### GameWith 일본 서버 데이터

- 전체 캐릭터 목록·티어: `https://gamewith.jp/jujutsuphanpara/425595`
- 캐릭터별 상세 페이지에서 다음 항목을 조사합니다.
  - 버전명과 소속·시기
  - 초기·최대 주력
  - 스킬별 소비 주력
  - 스킬 변화 조건
  - 필살기·영역 사용 조건
  - 자동 스킬과 상시 효과
  - 버프·디버프·상태 이상
  - 공격 횟수, 단일·전체 대상, 근접·원격 구분
  - 캐릭터 운용 순서와 핵심 상태 스택

GameWith는 일본 서버 기준이므로 명칭의 최종 출처가 아니라 **상세 전투 데이터와 일본 원문의 확인처**로 사용합니다.

### 글로벌 공식 자료

- 글로벌 공식 사이트: `https://www.jujutsuphanpara.global/`
- 한국어 글로벌 공식 사이트: `https://jujutsuphanpara.biligames.com/h5/ko-KR.html`
- 실제 글로벌 한국어 클라이언트 UI와 사용자가 제공한 스크린샷

글로벌 서버에서 확인 가능한 캐릭터명, 기술명, 상태명, 주력 관련 용어는 이쪽을 우선합니다.

## 명칭 확정 순서

프로젝트에서 화면에 노출되는 이름은 다음 순서로 확정합니다.

1. 글로벌 한국어 클라이언트의 실제 표기
2. 글로벌 공식 한국어 사이트
3. 한국 정식 단행본·애니메이션 자막 등 공식 번역
4. 글로벌 영어 클라이언트·공식 영어 사이트
5. 일본 원문과 GameWith 표기
6. 위 자료에서도 확인되지 않으면 `LOCALIZATION_PENDING`으로 기록하고 임의 번역을 확정하지 않음

일본 GameWith 명칭을 기계 번역한 표현을 글로벌 공식 명칭처럼 사용하지 않습니다.

## 현재 확인 예시 — 각성 고죠

GameWith 각성 고죠 상세 페이지에서 확인 가능한 설계 참고 예시:

- 최대 주력 100
- 스킬 소비가 0 또는 1
- 특정 상태에서 기본 스킬이 술식순전 「창」으로 변화
- 술식반전 「혁」이 주력 1을 소비
- 각성 관련 상태와 스킬 변화
- 특정 상태에서만 허식 「자」 사용 가능
- 무하한 계열 상시 방어·공격 무효화 표현

이 항목들은 현재 프로젝트의 회옥·옥절 각성 후 고죠를 설계할 때 참고하지만, 허식 자의 원작 실제 성립 조건이나 습득 시점은 만화·공식 애니를 우선합니다.

## 코드·문서 적용 규칙

- 내부 코드 ID는 언어에 종속되지 않게 영문 식별자를 사용합니다.
- UI 표시명은 향후 현지화 테이블에서 관리합니다.
- 캐릭터 데이터에는 출처별 명칭과 확인 상태를 기록합니다.
- 팬텀 퍼레이드에 있는 상태 스택을 차용할 때는 원작 근거인지 게임 고유 각색인지 표시합니다.
- 기술의 실루엣, 카메라 구도, 공격 타이밍은 참고할 수 있지만 원본 모델·애니메이션·텍스처·음원 파일은 복사하지 않습니다.
