# 첫 Unity 스쿠나 버전 조사·판단서

작성 기준일: 2026-07-28

이 문서는 두 번째 Unity 플레이 캐릭터로 어떤 스쿠나를 먼저 구현할지 결정한다. 팬텀 퍼레이드의 한 유닛을 그대로 복제하지 않고, 원작의 같은 시기·육체를 기준으로 공식 게임의 전투 번역 방식을 비교한다.

## 결론

```text
첫 내부 ID
SukunaShibuyaYujiBody

캐릭터 / 시기 / 육체
시부야 사변 · 이타도리 유지 육체 · 스쿠나

판정
NOW — 두 번째 캐릭터 프로토타입으로 적합
```

첫 구현을 헤이안 진신, 메구미 육체, 신주쿠 결전 버전으로 시작하지 않는다.

선정 이유:

1. 공식 애니메이션으로 외형·전투·연출 참고 범위가 충분하다.
2. 해·팔이 원거리/근거리 술식 차이를 명확하게 보여준다.
3. 고죠의 육안 효율형과 반대되는 대용량 주력형을 검증할 수 있다.
4. 개/화로는 해·팔 준비 조건을 이용해 기존 기술 연계 구조를 다른 캐릭터에서 검증할 수 있다.
5. 복마어주자는 `DomainSureHit`과 개방형 영역을 통해 현재 피해·무하한 구조를 검증할 수 있다.
6. 모든 요소를 한 번에 구현하지 않고 세 단계로 나누기 쉽다.

## 공식 기준

### OFFICIAL_CONFIRMED

- 스쿠나는 ‘저주의 왕’이며 이 버전은 이타도리 유지의 육체에 수육한 상태다.
- 시부야 사변에서 스쿠나는 영역전개 복마어주자를 사용한다.
- 해와 팔은 스쿠나의 참격 계열 핵심 기술이다.
- 화로/개 계열은 해와 팔의 준비와 연결되는 별도 상위 공격으로 취급한다.
- 영역 밖 화염 운용의 대상 수 제약과 영역 안 광역 운용은 `docs/CANON_SKILL_RULES.md` 기준을 유지한다.

세부 발동 문구나 대상 적중 요구 여부가 구현에 직접 영향을 주면 해당 원작 화와 정식 한국어 번역을 다시 대조한다.

## 팬텀 퍼레이드 비교

### 후보 A — 宿儺「本物の呪術」

GameWith 일본 서버 페이지:

```text
https://gamewith.jp/jujutsuphanpara/479749
```

확인된 특징:

- 이타도리 육체 수육체
- 초기 주력 30~40
- 최대 주력 100~110
- 스킬 1 「分を弁えろ」 소비 0
- 스킬 2 「魅せてみろ」 소비 0
- 스킬 3 「不可視の斬撃」이 현재 주력에 따라 20/40/90을 소비하며 위력 변화
- 필살/영역: 복마어주자
- 영역 사용 시 최대 주력 증가와 대량 회복
- 영역 사용 후 일정 기간 스킬 제한·변화
- 반전술식 회복, 여러 상태 이상 저항 등 다수의 자동 효과

평가:

```text
영역과 스쿠나의 규격 외 운용을 참고하기 좋음
하지만 첫 프로토타입으로는 상태 변화와 자동 효과가 너무 많음
```

따라서 복마어주자와 영역 후 상태의 `ADAPTATION_REFERENCE`로 사용하고, 첫 번째 코드 묶음에서 그대로 구현하지 않는다.

### 후보 B — 両面宿儺「火力勝負」

GameWith 일본 서버 페이지:

```text
https://gamewith.jp/jujutsuphanpara/531833
```

확인된 특징:

- 이타도리 육체 수육체
- 초기 주력 70~95
- 최대 주력 140~160
- 기본 체술 스킬 소비 0
- 「解」 소비 15
- 「解」는 적이 여러 명일 때 전체 2히트, 한 명일 때 단일 4히트로 변화
- 「捌」 소비 45, 단일 근접 7히트
- 필살 「開」는 「解」와 「捌」를 모두 사용하기 전에는 사용 불가
- 회심·반격 때 주력 회복
- 현재 주력량이 많을수록 피해 증가

평가:

```text
원거리 해 / 근거리 팔 / 준비형 화로가 명확함
대용량 주력 캐릭터 정체성을 테스트하기 좋음
실시간 액션 입력으로 번역하기 쉬움
```

첫 전투 세트는 이 버전을 주된 `ADAPTATION_REFERENCE`로 사용한다.

## 글로벌 한국어 명칭 상태

```text
캐릭터: 양면 스쿠나 / 료멘 스쿠나
버전명: [화력 승부] — 공식 글로벌 한국어 클라이언트 캡처 재확인 필요
解: 해 — 정식 한국어 표기 재확인 필요
捌: 팔 — 정식 한국어 표기 재확인 필요
開: 개 / 화로 「열어」 — UI 표기 재확인 필요
伏魔御廚子: 복마어주자
```

GameWith 일본어 표기를 기계 번역해 글로벌 공식 명칭으로 확정하지 않는다. 사용자가 글로벌 한국어 클라이언트의 해당 캐릭터 화면을 제공하거나 공식 자료에서 확인될 때까지 카드 부제와 세부 스킬 표기는 `LOCALIZATION_PENDING`이다.

코드 내부 영문 ID는 다음처럼 사용한다.

```text
Dismantle
Cleave
FurnaceOpen
MalevolentShrine
```

## 주력 설계 판단

기존 `SukunaVastReserve = 300`은 조사 전 임시 출발값이었다.

첫 플레이 테스트에서는 다음이 더 적합하다.

```text
최대 주력: 160
시작 주력: 95
기본 회복: 낮거나 조건부
Q 해: 15
E 팔: 45
R 화로: 별도 고비용 또는 준비 조건
V 복마어주자: 후속 단계에서 확정
```

이유:

- 고죠는 최대 100이지만 모든 기술을 1만 소비하는 효율형이다.
- 스쿠나는 고죠보다 주력통이 크지만 기술 비용도 큰 대용량형이어야 한다.
- 최대 300부터 시작하면 Q 15/E 45의 선택 압박이 약해져 첫 테스트에서 자원 시스템의 의미가 줄어든다.
- 160은 팬텀 퍼레이드 수치와 직접 비교하기 쉬운 첫 밸런스 값이다.

`GAME_ORIGINAL` 테스트 뒤 180/200/300으로 올릴 수 있다.

## 단계별 구현 범위

### Milestone 1 — 다음 코드 묶음 `NOW`

```text
플레이어 전환을 위한 최소 프로토타입 경로
스쿠나 전용 주력 프로필: 160 / 시작 95
LMB: 3단 체술
Q: 해
- 원거리 참격
- 적이 2명 이상이면 넓은 다중 대상형
- 적이 1명이면 집중 단일 대상형
- 소비 15

E: 팔
- 짧은 근거리
- 높은 단일 피해와 다중 히트 표현
- 소비 45

해/팔 사용 상태 기록
```

이번 단계에서는 화로와 영역을 발동시키지 않는다. 먼저 캐릭터 전환, 주력, 해·팔과 기존 피해 구조가 정상인지 검증한다.

### Milestone 2 — 해·팔 확인 뒤 `NOW 후보`

```text
R: 화로 「열어」
- 해와 팔을 모두 사용해야 준비
- 영역 밖에서는 살아 있는 적이 한 명일 때만 사용 가능
- 다중 적 상태에서는 이유를 HUD로 표시
- 화염·폭발 DamageContext 추가
```

팬텀 퍼레이드의 ‘해·팔 모두 사용’ 조건은 좋은 전투게임 번역이지만, 원작 밑준비 문구가 사용인지 적중인지 구현 직전에 다시 확인한다.

### Milestone 3 — 화로 확인 뒤 `NOW 후보`

```text
V: 복마어주자
- 개방형 영역
- 장벽으로 공간을 완전히 닫지 않음
- 영역 내 반복 참격
- DomainSureHit 전달 방식 사용
- 무하한 우회 구조와 연결
- 영역 안 화로의 광역형 전환은 별도 테스트
```
