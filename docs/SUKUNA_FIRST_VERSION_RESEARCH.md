# 첫 Unity 스쿠나 버전 조사·판단서

작성 기준일: 2026-07-28

이 문서는 두 번째 Unity 플레이 캐릭터로 어떤 스쿠나를 먼저 구현할지 결정하고, 단계별 구현 범위를 기록한다. 팬텀 퍼레이드의 한 유닛을 그대로 복제하지 않고 원작의 같은 시기·육체를 기준으로 공식 게임의 전투 번역 방식을 비교한다.

## 결론

```text
내부 ID: SukunaShibuyaYujiBody
캐릭터 / 시기 / 육체: 시부야 사변 · 이타도리 유지 육체 · 스쿠나
판정: NOW — 두 번째 캐릭터 프로토타입
```

첫 구현을 헤이안 진신, 메구미 육체, 신주쿠 결전 버전으로 시작하지 않는다.

선정 이유:

1. 공식 애니메이션으로 외형·전투·연출 참고 범위가 충분하다.
2. 해·팔이 원거리/근거리 술식 차이를 명확하게 보여준다.
3. 고죠의 육안 효율형과 반대되는 대용량 주력형을 검증할 수 있다.
4. 푸가는 해·팔 준비 조건을 이용해 기술 연계 구조를 두 번째 캐릭터에서 검증한다.
5. 복마어주자는 `DomainSureHit`과 개방형 영역으로 현재 피해·무하한 구조를 검증할 수 있다.
6. 해·팔 → 푸가 → 복마어주자의 세 단계로 나누기 쉽다.

## 공식 기준

### OFFICIAL_CONFIRMED

- 스쿠나는 ‘저주의 왕’이며 이 버전은 이타도리 유지의 육체에 수육한 상태다.
- 시부야 사변에서 영역전개 복마어주자를 사용한다.
- 해와 팔은 스쿠나의 참격 계열 핵심 기술이다.
- 화염 계열 상위 공격은 해와 팔의 준비와 연결되는 별도 상위 공격으로 취급한다.
- 영역 밖 화염 운용의 대상 수 제약과 영역 안 광역 운용은 `docs/CANON_SKILL_RULES.md` 기준을 유지한다.

세부 발동 문구나 대상 적중 요구 여부가 구현에 직접 영향을 주면 해당 원작 화와 정식 한국어 번역을 다시 대조한다.

## 팬텀 퍼레이드 비교

### 후보 A — 宿儺「本物の呪術」

GameWith 일본 서버 페이지:

```text
https://gamewith.jp/jujutsuphanpara/479749
```

확인된 특징:

- 이타도리 육체 수육체
- 초기 주력 30~40
- 최대 주력 100~110
- 앞의 두 스킬 소비 0
- 강한 참격이 현재 주력에 따라 20/40/90을 소비하며 위력 변화
- 필살/영역: 복마어주자
- 영역 사용 시 최대 주력 증가와 대량 회복
- 영역 사용 후 일정 기간 스킬 제한·변화
- 반전술식 회복과 여러 자동 저항

평가:

```text
복마어주자와 영역 후 상태 참고에 적합
첫 프로토타입으로는 상태 변화와 자동 효과가 과도함
```

### 후보 B — 両面宿儺「火力勝負」

GameWith 일본 서버 페이지:

```text
https://gamewith.jp/jujutsuphanpara/531833
```

확인된 특징:

- 이타도리 육체 수육체
- 초기 주력 70~95
- 최대 주력 140~160
- 기본 체술 소비 0
- 해 소비 15
- 해는 적이 여러 명일 때 전체 2히트, 한 명일 때 단일 4히트
- 팔 소비 45, 단일 근접 7히트
- 상위 화염 기술은 해와 팔을 모두 사용하기 전에는 사용 불가
- 회심·반격 때 주력 회복
- 현재 주력량이 많을수록 피해 증가

평가:

```text
원거리 해 / 근거리 팔 / 준비형 푸가가 명확함
대용량 주력 캐릭터 정체성을 테스트하기 좋음
실시간 액션 입력으로 번역하기 쉬움
```

첫 전투 세트는 이 버전을 주된 `ADAPTATION_REFERENCE`로 사용한다.

## 글로벌 한국어 명칭 상태

```text
캐릭터: 양면 스쿠나 / 료멘 스쿠나 — 카드 표기 재확인 대기
버전명: [화력 승부] — 글로벌 한국어 클라이언트 재확인 대기
解: 해 — 사용자 검토 중
捌: 팔 — 사용자 검토 중
상위 화염 기술: 푸가 — USER_VERIFIED_GLOBAL_KO
伏魔御廚子: 복마어주자
```

사용자가 실제 글로벌 한국어 클라이언트 기준으로 R 표시명을 `푸가`라고 검수했다. 프로젝트 UI는 이를 우선한다.

```text
내부 코드 ID
Dismantle
Cleave
Fuga
MalevolentShrine
```

`화로`는 기술 계열과 원리를 설명하는 문맥에서만 사용하며 UI 공식명처럼 표시하지 않는다.

## 주력 설계 판단

첫 플레이 테스트:

```text
최대 주력: 160
시작 주력: 95
기본 회복: 초당 4
사용 후 회복 지연: 1.2초
Q 해: 15
E 팔: 45
R 푸가: 35
V 복마어주자: Milestone 3에서 확정
```

- 고죠는 최대 100이지만 모든 기술을 1만 소비하는 효율형이다.
- 스쿠나는 고죠보다 주력통이 크지만 기술 비용도 큰 대용량형이다.
- 최대 300부터 시작하면 해 15/팔 45의 선택 압박이 약해진다.
- 푸가 35는 시작 주력 95에서 해 15 + 팔 45 + 푸가 35가 정확히 한 사이클이 되도록 정한 `GAME_ORIGINAL` 테스트 값이다.
- 주력 자동 회복 때문에 실제 발동 시 잔여량은 사용 시간에 따라 달라질 수 있다.

## 단계별 구현 범위

### Milestone 1 — 사용자 확인 완료

```text
1 키: 현대 고죠로 전환 후 장면 재시작
2 키: 시부야 스쿠나로 전환 후 장면 재시작

스쿠나 주력: 최대 160 / 시작 95
LMB: 기존 3단 체술 재사용

Q 해
- 원거리 참격
- 살아 있는 적이 2명 이상이면 넓은 다중 대상 2히트
- 적이 1명이면 집중 단일 대상 4히트
- 소비 15

E 팔
- 짧은 근거리
- 단일 대상 7히트
- 소비 45
- 마지막 타격에 강화 넉백·경직

해/팔 사용 상태 기록
```

사용자가 캐릭터 전환, 주력, 해·팔, 고죠 복귀를 정상 확인했다.

### Milestone 2 — 원격 구현 완료, 사용자 테스트 필요

```text
R: 푸가
- 해와 팔을 모두 사용해야 준비
- 준비는 적중이 아니라 사용 여부로 기록
- 영역 밖에서는 살아 있는 적이 정확히 한 명일 때만 사용 가능
- 적이 두 명 이상이면 HUD에 차단 이유 표시
- 대상이 약 24m 밖이면 발동 차단
- 소비 35
- 약 0.52초 준비 뒤 추적 화염 발사체 생성
- 단일 대상 78 피해
- 폭발 반경 약 4.5m는 시각 효과·접촉 판정용이며 영역 밖 피해 대상은 지정된 한 명으로 제한
- 성공 발동 뒤 해·팔 준비 상태 소모
- 쿨타임 약 11초
- `DamageContext.CursedTechnique`
```

현재 V 복마어주자는 계속 잠금 상태다. 영역 밖 푸가가 정상 확인되기 전에는 영역 안 광역 푸가를 섞지 않는다.

### Milestone 3 — 푸가 확인 뒤 NOW 후보

```text
V: 복마어주자
- 개방형 영역
- 장벽으로 공간을 완전히 닫지 않음
- 영역 내 반복 참격
- DomainSureHit 전달 방식
- 무하한 우회 구조와 연결
- 영역 안 푸가의 광역 전환은 별도 테스트
```

### LATER

```text
반전술식 자동 회복
독·기절·혼 관련 다중 저항
영역 후 스킬 변화
주력 20/40/90 가변 소비 참격
회심·반격 기반 자동 주력 회복
메구미 육체 스쿠나와 십종영법
헤이안 진신
세계참
```

## 현재 구현 판단

```text
첫 캐릭터 버전 선택: 완료
Milestone 1: 사용자 확인 완료
Milestone 2 푸가: 원격 구현 완료, 사용자 테스트 필요
Milestone 3 복마어주자: 잠금 유지
거대한 범용 캐릭터 시스템: 만들지 않음
```

고죠와 스쿠나 두 캐릭터에서 반복되는 부분이 실제로 확인된 뒤에만 추가 공통 인터페이스를 추출한다.
