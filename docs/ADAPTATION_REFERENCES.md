# 공식 게임·애니 연출 참고 규칙

## 역할 구분

프로젝트는 참고 자료를 다음 우선순위로 구분한다.

1. `OFFICIAL_CONFIRMED`
   - 만화 본편, 단행본 부록, 공식 팬북, 공식 애니메이션·극장판
   - 기술의 실제 발동 조건, 제한, 능력 원리의 최우선 기준
2. `ADAPTATION_REFERENCE`
   - 공식 라이선스 게임인 「주술회전 팬텀 퍼레이드」 등
   - 원작을 전투게임 조작, 자원, 모션, 카메라, VFX, 사운드로 번역하는 방법 참고
3. `GAME_ORIGINAL`
   - 이 프로젝트의 실시간 액션 조작감과 밸런스를 위해 추가한 수치와 규칙

공식 게임의 수치나 연출을 그대로 복제하지 않는다. 원작과 충돌하면 원작을 우선하며, 원본 자산을 가져오는 대신 동작 구조와 표현 방식을 참고한다.

## 팬텀 퍼레이드 활용 범위

캐릭터와 버전을 구현하기 전 다음 항목을 조사한다.

- 해당 캐릭터가 어느 시기·육체·상태의 버전인지
- 기본 공격과 술식의 준비 동작, 타격 시점과 후딜레이
- 술식별 실루엣, 이동 방향과 범위 전달 방식
- 카메라 컷, 흔들림, 플래시와 타격 정지의 강약
- 대사 시작 시점, 효과음 중첩 순서와 BGM 전환
- 초기·최대 주력과 소비 효율
- 영역전개와 필살기의 UI 전달 방식

## 고죠 버전 참고 기준

팬텀 퍼레이드처럼 같은 인물을 시기와 전투 상태에 따라 별도 유닛으로 다루는 방식을 참고한다.

```text
HiddenInventoryPreAwakening
- 회옥·옥절 각성 전
- 둥근 선글라스와 학생 고전복
- 스킬 구성은 구현 전에 별도 원작 검토

HiddenInventoryAwakened
- 회옥·옥절 각성 후
- 각성 전과 습득 기술·운용을 분리

ModernTeacher
- 현대 일반 고죠
- 안대와 검은 고전복
- 현재 Unity 프로토타입 기본 버전

ShinjukuShowdown
- 신주쿠 결전 고죠
- 눈을 드러낸 외형
- 영역 번아웃 강제 회복 같은 고급 운용 후보
```

한 버전의 전용 운용을 다른 버전에 자동으로 넣지 않는다.

## 현재 주력 프로필 기준

### 고죠 사토루 — `SixEyesEfficiency`

- 원작 핵심: 육안에 의한 정밀한 주력 조작과 거의 0에 가까운 손실
- 팬텀 퍼레이드 참고: 고죠 커맨드 스킬이 0~1 또는 전부 1 소비로 표현되는 사례
- 현재 번역: 최대 주력 100, Q/E/R/V 실제 소비 각각 1
- 주력 고갈보다 쿨타임, 시전 위험과 술식 번아웃으로 제한

### 료멘 스쿠나 — `SukunaVastReserve` 예정

- 핵심 정체성: 매우 큰 주력 총량
- 최대 주력 300 대용량형을 출발점으로 준비
- 최종 수치와 회복은 스쿠나 전투 구현 때 다시 비교

### 옷코츠 유타 — `YutaLargeReserve` 예정

- 핵심 정체성: 고죠보다 큰 주력 총량을 가진 대용량형
- 팬텀 퍼레이드 참고 사례: 최대 주력 150으로 표현된 유타 버전
- 최대 주력 150을 출발점으로 준비
- 리카 완전현현과 상태 변화의 자원 변화를 별도 구현

## 3D 모델·애니메이션 제작 경로

현재 단계:

- 외부 캐릭터 자산 없이 런타임 Primitive로 흰 머리·안대·검은 복장의 로우폴리 고죠 프록시를 생성
- 플레이 캡슐의 충돌·이동 구조는 유지하고 표시용 Renderer만 숨김
- 버전에 따라 선글라스·안대·눈 노출 외형을 바꿀 수 있는 기반 준비

최종 모델 권장 경로:

```text
VRoid Studio 또는 Blender로 프로젝트용 인체 모델 제작
→ VRM/FBX로 내보내기
→ Unity에 가져오기
→ Mixamo 또는 직접 제작한 Humanoid 애니메이션으로 리깅·리타기팅
→ 팬텀 퍼레이드와 애니를 참고해 공격 타이밍·카메라·VFX를 새로 제작
```

외부 모델 사용 시:

- Unity Asset Store는 상품별 표준/비표준 EULA를 확인한다.
- Sketchfab은 CC BY, NC, ND, SA 또는 스토어 라이선스를 개별 확인하고 필요한 저작자 표시를 남긴다.
- 다운로드 가능한 ‘고죠’ 팬 모델이라도 원작 캐릭터 권리까지 허가된 것은 아니므로 저장소 기준 모델로 바로 채택하지 않는다.

## 저작권·자산 원칙

- 원본 게임의 모델, 애니메이션, 텍스처, 음원과 보이스 파일을 저장소에 복사하지 않는다.
- 개인 로컬 테스트 음원은 `unity/Assets/Resources/LocalAudio/`에서만 사용한다.
- 모션과 VFX는 타이밍·구도·가독성을 참고해 프로젝트용으로 새로 제작한다.
