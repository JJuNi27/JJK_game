# 공식 게임·애니 연출 참고 규칙

## 역할 구분

프로젝트는 참고 자료를 다음 우선순위로 구분한다.

1. `OFFICIAL_CONFIRMED`
   - 만화 본편, 단행본 부록, 공식 팬북, 공식 애니메이션·극장판
   - 기술의 실제 발동 조건, 제한, 능력 원리의 최우선 기준
2. `ADAPTATION_REFERENCE`
   - 공식 라이선스 게임인 「주술회전 팬텀 퍼레이드」 등
   - 원작 설정을 전투게임 조작, 자원, 모션, 카메라, VFX, 사운드로 번역하는 방법을 참고
3. `GAME_ORIGINAL`
   - 이 프로젝트의 실시간 액션 조작감과 밸런스를 위해 추가한 수치와 규칙

공식 게임의 수치나 연출을 그대로 복제하지 않는다. 원작과 충돌하는 경우 원작을 우선하며, 자산 파일을 가져오는 대신 동작의 구조와 표현 방식을 참고한다.

## 팬텀 퍼레이드 활용 범위

다음 항목을 캐릭터 구현 전 조사한다.

- 기본 공격과 술식의 준비 동작, 타격 타이밍, 후딜레이
- 창·혁·허식 자처럼 기술마다 구분되는 실루엣과 이동 방향
- 카메라 컷, 화면 흔들림, 플래시, 타격 정지의 강약
- 대사 시작 시점, 효과음이 겹치는 순서, BGM 전환 타이밍
- 캐릭터별 초기 주력, 최대 주력, 소비 효율의 차이
- 영역전개와 필살기의 UI 전달 방식

## 현재 주력 프로필 기준

### 고죠 사토루 — `SixEyesEfficiency`

- 원작 핵심: 육안에 의한 극도로 정밀한 주력 조작과 거의 0에 가까운 손실
- 팬텀 퍼레이드 참고: 고죠의 커맨드 스킬이 0~1 또는 전부 1 소비로 표현되는 사례
- 현재 게임 번역: 최대 주력은 100으로 유지하되 Q/E/R/V 실제 소비를 각각 1로 보정
- 주력 고갈보다 술식 번아웃, 쿨타임, 시전 위험으로 제한을 표현

### 료멘 스쿠나 — `SukunaVastReserve` 예정

- 핵심 정체성: 매우 큰 주력 총량
- 예정 프로필: 최대 주력 300의 대용량형 출발점
- 최종 수치와 회복은 스쿠나 전투 구현 때 원작과 공식 게임을 다시 비교

### 옷코츠 유타 — `YutaLargeReserve` 예정

- 핵심 정체성: 고죠보다 큰 주력 총량을 가진 대용량형
- 팬텀 퍼레이드 참고 사례: 최대 주력 150으로 표현된 유타 버전
- 예정 프로필: 최대 주력 150의 대용량형 출발점
- 리카 완전현현과 상태 변화에 따른 자원 변화를 별도 시스템으로 구현

## 저작권·자산 원칙

- 원본 게임의 모델, 애니메이션, 텍스처, 음원, 보이스 파일을 저장소에 복사하지 않는다.
- 개인 로컬 테스트 음원은 `unity/Assets/Resources/LocalAudio/`에서만 사용한다.
- 모션과 VFX는 타이밍·구도·가독성을 참고해 프로젝트용으로 새로 제작한다.
