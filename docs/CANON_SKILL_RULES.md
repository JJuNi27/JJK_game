# 원작 우선 스킬 구현 규칙

이 문서는 캐릭터 기술을 구현할 때 원작 설정, 팬텀 퍼레이드의 게임식 번역과 프로젝트 고유 규칙을 섞지 않기 위한 기준입니다.

## 표기

- `OFFICIAL_CONFIRMED`: 만화, 단행본 부록, 공식 팬북, 공식 애니메이션·영화·사이트에서 확인되는 규칙
- `ADAPTATION_REFERENCE`: 팬텀 퍼레이드처럼 공식 라이선스 게임이 원작을 전투게임으로 번역한 사례
- `GAME_ORIGINAL`: 조작감·밸런스·UI를 위해 프로젝트에서 추가한 규칙
- `INTERPRETATION_PENDING`: 원작 문구의 해석이나 추가 대조가 필요한 규칙
- `LOCALIZATION_PENDING`: 글로벌 한국어 공식 표기를 아직 확인하지 못한 명칭
- `USER_VERIFIED_GLOBAL_KO`: 사용자가 실제 글로벌 한국어 클라이언트 기준으로 검수한 명칭

기술 조건은 `OFFICIAL_CONFIRMED`를 우선합니다. 팬텀 퍼레이드는 모션·자원·상태·VFX·사운드의 번역 참고자료이며 원작과 충돌하면 원작을 따릅니다.

## 공통 주력 자원

`GAME_ORIGINAL`

- 화면 주력 게이지, 자동 회복과 회복 지연은 프로토타입 수치입니다.
- 실제 소비는 캐릭터 프로필을 거칩니다.

현재 프로필:

```text
SixEyesEfficiency
- 현대 고죠
- 최대 100
- Q/E/R/V 실제 소비 각각 1

SukunaShibuyaReserve
- 시부야 이타도리 육체 스쿠나
- 최대 160 / 시작 95
- 낮은 자동 회복

SukunaVastReserve
- 미래 스쿠나 버전 검토용 최대 300 임시 프로필

YutaLargeReserve
- 유타 최대 150 출발점

Standard
- 일반형 최대 100
```

## 공통 피해와 방어 판정

피해량과 방어 우회 이유를 분리합니다. 단순히 공격력이 높다는 이유로 무하한을 통과하지 않습니다.

```text
DamageDeliveryType
Unspecified
PhysicalStrike
CursedTechnique
DomainSureHit
Environmental

DamageTraits
DomainAmplification
TechniqueNullification
IgnoresInfinity
Unblockable
```

`OFFICIAL_CONFIRMED`

- 완성된 영역의 필중 효과는 무하한에 도달할 수 있습니다.
- 영역전연은 접촉하는 술식을 중화해 무하한에 대응할 수 있습니다.
- 술식 무효화 수단은 별도 우회 사유입니다.

`GAME_ORIGINAL`

- `Health`는 회피 무적 뒤 활성화된 `IDamageGuard`를 검사합니다.
- 비활성화된 캐릭터의 방어 컴포넌트는 판정에 참여하지 않습니다.
- 신규 공격은 `DamageContext`를 사용합니다.
- `DomainSureHit`도 현재 프로토타입에서는 회피 무적 판정을 먼저 거칩니다. 이는 실시간 액션 게임용 규칙이며 원작의 필중 원리를 그대로 뜻하지 않습니다.

## 같은 인물의 시기별 버전

같은 인물도 시기·육체·습득 기술·속박·경험이 다르면 별도 플레이 버전으로 분리합니다.

### 고죠

```text
HiddenInventoryPreAwakening  회옥·옥절 각성 전
HiddenInventoryAwakened     회옥·옥절 각성 후
ModernTeacher               현대 일반 고죠
ShinjukuShowdown            신주쿠 결전 고죠
```

현재 고죠 기본값은 `ModernTeacher`입니다.

### 스쿠나

```text
SukunaShibuyaYujiBody
- 시부야 사변
- 이타도리 유지 육체
- 첫 Unity 스쿠나 프로토타입

MegumiBody / HeianTrueForm / Shinjuku
- 별도 미래 버전
```

## 고죠 사토루

### 육안과 주력 효율

`OFFICIAL_CONFIRMED`

- 육안은 정밀한 주력 조작을 가능하게 하며 술식 발동 손실을 한없이 0에 가깝게 만듭니다.
- 고죠의 자원 정체성은 큰 주력통보다 소비 효율입니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드에서 고죠의 커맨드 스킬은 0~1 또는 모두 1 소비로 표현되는 사례가 있습니다.

`GAME_ORIGINAL`

- 현재 고죠는 `SixEyesEfficiency`를 사용합니다.
- 주력 고갈보다 쿨타임, 시전 위험과 영역 후 번아웃으로 제한합니다.

### 무하한 자동 방어

`OFFICIAL_CONFIRMED`

- 현대 고죠는 무하한을 자동 운용해 위협을 자신에게 도달하기 전에 정지시킵니다.
- 일반 물리 타격과 일반 술식은 강하다는 이유만으로 통과하지 않습니다.
- 영역 필중, 영역전연, 술식 무효화는 별도 우회 판정입니다.

`GAME_ORIGINAL`

- `ModernTeacher`와 미래 `ShinjukuShowdown`에 자동 방어를 적용합니다.
- 차단 시 `INFINITY · BLOCKED`, 우회 시 `INFINITY BYPASSED`와 사유를 표시합니다.

### 술식순전 「창」

`OFFICIAL_CONFIRMED`

- 수렴·인력 성질을 이용해 대상을 끌어당깁니다.

`GAME_ORIGINAL`

- Q로 락온 대상 근처 또는 전방에 지속 수렴장을 생성합니다.
- 대상별 피해는 한 번이며 인력은 반복 적용합니다.

### 술식반전 「혁」

`OFFICIAL_CONFIRMED`

- 술식반전으로 발생하는 발산·반발력 계열 기술입니다.

`GAME_ORIGINAL`

- E로 이동하는 전방 발사체를 생성합니다.
- 경로의 여러 적을 관통하고 발사 방향으로 밀어냅니다.

### 허식 「자」

`OFFICIAL_CONFIRMED`

- 창의 수렴과 혁의 발산을 충돌시켜 성립합니다.
- 상대에게 창과 혁을 먼저 적중시켜야 하는 조건은 없습니다.

`GAME_ORIGINAL`

- Q와 E를 각각 사용하면 준비 상태가 생깁니다.
- 제한시간 안에 두 상태가 함께 있으면 R로 발동합니다.
- 창→혁 적중 추가 피해는 별도 게임용 연계입니다.

### 무량공처와 술식 번아웃

`OFFICIAL_CONFIRMED`

- 영역전개 뒤에는 생득술식 번아웃이 발생합니다.
- 번아웃된 술식을 반전술식으로 강제 회복하는 운용은 신주쿠 결전 버전으로 분리합니다.

`GAME_ORIGINAL`

- 현재 V 장인 입력, 영역 지속시간·범위와 행동 불능은 프로토타입 규칙입니다.
- 종료 후 약 5초 동안 Q/E/R/V를 봉인합니다.
- 현대 일반 고죠는 시간 경과로만 회복합니다.

## 시부야 사변 스쿠나

상세 조사: `docs/SUKUNA_FIRST_VERSION_RESEARCH.md`

### 주력 정체성

`OFFICIAL_CONFIRMED`

- 스쿠나는 큰 주력 총량을 가진 대용량형으로 고죠의 육안 효율형과 구분합니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드 `[화력 승부]` 스쿠나는 최대 주력 160, 해 15, 팔 45의 큰 통·큰 소비 구조를 보여줍니다.

`GAME_ORIGINAL`

- 첫 테스트는 `SukunaShibuyaReserve`: 최대 160, 시작 95, 초당 회복 4입니다.

### Q · 해

`ADAPTATION_REFERENCE`

- 적이 여러 명일 때 전체 2히트, 한 명일 때 단일 4히트로 변화하는 구성을 참고합니다.

`GAME_ORIGINAL`

- 적 한 명이면 락온 우선 집중 4히트입니다.
- 살아 있는 적이 두 명 이상이면 전방 넓은 판정의 대상에게 2히트입니다.
- 소비 15, 쿨타임과 피해량은 테스트 수치입니다.

### E · 팔

`ADAPTATION_REFERENCE`

- 단일 근거리 7히트와 소비 45 구성을 참고합니다.

`GAME_ORIGINAL`

- 약 3.4m 안의 락온 또는 가장 가까운 적을 7회 타격합니다.
- 마지막 타격에 강화 넉백과 경직을 적용합니다.
- 빗나가도 사용·소비·준비 상태는 기록합니다.

### R · 푸가

`USER_VERIFIED_GLOBAL_KO`

- 글로벌 한국어 UI 표시명은 `푸가`입니다.
- 내부 코드 ID는 `Fuga`입니다.
- `화로`는 기술 계열을 설명할 때만 사용합니다.

`OFFICIAL_CONFIRMED`

- 해와 팔의 밑준비와 연결되는 상위 화염 공격입니다.
- 영역 밖에서는 다수 상대를 대상으로 사용할 수 없는 제약을 반영합니다.
- 복마어주자 안에서는 광역형 운용이 가능합니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드에서는 해와 팔을 모두 사용해야 준비되는 구조가 사용됩니다.

`GAME_ORIGINAL`

- 해·팔 사용 뒤 영역 밖 살아 있는 적이 한 명일 때 R로 발동합니다.
- 현재 주력 35, 준비 0.52초, 최대 추적 거리 약 24m, 피해 78과 쿨타임 11초는 조정 가능한 테스트 값입니다.
- 거리 제한은 원작 발동 조건으로 취급하지 않습니다.
- 영역 밖 폭발은 시각적으로 넓어도 지정된 한 대상에게만 피해를 적용합니다.

`INTERPRETATION_PENDING`

- 원작의 밑준비를 단순 사용으로 볼지 실제 적중까지 요구할지는 추가 대조합니다.

### V · 복마어주자

`OFFICIAL_CONFIRMED`

- 장벽으로 공간을 완전히 닫지 않는 개방형 영역입니다.
- 상대에게 퇴로를 제공하는 속박과 넓은 범위를 가진 운용으로 일반 장벽형 영역과 구분됩니다.
- 영역 안의 대상에게 참격이 계속 적용됩니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드의 `본물의 주술` 스쿠나는 복마어주자를 적 전체 8히트 공격으로 표현합니다.
- 영역 상태에 필중과 공격 무효화 중화를 부여하고, 사용 후 최대 주력 증가·회복과 스킬 변화도 제공합니다.
- 이 프로젝트는 해당 턴제 버프 전체를 복제하지 않고 반복 필중 참격 표현만 우선 참고합니다.

`GAME_ORIGINAL`

- 현재 V를 누르면 약 0.65초 준비 후 직접 전개합니다. 이 입력은 향후 Python 장인·음성 인식 연결 전까지의 임시 입력입니다.
- 장벽 벽이나 밀폐 구체를 생성하지 않고, 고정된 중심 사당과 지면 범위선만 표시합니다.
- 현재 반경 약 30m, 지속 약 3.2초, 주력 80, 쿨타임 18초입니다.
- 범위 안 살아 있는 적 모두에게 8회, 회당 12의 `DomainSureHit` 참격을 전달합니다.
- `DomainSureHit`은 기존 무하한 우회 구조와 연결됩니다.
- 영역 중 Q/E/R, 기본 공격과 새 회피는 잠기며 이동은 가능합니다.
- 영역 안 푸가 광역 전환, 영역 후 최대 주력 증가·회복과 스킬 변화는 이번 단계에 포함하지 않습니다.
- 원작의 약 200m 범위를 현재 작은 테스트 맵의 30m와 동일시하지 않습니다.

## 옷코츠 유타

`OFFICIAL_CONFIRMED`

- 유타는 큰 주력 총량을 가진 캐릭터입니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드의 일부 유타는 최대 주력 150으로 표현됩니다.

`GAME_ORIGINAL` 예정

- `YutaLargeReserve` 최대 150을 출발점으로 사용합니다.
- 리카 완전현현과 복사 술식의 상태별 자원 변화는 유타 구현 때 설계합니다.

## 작업 절차

1. 원작 등장 시점과 습득 상태를 확인합니다.
2. 캐릭터의 시기·육체 버전을 결정합니다.
3. 발동 조건, 제한, 대상 수와 영역 상호작용을 기록합니다.
4. 팬텀 퍼레이드·GameWith에서 자원·모션·VFX·사운드 번역을 확인합니다.
5. 글로벌 한국어 명칭을 검수합니다.
6. 원작 조건과 게임용 수치를 독립적으로 구현합니다.
7. 작업 뒤 인수인계 문서를 갱신합니다.
