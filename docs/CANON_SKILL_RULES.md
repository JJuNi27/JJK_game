# 원작 우선 스킬 구현 규칙

이 문서는 캐릭터 기술을 구현할 때 원작 설정과 게임용 각색을 섞지 않기 위한 기준입니다.

## 표기

- `OFFICIAL_CONFIRMED`: 만화 본편, 단행본 부록, 공식 팬북, 공식 애니메이션·영화·공식 사이트에서 직접 확인되는 규칙
- `ADAPTATION_REFERENCE`: 「주술회전 팬텀 퍼레이드」처럼 공식 라이선스 게임이 원작을 전투게임으로 번역한 사례
- `GAME_ORIGINAL`: 조작감, 밸런스, UI를 위해 이 프로젝트에서 추가한 규칙
- `INTERPRETATION_PENDING`: 원작 문구의 해석이 갈리거나 추가 확인이 필요한 규칙

기술 조건은 `OFFICIAL_CONFIRMED`를 먼저 코드 구조에 반영합니다. 공식 게임은 모션·자원·VFX·사운드의 번역 참고자료로 활용하지만 원작과 충돌하면 원작을 우선합니다. 세부 참고 정책은 `docs/ADAPTATION_REFERENCES.md`와 `docs/PHANTOM_PARADE_REFERENCE.md`를 따릅니다.

## 공통 주력 자원

`GAME_ORIGINAL`

- 화면 주력 게이지, 자동 회복과 회복 지연은 전투 프로토타입용 수치입니다.
- 기술별 기본 소비량은 캐릭터 간 비교용 내부 값입니다.
- 실제 소비는 캐릭터 주력 프로필의 최대치와 효율 보정을 거쳐 결정됩니다.

현재 프로필:

- `SixEyesEfficiency`: 고죠 효율형. 기본 소비를 기술당 최소 1까지 절감
- `SukunaVastReserve`: 스쿠나용 최대 주력 300 대용량형 예정
- `YutaLargeReserve`: 유타용 최대 주력 150 대용량형 예정
- `Standard`: 일반 캐릭터용 최대 주력 100

## 공통 피해와 방어 판정

피해량과 방어 우회 이유를 분리합니다. 단순히 피해량이 높다는 이유로 무하한이나 다른 방어를 통과하지 않습니다.

현재 `DamageDeliveryType`:

```text
Unspecified
PhysicalStrike
CursedTechnique
DomainSureHit
Environmental
```

현재 `DamageTraits`:

```text
DomainAmplification
TechniqueNullification
IgnoresInfinity
Unblockable
```

`OFFICIAL_CONFIRMED`

- 완성된 영역의 필중 효과는 일반적인 무하한 방어와 다른 판정으로 상대에게 도달할 수 있습니다.
- 영역전연은 접촉하는 술식을 중화하는 방식으로 무하한에 대응할 수 있습니다.
- 술식 자체를 무효화하는 특수 수단도 무하한 우회 사유로 분리합니다.

`GAME_ORIGINAL`

- 코드에서는 `DamageContext`가 피해량, 공격자, 전달 방식과 우회 속성을 함께 전달합니다.
- `Health`는 피해 적용 전에 `IDamageGuard`들을 검사합니다.
- 영역 필중, 영역전연, 술식 무효화와 명시적인 특수 우회만 무하한을 통과합니다.
- 낙사 같은 환경 사망은 직접 사망 처리하며 일반 전투 방어와 분리합니다.
- 기존 코드의 `TakeDamage(float)`는 단계적 마이그레이션을 위한 호환 경로이며 신규 공격은 `DamageContext`를 우선합니다.

## 같은 인물의 시기별 버전

같은 캐릭터라도 시기·육체·습득 기술·속박·전투 경험이 달라지면 별도 플레이 버전으로 분리합니다. 한 버전에서 가능한 고급 운용을 모든 시기의 동일 인물에게 자동 제공하지 않습니다.

### 현재 고죠 버전 ID

```text
HiddenInventoryPreAwakening
- 회옥·옥절 각성 전
- 상세 스킬 세트는 구현 전 별도 확정

HiddenInventoryAwakened
- 회옥·옥절 각성 후
- 반전술식 습득과 창·혁·자의 변화 반영 예정

ModernTeacher
- 현대 일반 고죠
- 현재 Unity 프로토타입의 기본 버전

ShinjukuShowdown
- 신주쿠 결전 고죠
- 영역 운용, 술식 번아웃 강제 회복 등 고급 전투 운용 후보
```

현재 Unity에서 실제 선택된 버전은 `ModernTeacher`입니다.

## 고죠 사토루

### 육안과 주력 효율

`OFFICIAL_CONFIRMED`

- 육안은 극도로 정밀한 주력 조작을 가능하게 하며 술식 발동 시 주력 손실을 한없이 0에 가깝게 만듭니다.
- 고죠의 자원 정체성은 큰 주력통 자체보다 압도적인 소비 효율에 있습니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드에서 고죠의 커맨드 스킬은 0~1 또는 모두 1 소비로 표현되는 사례가 있습니다.

`GAME_ORIGINAL`

- 고죠 버전들은 `SixEyesEfficiency` 프로필을 사용합니다.
- Q/E/R/V 내부 기본 소비는 유지하지만 현재 실제 전투 소비는 각각 1입니다.
- 고죠의 제약은 주력 고갈보다 쿨타임, 시전 위험과 술식 번아웃으로 표현합니다.

### 무하한 자동 방어

`OFFICIAL_CONFIRMED`

- 현대 고죠는 무하한을 자동으로 운용해 위협을 선별하고 자신에게 도달하기 전에 정지시킵니다.
- 일반적인 물리 타격이나 술식은 강하다는 이유만으로 무하한을 통과하지 않습니다.
- 영역의 필중 효과, 영역전연, 술식 무효화 수단처럼 원리상 우회가 가능한 공격은 별도 판정입니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드의 고죠 버전들에서 무하한은 공격 무효화·공격 무효화 해제 같은 명시적인 상태 규칙으로 표현됩니다.

`GAME_ORIGINAL`

- 현재 `ModernTeacher`와 미래 `ShinjukuShowdown`에 자동 무하한 방어를 적용합니다.
- 회옥·옥절 버전의 자동화 수준은 각 버전 구현 때 다시 확정합니다.
- 일반 공격이 막히면 체력이 줄지 않고 `INFINITY · BLOCKED`와 청색 파문이 표시됩니다.
- 명시적인 우회 공격은 `INFINITY BYPASSED` 사유를 표시하고 정상 피해를 적용합니다.

### 술식순전 「창」

`OFFICIAL_CONFIRMED`

- 강화된 무하한의 수렴·인력 성질을 이용해 대상을 끌어당기는 기술입니다.
- 고죠 몸 전체를 중심으로 단순 원형 충격파가 발생하는 기술로 고정하지 않습니다.

`GAME_ORIGINAL`

- Q 입력 시 락온 대상 근처 또는 고죠 전방에 수렴점을 생성합니다.
- 수렴점 주변의 적에게 피해와 경직을 주고 중심 방향으로 끌어당깁니다.
- 사거리, 반경, 피해량, 인력과 쿨타임은 프로토타입 수치입니다.

### 술식반전 「혁」

`OFFICIAL_CONFIRMED`

- 술식반전으로 발생하는 강한 발산·반발력 계열 기술입니다.
- 창과 동일한 고죠 중심 원형 판정을 색만 바꿔 재사용하지 않습니다.

`GAME_ORIGINAL`

- E 입력 시 락온 대상 또는 현재 정면을 향해 이동하는 반발 발사체를 생성합니다.
- 전방 경로의 적에게 피해·경직을 주고 발사 방향으로 밀어냅니다.
- 사거리, 판정 반경, 피해량, 반발력과 쿨타임은 프로토타입 수치입니다.

### 허식 「자」

`OFFICIAL_CONFIRMED`

- 술식순전 「창」의 수렴과 술식반전 「혁」의 발산을 충돌시켜 성립합니다.
- 상대에게 창과 혁을 먼저 적중시켜야 한다는 조건은 없습니다.
- 허식 자 준비와 창→혁 적중 콤보는 서로 다른 시스템이어야 합니다.

`GAME_ORIGINAL`

- Q와 E를 각각 사용하면 적중 여부와 무관하게 준비 상태를 얻습니다.
- 두 준비 상태가 제한시간 안에 함께 존재할 때 R로 발동합니다.
- 준비시간, 피해량, 자동 조준, 쿨타임과 빔 판정은 프로토타입 수치입니다.
- 같은 적에게 창 이후 혁을 적중시키는 `BLUE → RED CHAIN`은 별도 게임용 보너스입니다.

### 무량공처와 술식 번아웃

`OFFICIAL_CONFIRMED`

- 영역전개 뒤에는 생득술식이 일시적으로 불안정해지는 술식 번아웃이 발생합니다.
- 번아웃된 술식을 반전술식으로 강제로 회복하는 고급 운용은 신주쿠 결전 시기 능력 구성으로 취급합니다.

`GAME_ORIGINAL`

- 현재 영역 장인 입력, 지속시간, 범위와 행동 불능 시간은 프로토타입 규칙입니다.
- 무량공처 종료 후 약 5초 동안 Q/E/R/V를 봉인합니다.
- 번아웃 중 이동, 기본 공격과 회피는 가능합니다.
- `ModernTeacher`에서는 시간 경과로만 회복합니다.
- 코드의 `TryRestoreTechniqueEarly()`는 `ShinjukuShowdown`일 때만 성공하도록 잠겨 있으며 현재 입력키는 연결하지 않습니다.

## 료멘 스쿠나

### 주력 정체성

`OFFICIAL_CONFIRMED`

- 스쿠나는 고죠의 육안 효율형과 달리 압도적으로 큰 주력 총량을 가진 대용량형으로 구분합니다.

`GAME_ORIGINAL` 예정안

- `SukunaVastReserve` 최대 주력 300을 출발점으로 사용합니다.
- 실제 소비와 회복은 스쿠나 Unity 구현 전에 다시 조정합니다.

### 신기 「카미노」 / 화염·화로 계열

`OFFICIAL_CONFIRMED`

- 해와 팔로 밑준비를 마친 뒤 화로를 열 수 있습니다.
- 속박 때문에 영역 밖에서는 여러 상대를 대상으로 화염을 사용할 수 없습니다.
- 복마어주자 안에서는 영역 조건을 이용해 광역 폭발형으로 운용됩니다.

`GAME_ORIGINAL` 예정안

- 영역 밖: 해와 팔 준비 판정 충족 + 살아 있는 적 한 명일 때 R 가능
- 영역 안: 해·팔 준비와 영역 내 판정을 연결해 광역형 R로 전환
- 쿨타임, 피해량, 준비시간, 소비량과 적중 요구 여부는 별도 테스트 값

`INTERPRETATION_PENDING`

- ‘해와 팔로 밑준비’가 단순 사용인지 대상 적중까지 요구하는지는 구현 직전에 원작 표현을 다시 대조합니다.

## 옷코츠 유타

### 주력 정체성

`OFFICIAL_CONFIRMED`

- 유타는 매우 큰 주력 총량을 가진 캐릭터로 고죠의 육안 효율형과 다른 대용량형입니다.

`ADAPTATION_REFERENCE`

- 팬텀 퍼레이드의 일부 유타는 최대 주력 150으로 표현됩니다.

`GAME_ORIGINAL` 예정안

- `YutaLargeReserve` 최대 주력 150을 출발점으로 사용합니다.
- 리카 완전현현과 복사 술식에 따른 상태별 자원 변화를 별도 설계합니다.

## 작업 절차

1. 구현 전 원작 등장 화와 공식 설명을 확인합니다.
2. 시기·육체·습득 상태를 확인하고 캐릭터 버전을 결정합니다.
3. 발동 조건, 대상 수, 영역과의 상호작용을 기록합니다.
4. 팬텀 퍼레이드 등 공식 게임의 모션·VFX·사운드·자원 번역을 확인합니다.
5. 원작 조건과 게임용 수치를 독립된 상태로 구현합니다.
6. 테스트 안내에서도 원작 규칙, 공식 게임 참고와 프로토타입 수치를 구분합니다.
