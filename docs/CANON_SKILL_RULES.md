# 원작 우선 스킬 구현 규칙

이 문서는 캐릭터 기술을 구현할 때 원작 설정과 게임용 각색을 섞지 않기 위한 기준입니다.

## 표기

- `OFFICIAL_CONFIRMED`: 만화 본편, 단행본 부록, 공식 애니메이션·영화·공식 사이트에서 직접 확인되는 규칙
- `GAME_ORIGINAL`: 조작감, 밸런스, UI를 위해 게임에서 추가한 규칙
- `INTERPRETATION_PENDING`: 원작 문구의 해석이 갈리거나 추가 확인이 필요한 규칙

기술 조건을 만들 때는 `OFFICIAL_CONFIRMED`를 먼저 코드 구조에 반영하고, 필요한 게임 규칙만 별도로 추가합니다. 원작에 없는 적중 횟수, 게이지, 쿨타임, 키 배치 등을 원작 조건처럼 설명하지 않습니다.

## 고죠 사토루

### 허식 「자」

`OFFICIAL_CONFIRMED`

- 술식순전 「창」의 수렴과 술식반전 「혁」의 발산을 충돌시켜 성립합니다.
- 상대에게 창과 혁을 먼저 적중시켜야 한다는 조건은 없습니다.
- 따라서 허식 자의 준비 여부와 창→혁 적중 콤보는 서로 다른 시스템이어야 합니다.

`GAME_ORIGINAL`

- Q로 창을 사용하고 E로 혁을 사용하면 각각 준비 상태를 얻습니다.
- 두 준비 상태가 제한시간 안에 함께 존재할 때 R로 허식 자를 발동합니다.
- 현재 준비 유지시간, 피해량, 자동 조준, 쿨타임, 빔 판정은 프로토타입 수치입니다.
- 창이 적중한 상대에게 짧은 시간 안에 혁을 적중시키면 추가 피해를 주는 `BLUE → RED CHAIN`은 별도의 게임용 전투 연계입니다.

## 료멘 스쿠나

### 신기 「카미노」 / 화염·화로 계열

`OFFICIAL_CONFIRMED`

- 해와 팔로 밑준비를 마친 뒤 화로를 열 수 있습니다.
- 속박으로 인해 영역 밖에서는 여러 상대를 대상으로 화염을 사용할 수 없습니다.
- 복마어주자의 영역 안에서는 잘게 절단된 물질과 영역 조건을 이용해 광역 폭발형으로 운용됩니다.

`GAME_ORIGINAL` 예정안

- 영역 밖: 해와 팔의 준비 판정을 충족하고, 전투 중인 살아 있는 적이 한 명일 때만 R 사용 가능
- 영역 안: 해·팔의 준비를 영역 내 판정과 연동해 광역형 R로 전환
- 쿨타임, 피해량, 준비 유지시간, 실제로 ‘적중’을 요구할지는 플레이 테스트 수치로 분리

`INTERPRETATION_PENDING`

- 원작의 ‘해와 팔로 밑준비’ 문구를 게임에서 단순 사용으로 볼지, 대상 적중까지 요구할지는 구현 전에 해당 화·단행본 표현을 다시 대조합니다.

## 작업 절차

1. 기술을 구현하기 전에 원작 등장 화와 공식 설명을 확인합니다.
2. 발동 조건, 제한, 대상 수, 영역과의 상호작용을 먼저 기록합니다.
3. 원작 조건을 코드의 독립된 상태나 규칙으로 구현합니다.
4. 쿨타임과 입력키 같은 게임 규칙은 `GAME_ORIGINAL`로 분리합니다.
5. 테스트 안내에서도 원작 규칙과 프로토타입 수치를 구분해 설명합니다.
