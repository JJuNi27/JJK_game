## 범위와 발동

기존 공격·이동 엔진을 재사용하고 마무리 이벤트에 선택적인 `ShibuyaCinematicProfile` 참조를 추가했다. 기본 Combat Profile의 `defaultFinisherCinematic`은 저장상 null이며 원본 데이터는 변경하지 않았다. 새 예제 자산도 저장 기본 OFF다.

기존 Health.ReceiveDamage의 실제 Applied 뒤 기존 피격·넉백·발사/다운·히트스톱 처리를 수행하고, 해당 이벤트의 대상 판정 루프가 끝난 뒤 세션을 시도한다. 따라서 다중 대상의 기존 피해를 먼저 유지하고 선택된 한 명만 카메라 참가자로 삼는다. 가장 가까운 유효 적중 대상, 동일 거리에서는 Instance ID로 선택한다. 허공/무적/방어/프로필 OFF/거리·지형 조건 실패에서는 발동하지 않는다.

공격자별 action/event 키로 중복 발동을 막고 두 참가자의 세션 참조로 이중 참가를 막는다. 일반 마지막 타격은 기본 프로필 참조, W/S는 해당 finisher의 hit.cinematic, 그 외 명시적 이벤트는 Authored 트리거를 사용할 수 있다. `TryStartAfterApplied`는 실제 Health 반환값과 고유한 action/event ID를 전달하는 신뢰된 게임 코드용 연결 지점이다. 클라이언트 네트워크 권한 검증을 구현한 API는 아니다.

## 두 참가자만 적용하는 정책

`ShibuyaCinematicSession`은 두 Fighter만 소유한다. 전역 세션 매니저·전역 시계·전역 카메라 검색은 없다. 기본값은 두 참가자의 전투 진행 시계·자세와 실제 이동을 잠시 보존하며 공격·점프 입력과 후속 예약은 실행하지 않는다. 전역 Time.timeScale은 바꾸지 않는다. 제3자의 입력·이동·전투·히트스톱에는 관여하지 않는다.

입력 취소 정책을 켜면 새 이동/공격 입력으로 연출을 취소할 수 있으나 그 입력을 새 공격으로 재실행하지 않는다. 방향 유지 OFF에서는 제한된 방향 입력을 허용한다. 기존 물리 정지 OFF에서는 기존 중력·넉백·수평 발사·거리 넉백을 Fighter 소유의 CharacterController와 충돌 제한으로 진행한다. 위치 대입·순간 정렬·벽 관통은 없다.

Health/IDamageGuard를 통해 연출 외 피해를 Guarded로 반환하여 피해 이후의 경직·넉백 경로도 막는다. 직접 IHitReactable 반응 호출도 연출 중 무시한다. 전역 무적 시간은 부여하지 않는다. 참가자 사이의 명시적 `ApplyAuthoredDamage`만 일회용 출처/대상 권한으로 허용하며, 콜백 재진입은 권한을 재사용할 수 없다. 세션은 추가 타격을 자동 예약하지 않는다. 기존 다른 guard도 계속 적용된다.

**사망·승패는 기존 규칙 우선**이다. 첫 마무리가 치명타면 HP 0과 ShibuyaMatch 종료를 지연하지 않으며 시네마틱을 시작하지 않는다. 환경 피해와 Health.Kill은 차단하지 않고 연출을 해제한다. 사망·전투 종료·비활성화·씬 종료·프로필 OFF/무효·과도한 간격·지형 차단에서도 해제한다. 연출 중 체공 상한을 갱신하지 않으므로 긴 공중 연출 뒤 상한이 이미 만료되었다면 정상 낙하로 돌아간다.

## 카메라 소유권과 복구

기존 `ShibuyaOrbitCamera`를 partial override로 확장했다. 각 카메라는 자기 target Fighter에 `IShibuyaCinematicView`를 등록하고, 세션은 두 참가자에 등록된 뷰에만 요청한다. 제3자 카메라에 방송하지 않는다. 현재 단일 로컬 플레이어 구조에서 별도 카메라 인스턴스도 만들어 소유권 경계를 검사하며 실제 멀티플레이는 만들지 않는다.

공격자·피격자·중간 지점 기준 샷 배열을 unscaled 세션 시간으로 진행한다. 샷의 거리·높이·수평 각도·로컬 위치/주시점/회전 보정·FOV·전환 시간과 전체 시작/복귀 블렌드를 작성한다. 진입 전 자유 시점 yaw/pitch/focus/FOV를 보존하고, 종료 뒤 현재 참가자 위치를 따라 정상 카메라와 조작으로 복귀한다. 복귀 블렌드 중 새 세션은 원래 복구 상태를 유지하며 뷰를 인계받는다. 카메라 비활성화나 다른 소유자 재연결도 이전 요청을 해제한다.

샷 위치와 블렌드 위치에 SphereCast를 적용하고, 유효 위치가 지형에 묻히면 연출을 취소한다. 자동 경로 탐색·모든 지형에서의 완벽한 샷 구도 보장은 없다.
