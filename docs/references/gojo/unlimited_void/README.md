## 매우 중요 — `interior_concept_ref_01.png`에 대한 설명

이 이미지는 **사용자가 ChatGPT에게 원하는 분위기를 설명해서 의도적으로 과장되게 생성한 컨셉 이미지**다.

**최종 정답 이미지가 아니며 그대로 복제하면 안 된다.**

실제 목표보다 시각 밀도와 화려함이 훨씬 과한 편이다.

이 이미지에서 참고할 것은:
- blue / blue-white nebula 언어
- cosmic depth
- layered space
- 더 풍부한 환경 안에 White Blood가 존재하는 방식

전체적인 원작 충실도와 분위기는 `interior_anime_ref_01.png`를 더 우선한다.

최종 결과는 다음 두 지점의 사이를 목표로 한다.

**더 어둡고 절제된 anime reference**
↕
**과장된 cosmic richness의 concept reference**

즉 생성 이미지는 "이만큼 그대로 만들어라"가 아니라,
**어떤 방향으로 공간을 더 풍부하게 만들 수 있는지 보여주는 아이디어 증폭용 레퍼런스**다.

앞으로 추가되는 Unlimited Void reference도 같은 폴더에 설명적인 파일명으로 넣는다.
