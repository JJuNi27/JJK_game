# 개발 로드맵과 우선순위 판단 기준

이 문서는 사용자의 아이디어를 무조건 즉시 구현하지 않고, 현재 단계에 필요한지 평가하기 위한 기준입니다.

## 판단 질문

새 제안이 들어오면 다음 순서로 평가합니다.

1. 현재 전투 루프의 정확성이나 테스트 품질을 높이는가?
2. 다음 캐릭터에도 재사용될 실제 공통 규칙인가?
3. 지금 하지 않으면 이후 코드를 크게 다시 작성해야 하는가?
4. 반대로 지금 하면 모델·연출·콘텐츠 변경 때문에 반복 작업이 커지는가?
5. 원작 조건인지, 공식 게임의 각색인지, 우리 게임용 편의인지 구분됐는가?

판정 결과는 다음 중 하나로 명확히 설명합니다.

```text
NOW
- 현재 구조에 필요하며 바로 구현

FOUNDATION_ONLY
- 지금은 기반만 만들고 콘텐츠는 보류

LATER
- 좋은 아이디어지만 현재 단계에서는 반복 작업이 커서 보류

REJECT
- 프로젝트 방향·원작 기준·기술 구조와 맞지 않아 채택하지 않음
```

## 현재 단계 — 현대 고죠 핵심 전투

목표는 외형 완성이 아니라 현대 고죠의 전투 정체성과 두 번째 캐릭터가 사용할 공통 판정을 검증하는 것입니다.

현재 우선순위:

1. 공격 속성·방어·우회 판정
2. 현대 고죠 무하한 자동 방어
3. 스쿠나 프로토타입으로 공통 구조 검증
4. 실제로 반복되는 부분만 캐릭터 공통 구조로 추출
5. Python 장인·음성 인식과 Unity 연결

## 이번 단계에서 보류

```text
LATER
- 최종 고죠 3D 모델
- 정교한 공격·표정·손가락 애니메이션
- 완성형 BGM·보이스·사운드 믹싱
- 회옥·옥절·신주쿠 버전 전체 구현
- 캐릭터 선택·수집 UI
- 완성형 맵과 배경 연출
```

현재 로우폴리 프록시와 합성 효과음은 기능 확인용이며 최종 품질 목표가 아닙니다.

## 다음 단계 진입 조건

### 스쿠나 프로토타입으로 이동

다음이 확인되면 진행합니다.

- 일반 공격이 무하한에 막힘
- 영역전연·영역 필중·술식 무효화 속성이 명시적으로 우회함
- 회피 무적과 무하한 방어가 충돌하지 않음
- 기존 고죠 술식·영역·승패가 회귀하지 않음

### 모델·애니메이션 본작업으로 이동

다음이 확인된 뒤 진행합니다.

- 최소 두 캐릭터의 기본 공격·술식·영역 상태 구조가 안정됨
- 기술 판정 타이밍과 행동 잠금 규칙이 더 이상 크게 변하지 않음
- 캐릭터 모델 교체에 필요한 뼈대·애니메이션 이벤트 요구사항이 실제 전투에서 확정됨
