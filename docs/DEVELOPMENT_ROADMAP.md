# 개발 로드맵과 우선순위 판단 기준

이 문서는 사용자의 아이디어를 무조건 즉시 구현하지 않고, 현재 단계에 필요한지 평가하기 위한 기준입니다.

## 판단 질문

새 제안이 들어오면 다음 순서로 평가합니다.

1. 현재 전투 루프의 정확성이나 테스트 품질을 높이는가?
2. 다음 캐릭터에도 재사용될 실제 공통 규칙인가?
3. 지금 하지 않으면 이후 코드를 크게 다시 작성해야 하는가?
4. 반대로 지금 하면 모델·연출·콘텐츠 변경 때문에 반복 작업이 커지는가?
5. 원작 조건인지, 공식 게임의 각색인지, 우리 게임용 편의인지 구분됐는가?

판정 결과는 다음 중 하나로 명확히 설명합니다.

```text
NOW
- 현재 구조에 필요하며 바로 구현

FOUNDATION_ONLY
- 지금은 기반만 만들고 콘텐츠는 보류

LATER
- 좋은 아이디어지만 현재 단계에서는 반복 작업이 커서 보류

REJECT
- 프로젝트 방향·원작 기준·기술 구조와 맞지 않아 채택하지 않음
```

## 완료된 현재 단계 — 현대 고죠 핵심 전투

다음 항목은 사용자가 정상 확인했습니다.

- 기본 전투와 다중 적
- 창·혁·허식 자·무량공처
- 육안 효율형 주력
- 술식 번아웃
- 공통 `DamageContext`
- 현대 고죠 무하한 자동 방어
- 일반 공격 차단, 영역전연 우회, 회피 무적 우선순위
- 허식 자와 창→혁 추가 피해의 `DamageContext` 마이그레이션

## 현재 단계 — 첫 스쿠나 프로토타입

조사 문서:

```text
docs/SUKUNA_FIRST_VERSION_RESEARCH.md
```

선택 버전:

```text
SukunaShibuyaYujiBody
시부야 사변 · 이타도리 유지 육체 스쿠나
```

현재 우선순위:

1. 거대한 캐릭터 프레임워크가 아닌 최소 플레이어 전환 경로
2. 스쿠나 대용량 주력 프로필: 최대 160 / 시작 95 테스트
3. 기본 3단 체술
4. Q 해 — 원거리 참격, 적 수에 따른 단일/다중 변화
5. E 팔 — 근거리 고비용 단일 참격
6. 해·팔 사용 상태 기록
7. 사용자 테스트 뒤 R 화로 구현 여부 판단
8. 화로 확인 뒤 V 복마어주자 구현
9. 고죠와 스쿠나에서 실제로 반복된 부분만 공통 구조로 추출

## 이번 단계에서 보류

```text
LATER
- 최종 고죠·스쿠나 3D 모델
- 정교한 공격·표정·손가락 애니메이션
- 완성형 BGM·보이스·사운드 믹싱
- 회옥·옥절·신주쿠 고죠 전체 구현
- 메구미 육체·헤이안 진신·신주쿠 스쿠나
- 스쿠나 반전술식 자동 회복과 다중 상태 저항
- 세계참
- 캐릭터 선택·수집 UI
- 완성형 맵과 배경 연출
```

현재 로우폴리 프록시와 합성 효과음은 기능 확인용이며 최종 품질 목표가 아닙니다.

## 단계 진입 조건

### 스쿠나 Milestone 2 — 화로

다음이 확인되면 진행합니다.

- 고죠와 스쿠나 프로토타입을 안전하게 전환할 수 있음
- 스쿠나 기본 공격·Q 해·E 팔이 정상 작동
- 주력 160/95와 소비 15/45가 전투 선택을 만듦
- 적 한 명/여러 명일 때 해의 판정 변화가 정상
- 기존 고죠 전투가 회귀하지 않음

### 스쿠나 Milestone 3 — 복마어주자

다음이 확인된 뒤 진행합니다.

- 해·팔 준비 상태와 화로 조건이 안정됨
- 영역 밖 단일 대상 제약이 정상 작동
- `DomainSureHit` 반복 참격 설계가 기존 무하한 판정과 충돌하지 않음

### 모델·애니메이션 본작업

다음이 확인된 뒤 진행합니다.

- 최소 두 캐릭터의 기본 공격·술식·영역 상태 구조가 안정됨
- 기술 판정 타이밍과 행동 잠금 규칙이 더 이상 크게 변하지 않음
- 캐릭터 모델 교체에 필요한 뼈대·애니메이션 이벤트 요구사항이 실제 전투에서 확정됨
