# 료멘 스쿠나 설정 카드 v0.1

> 상태: **사용자 검토 전 초안**  
> 스포일러 범위: 원작 만화 완결부 포함  
> 이 문서가 승인되기 전까지 스쿠나는 캐릭터 선택 화면에서 잠금 상태를 유지한다.

## 1. 캐릭터 기준

- 이름: 료멘 스쿠나
- 별칭: 저주의 왕
- 기준 작품: 원작 만화 전체 + 공식 TV 애니메이션
- 기준 몸 형태: **미정**
  - 이타도리 유지 몸
  - 후시구로 유지 몸
  - 헤이안 시대 본래 모습
- 첫 프로토타입 권장 범위: 몸 형태와 무관하게 공통으로 사용할 수 있는 `복마어주자 장인 커맨드`부터 검증

## 2. 핵심 설정

### [OFFICIAL_CONFIRMED] 생득술식

- 명칭: `御厨子` / Mizushi / Shrine
- 한국어 정식 표기는 구현 전 사용자와 다시 확인한다.
- 핵심 성질:
  - 보이지 않는 참격
  - 대상과 상황에 따른 참격 운용
  - 특정 조건에서 사용하는 화염 계열 공격

### [OFFICIAL_CONFIRMED] 주요 파생 기술

- `解` / Dismantle
  - 기본 원거리 참격 계열
  - 생물과 무생물 모두 공격 가능
- `捌` / Cleave
  - 대상의 내구와 주력 수준에 맞춰 절단력을 조절하는 참격 계열
- 화염 계열 공격
  - 복마어주자와 연계되는 고위력 공격이 존재
  - 발동 조건과 게임 내 사용 방식은 고급 단계에서 별도 설계
- 세계를 가르는 참격
  - 원작 후반의 고급 응용
  - 첫 스쿠나 MVP에서는 제외하고 최종 단계 후보로 보류

### [OFFICIAL_CONFIRMED] 영역전개

- 명칭: `伏魔御厨子` / 복마어주자 / Malevolent Shrine
- 일반적인 영역처럼 외부 껍질로 공간을 완전히 닫지 않는 개방형 영역
- 도망갈 길을 남기는 속박을 통해 필중 범위를 크게 확장
- 최대 범위는 약 200m로 설명됨
- 시부야 전투 기준:
  - 무생물에는 기본 참격
  - 주력이 있는 대상에는 조절형 참격
- 범위와 세부 필중 규칙은 게임 밸런스를 위해 축소 가능하지만, 축소분은 `[GAME_ORIGINAL]`로 표시한다.

### [OFFICIAL_CONFIRMED] 장인

- 두 손을 사용하는 복마어주자 고유 장인
- 2차 자료에서는 염마천의 수인으로 설명됨
- 불교 수인의 해석 자체를 게임 공식 설정처럼 단정하지 않고, **원작·애니에 보이는 손 모양과 두 손 사용 여부**를 구현 기준으로 삼는다.

### [OFFICIAL_CONFIRMED] 음성

- 공통 선언: `領域展開` / 료이키 텐카이
- 영역명: `伏魔御厨子` / 복마어주자
- 첫 음성 프로토타입에서는 현재 고죠와 같은 `료이키 텐카이` 인식기를 재사용할 수 있다.
- 추후 영역명을 추가로 말해야 하는 2단계 음성 방식도 검토한다.

## 3. 전투 능력 카드

### [OFFICIAL_CONFIRMED] 흑섬

- 사용 가능
- 원작 최종 전투에서 여러 차례 성공
- 게임에서는 고죠와 마찬가지로 확정 버튼이 아니라 타격 타이밍 시스템으로 구현

### [OFFICIAL_CONFIRMED] 반전술식

- 사용 가능
- 신체 회복과 높은 수준의 주력 운용 가능
- 영역전개 후 번아웃된 술식을 강제로 회복시키는 예외적 운용도 가능
- 강제 회복은 뇌 손상 위험이 따르는 고급 시스템으로 분리

### [OFFICIAL_CONFIRMED] 대영역 기술

- 영역전연
- 미허갈롱(Hollow Wicker Basket)
- 복마어주자와 대영역 기술의 동시·연속 운용은 고급 전투 단계에서 구현

### [OFFICIAL_CONFIRMED] 영역 사용 후 제약

- 영역전개 종료 후 생득술식 번아웃 발생
- 일반 상태에서는 회복 시간이 필요
- 스쿠나는 고죠와 마찬가지로 뇌의 술식 부위를 손상시키고 반전술식으로 회복하는 위험한 강제 초기화가 가능
- 반복 사용에는 뇌 손상과 영역 사용 불가 위험이 따른다.

## 4. 몸 형태별 예외

### 이타도리 유지 몸

- 애니메이션 초반과 시부야 기준의 익숙한 외형
- 두 팔로 복마어주자 장인을 사용
- 첫 캐릭터 프로토타입으로 구현 난도가 가장 낮음

### 후시구로 유지 몸

- 십종영법술 접근 가능 시기의 스쿠나
- 스쿠나 고유 술식과 십종영법술이 함께 등장해 구현 범위가 급격히 커짐
- 첫 MVP에서 십종영법술을 포함하지 않는다면 별도 변형 캐릭터로 취급하는 편이 안전

### 헤이안 시대 본래 모습

- 네 팔과 두 입을 활용한 동시 전투·장인·영창이 핵심
- 가장 스쿠나다운 최종형이지만 애니메이션·모델링·입력 설계 난도가 높음
- Unity 전투 단계 이후 고급 캐릭터 형태로 적합

## 5. 1차 구현 범위 제안

### Phase S1 — 복마어주자 장인 연습

- 캐릭터 선택에서 스쿠나 해금
- 음성 `료이키 텐카이`
- 스쿠나 전용 두 손 장인 커맨드
- 성공/실패와 연습 통계
- 임시 복마어주자 화면

### Phase S2 — 기본 술식

- 기본 참격
- 조절형 참격
- 주력 자원과 쿨다운
- 반전술식 회복

### Phase S3 — 고급 전투

- 개방형 영역 범위
- 영역전연
- 미허갈롱
- 흑섬
- 화염 계열 공격
- 술식 번아웃 강제 회복

### Phase S4 — 최종 응용

- 세계를 가르는 참격
- 영역 조건 변경
- 고죠와의 영역 충돌
- 헤이안 본래 모습
- 후시구로 유지 몸과 십종영법술 변형

## 6. 장인 커맨드 설계 전 확인할 사항

아래 항목을 사용자와 확정한 뒤 커맨드를 설계한다.

1. 첫 스쿠나의 몸 형태
2. 첫 MVP에 십종영법술을 포함할지
3. `御厨子`의 프로젝트 내 한국어 표기
4. 화염 계열 공격을 기본 스쿠나에 포함할지
5. 세계를 가르는 참격을 최종 기술로 포함할지
6. 복마어주자 커맨드가 실제로 양손 키보드·마우스를 사용해야 하는지
7. 음성을 `료이키 텐카이`까지만 요구할지, `복마어주자`까지 요구할지

## 7. 커맨드 방향 후보 — 아직 미확정

### 후보 A: 양손 입력 강조

```text
료이키 텐카이
→ 왼손 키 유지
→ 오른손 마우스 양 버튼 결합
→ 정해진 타이밍에 동시 해제
```

- 장점: 고죠의 한 손 장인과 확실히 다른 조작감
- 단점: 접근성과 키 충돌을 추가 검토해야 함

### 후보 B: 마우스만 사용

```text
료이키 텐카이
→ 좌·우클릭 동시 유지
→ 짧은 결합 입력
→ 동시 해제
```

- 장점: 현재 프로토타입 구조를 재사용하기 쉬움
- 단점: 실제 두 손 장인의 느낌은 약함

`[GAME_ORIGINAL]` 커맨드 입력은 원작 설정이 아니라 장인 형태를 게임 조작으로 번역한 각색이다.
