# 료멘 스쿠나 설정 카드 v1.0

> 상태: **사용자 1차 검토 완료**  
> 스포일러 범위: 원작 만화 완결부 포함  
> 첫 구현 형태: **이타도리 유지 몸의 스쿠나**

## 1. 캐릭터 기준

- 이름: 료멘 스쿠나
- 별칭: 저주의 왕
- 기준 작품: 원작 만화 전체 + 공식 TV 애니메이션
- 첫 구현 형태: 이타도리 유지 몸
- 몸 형태별 스쿠나는 추후 별도 캐릭터 슬롯으로 추가한다.

예정 변형:

```text
스쿠나(이타도리)
스쿠나(메구미)
스쿠나(헤이안 본체)
```

각 형태의 사용 가능 술식과 입력 체계는 섞지 않는다.

## 2. 첫 구현 범위 결정

| 항목 | 결정 |

| 몸 형태 | 이타도리 유지 몸 |
| 십종영법술 | 미포함 |

## 3. 핵심 설정

### [OFFICIAL_CONFIRMED] 생득술식

- 명칭: `御厨子` / Mizushi / Shrine
- 프로젝트 내 한국어 표기는 일반적으로 알려진 `주복사`를 우선 후보로 두되, 정식 번역 확인 후 확정한다.
- 핵심 성질:
  - 보이지 않는 참격
  - 대상과 상황에 따른 참격 운용
  - 조건을 거쳐 사용하는 화염 계열 공격

### [OFFICIAL_CONFIRMED] 주요 파생 기술

- `解` / 해
  - 기본 원거리 참격
  - 생물과 무생물 모두 공격 가능
- `捌` / 팔
  - 대상의 내구와 주력 수준에 맞춰 절단력을 조절하는 참격
- 푸가
  - 이타도리 유지 몸의 스쿠나가 시부야에서 사용했으므로 첫 스쿠나의 구현 범위에 포함
  - 일반 기본기보다 조건부 고위력 기술로 설계
- 세계를 가르는 참격
  - 후시구로 유지 몸 시기의 후반 응용
  - 이타도리 유지 몸 첫 버전에서는 제외

### [OFFICIAL_CONFIRMED] 영역전개

- 명칭: `伏魔御厨子` / 복마어주자
- 일반적인 영역처럼 외부 껍질로 공간을 완전히 닫지 않는 개방형 영역
- 도망갈 길을 남기는 속박을 통해 넓은 필중 범위를 확보
- 최대 범위는 약 200m로 설명됨
- 시부야 전투 기준:
  - 무생물에는 기본 참격
  - 주력이 있는 대상에는 조절형 참격
- 실제 게임에서는 전장 크기에 맞춰 범위를 축소할 수 있으며, 축소 수치는 `[GAME_ORIGINAL]`로 표시한다.

### [OFFICIAL_CONFIRMED] 장인

- 두 손을 사용하는 복마어주자 고유 장인
- 불교 수인의 명칭과 해석은 공식 전투 설정처럼 단정하지 않는다.
- 원작·애니메이션에 보이는 두 손 사용과 손 모양을 구현 기준으로 삼는다.

### [OFFICIAL_CONFIRMED] 음성 규칙

- 공통 선언: `領域展開` / 료이키 텐카이
- 모든 영역전개 캐릭터는 공통 선언까지만 음성으로 입력한다.
- 영역명 `복마어주자`를 추가로 말할 필요는 없다.
- 선택한 캐릭터와 장인 커맨드 성공 결과가 발동 영역을 결정한다.

## 4. 전투 능력 카드

### [OFFICIAL_CONFIRMED] 흑섬

- 사용 가능
- 확정 기술 버튼이 아니라 타격 타이밍 시스템으로 구현한다.

### [OFFICIAL_CONFIRMED] 반전술식

- 사용 가능
- 신체 회복과 높은 수준의 주력 운용 가능
- 영역 사용 후 번아웃된 술식을 강제로 회복시키는 위험한 운용 가능
- 강제 회복은 고죠와 함께 고급 시스템으로 분리한다.

### [OFFICIAL_CONFIRMED] 대영역 기술

- 영역전연
- 미허갈롱
- 첫 이타도리 몸 프로토타입의 영역 장인 연습에는 포함하지 않는다.

### [OFFICIAL_CONFIRMED] 영역 사용 후 제약

- 영역전개 종료 후 생득술식 번아웃 발생
- 일반 상태에서는 회복 시간이 필요
- 위험한 강제 초기화 반복 시 뇌 손상과 영역 사용 불가 위험

## 5. 몸 형태별 운영 원칙

### 스쿠나(이타도리) — 첫 구현

- 복마어주자
- 해·팔
- 푸가
- 반전술식
- 흑섬
- 십종영법술 없음
- 세계참 없음

### 스쿠나(메구미) — 추후 별도 캐릭터

- 십종영법술 접근 가능 시기
- 마허라와 식신 운용 때문에 별도 전투 설계 필요
- 세계를 가르는 참격은 이 버전 또는 후반 전용 버전의 최종 기술 후보
- 첫 버전의 기술 목록과 섞지 않는다.

### 스쿠나(헤이안 본체) — 추후 별도 캐릭터

- 네 팔과 두 입을 활용한 전투·장인·영창
- 가장 복잡한 입력과 애니메이션이 필요한 고급 캐릭터
- Unity 전투 기반이 생긴 이후 구현한다.

## 7. 복마어주자 장인 커맨드

### [GAME_ORIGINAL] 왼손 키보드 + 오른손 마우스

```text
료이키 텐카이 또는 V
→ 왼손으로 E 키 유지
→ E를 유지한 채 오른손으로 좌·우클릭을 거의 동시에 누르고 유지
→ 목표 타이밍에 좌·우클릭을 거의 동시에 해제
→ 복마어주자 발동
```

현재 초기 판정값:

```text
E 입력 후 양쪽 마우스 버튼 완성 제한: 0.70초
좌·우클릭을 모두 누른 것으로 인정하는 간격: 0.18초 이내
목표 유지 시간: 0.85초
유지 시간 허용 오차: ±0.22초
좌·우클릭 동시 해제 인정 간격: 0.18초 이내
```

설계 이유:

- 왼손의 E 키가 장인의 한쪽 손을 나타낸다.
- 오른손 마우스 양 버튼이 다른 쪽 손의 결합을 나타낸다.
- 실제로 양손을 사용하므로 고죠의 마우스 한 손 커맨드와 조작감이 확실히 달라진다.
- 영역 준비 상태에서는 E 키를 장인 전용으로 사용한다.
- 너무 어렵다면 동시 입력·해제 허용 간격을 넓힌다.
