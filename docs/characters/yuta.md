# 옷코츠 유타 설정 카드 v0.1

> 상태: **사용자 검토 전 초안**  
> 스포일러 범위: 원작 만화 249화 이후 포함  
> 첫 구현 후보: **본편 2학년 옷코츠 유타**  
> 이 문서가 승인되기 전까지 유타는 선택 화면에서 잠금 상태를 유지한다.

## 1. 캐릭터 기준

- 이름: 옷코츠 유타
- 소속: 도쿄 도립 주술 고등전문학교 2학년
- 등급: 특급 주술사
- 첫 구현 형태: 극장판 0 이후의 본편 2학년 유타
- `주술회전 0`의 1학년 유타는 필요하면 추후 별도 변형 캐릭터로 검토한다.
- 진안상애가 공개된 시기의 유타를 기준으로 하므로, 극장판 시점의 특급 과주원령 리카와 현재의 `리카`를 같은 상태로 섞지 않는다.

예정 변형 후보:

```text
옷코츠 유타(2학년·본편)
옷코츠 유타(주술회전 0)
```

## 2. 핵심 설정

### [OFFICIAL_CONFIRMED] 생득술식 — 모방

- 명칭: `模倣` / Copy
- 다른 술사의 생득술식을 복사해 사용할 수 있다.
- 복사된 술식은 리카에 외부 저장된다.
- 본편 후반부에서 리카가 대상의 신체 일부를 섭취하는 것이 복사 조건과 관련됨이 확인된다.
- 강한 술식일수록 요구되는 신체 부위와 사용 조건이 커질 수 있다.
- 복사했다고 해서 원본 사용자와 동일한 출력·숙련도를 자동으로 얻는 것은 아니다.

### [OFFICIAL_CONFIRMED] 리카

- 극장판 0에서 오리모토 리카의 혼은 해주되었다.
- 본편의 `리카`는 유타에게 남겨진 외부 저장 장치에 가까운 존재다.
- 부분 현현 상태로도 유타를 보조하고 독립적으로 공격할 수 있다.
- 반지를 통해 완전 현현하면 다음을 사용할 수 있다.
  - 리카 완전 현현
  - 저장된 복사 술식
  - 리카의 주력 공급
  - 리카 내부의 주구 저장고
- 완전 현현과 지속 연결은 최대 5분이다.

### [OFFICIAL_CONFIRMED] 기본 전투 능력

- 매우 큰 주력 총량
- 검술과 주력 강화
- 리카와의 협공
- 반전술식
  - 자신을 회복할 수 있다.
  - 타인에게 반전술식을 출력해 치료할 수 있다.
- 주술회전 0 극장판에서 흑섬 연출이 확인되므로 프로젝트에서는 흑섬 사용 가능 캐릭터로 둔다.

## 3. 복사 술식 구현 후보

첫 구현 우선 후보:

- 주언
- 하늘 조작
- 우스라비
- 드루브의 궤적형 식신 술식

후순위 고급 후보:

- 천사의 술식 소멸 / 야곱의 사다리
- 미래 예지 계열 술식
- 주복사 계열 참격
- 그 밖에 원작에서 사용이 확인된 복사 술식

운영 원칙:

- 유타가 실제로 사용한 술식만 후보로 둔다.
- 모든 복사 술식을 처음부터 동시에 구현하지 않는다.
- 전투 밸런스와 입력 수를 고려해 단계별로 해금한다.
- 복사 조건과 사용 횟수를 단순화하면 `[GAME_ORIGINAL]`로 표시한다.

## 4. 영역전개 — 진안상애

### [OFFICIAL_CONFIRMED]

- 명칭: `真贋相愛` / 진안상애 / Authentic Mutual Love
- 사용자: 옷코츠 유타
- 첫 등장: 원작 249화
- 모방을 기반으로 한 영역전개
- 영역 내부에는 십자형 구조물과 수많은 검이 꽂혀 있다.
- 유타는 복사 술식 하나를 영역의 필중 효과로 지정할 수 있다.
- 나머지 복사 술식은 영역 내부의 검에 무작위로 저장된다.
- 유타도 검을 잡기 전에는 어떤 술식이 들어 있는지 알 수 없다.
- 검에 든 술식은 사용 후 해당 검과 함께 사라지지만, 영역 안의 검 수는 사실상 계속 공급된다.
- 원작 전투에서는 상대가 필중 효과를 막는 동안 유타가 여러 검을 뽑아 복사 술식을 연속 사용한다.

### 구현 시 반드시 보존할 정체성

```text
필중 술식 1개 선택
+
나머지 술식이 무작위 검에 배정
+
검을 뽑아야 술식 확인
+
한 검은 1회 사용
```

단순히 원하는 술식을 자유 선택하는 메뉴로만 만들면 진안상애의 핵심인 불확실성과 다재다능함이 사라지므로 권장하지 않는다.

## 5. 영역과 리카의 관계

- 진안상애 안에서는 복사 술식을 영역의 검을 통해 사용할 수 있다.
- 리카 완전 현현의 5분 제한과 영역 내부 검 시스템은 서로 다른 접근 방식이다.
- 게임에서는 두 시스템을 완전히 같은 자원으로 합치지 않는다.
- 영역 밖:
  - 반지 연결과 리카 완전 현현을 통해 복사 술식 사용
- 영역 안:
  - 필중 술식과 무작위 검을 통해 복사 술식 사용

정확한 주력 소모와 재사용 대기시간은 `[GAME_ORIGINAL]` 밸런스 값으로 정한다.

## 7. 장인 커맨드 방향 후보

유타의 영역은 `반지`, `리카와의 연결`, `검을 뽑는 행위`가 시각적 정체성이다. 실제 손 장인을 그대로 재현하기보다 게임 입력으로 번역할 때 다음 방향을 우선 검토한다.

### 후보 A — 반지 연결 + 검 뽑기

```text
료이키 텐카이
→ 왼손 키를 눌러 반지 연결 상태 유지
→ 좌클릭을 누른 채 마우스를 아래에서 위로 드래그
→ 검을 뽑는 최소 거리 도달
→ 왼손 키를 유지한 채 좌클릭 해제
→ 진안상애
```

- 장점: 메구미의 아래→옆 그림자 궤적과 반대 방향이라 조작감이 다르다.
- 장점: 영역 내부의 검과 유타의 검술을 직관적으로 표현한다.
- 단점: 실제 영역 장인 손 모양을 직접 재현한 입력은 아니다.

### 후보 B — 반지 연결 + 장인 결합 + 검 뽑기

```text
료이키 텐카이
→ 왼손 키 유지
→ 우클릭으로 장인 결합
→ 좌클릭 드래그로 검 뽑기
→ 입력 해제
```

- 장점: 손 장인과 검 뽑기를 모두 표현한다.
- 단점: 입력 단계가 길어져 전투 중 사용성이 떨어질 수 있다.

### 현재 권장

**후보 A**를 우선한다.

프로토타입에서는 입력이 짧고 캐릭터별 차이가 분명한 것이 중요하다. 실제 카메라 장인을 추가할 때 손 모양은 별도 `CameraSealInput`으로 대체할 수 있다.

`[GAME_ORIGINAL]` 위 커맨드는 원작 장인을 그대로 재현한 것이 아니라 유타의 설정을 키보드·마우스로 번역한 각색이다.

## 8. 사용자 검토가 필요한 결정

1. 첫 유타를 본편 2학년 버전으로 확정할지
2. 주술회전 0 유타를 추후 별도 캐릭터로 둘지
3. 첫 복사 술식을 `주언 + 하늘 조작/우스라비`로 시작할지
4. 드루브 술식을 첫 일반 전투 범위에 포함할지
5. 야곱의 사다리와 주복사 참격은 고급 단계로 미룰지
6. 진안상애의 무작위 검 시스템을 원작처럼 유지할지
7. 영역 발동 커맨드를 후보 A로 진행할지
8. 리카 완전 현현은 영역 구현 이후 별도 시스템으로 만들지
