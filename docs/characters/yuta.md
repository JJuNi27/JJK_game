# 옷코츠 유타 설정 카드 v1.0

> 상태: **사용자 1차 검토 완료 · 장인 프로토타입 구현**  
> 스포일러 범위: 원작 만화 249화 이후 포함  
> 첫 구현 형태: **본편 2학년 옷코츠 유타**

## 1. 캐릭터 기준

- 이름: 옷코츠 유타
- 소속: 도쿄 도립 주술 고등전문학교 2학년
- 등급: 특급 주술사
- 첫 구현은 극장판 0 이후의 본편 2학년 유타다.
- `주술회전 0`의 1학년 유타는 추후 별도 캐릭터로 추가한다.
- 진안상애가 공개된 시기의 유타를 기준으로 하며, 극장판 시점의 특급 과주원령 리카와 본편의 `리카`를 같은 상태로 섞지 않는다.

예정 변형:

```text
옷코츠 유타(2학년·본편)  ← 현재 구현
옷코츠 유타(주술회전 0)  ← 추후 별도 캐릭터
```

## 2. 핵심 설정

### [OFFICIAL_CONFIRMED] 생득술식 — 모방

- 명칭: `模倣` / Copy
- 다른 술사의 생득술식을 복사해 사용할 수 있다.
- 복사된 술식은 리카에 외부 저장된다.
- 본편 후반부에서 리카가 대상의 신체 일부를 섭취하는 것이 복사 조건과 관련됨이 확인된다.
- 강한 술식일수록 요구되는 신체 부위와 사용 조건이 커질 수 있다.
- 복사했다고 해서 원본 사용자와 동일한 출력·숙련도를 자동으로 얻는 것은 아니다.

### [OFFICIAL_CONFIRMED] 리카

- 극장판 0에서 오리모토 리카의 혼은 해주되었다.
- 본편의 `리카`는 유타에게 남겨진 외부 저장 장치에 가까운 존재다.
- 부분 현현 상태로도 유타를 보조하고 독립적으로 공격할 수 있다.
- 반지를 통해 완전 현현하면 다음을 사용할 수 있다.
  - 리카 완전 현현
  - 저장된 복사 술식
  - 리카의 주력 공급
  - 리카 내부의 주구 저장고
- 완전 현현과 지속 연결은 최대 5분이다.

### [OFFICIAL_CONFIRMED] 기본 전투 능력

- 매우 큰 주력 총량
- 검술과 주력 강화
- 리카와의 협공
- 반전술식
  - 자신을 회복할 수 있다.
  - 타인에게 반전술식을 출력해 치료할 수 있다.
- 주술회전 0 극장판에서 흑섬 연출이 확인되므로 프로젝트에서는 흑섬 사용 가능 캐릭터로 둔다.

## 3. 첫 복사 술식 구현 범위

첫 구현 우선:

- 주언
- 하늘 조작
- 우스라비

후순위:

- 드루브의 궤적형 식신 술식
- 천사의 술식 소멸 / 야곱의 사다리
- 미래 예지 계열 술식
- 주복사 계열 참격
- 그 밖에 원작에서 사용이 확인된 복사 술식

운영 원칙:

- 유타가 실제로 사용한 술식만 후보로 둔다.
- 모든 복사 술식을 처음부터 동시에 구현하지 않는다.
- 전투 밸런스와 입력 수를 고려해 단계별로 해금한다.
- 복사 조건과 사용 횟수를 단순화하면 `[GAME_ORIGINAL]`로 표시한다.

## 4. 영역전개 — 진안상애

### [OFFICIAL_CONFIRMED]

- 명칭: `真贋相愛` / 진안상애 / Authentic Mutual Love
- 사용자: 옷코츠 유타
- 첫 등장: 원작 249화
- 모방을 기반으로 한 영역전개
- 영역 내부에는 십자형 구조물과 수많은 검이 꽂혀 있다.
- 유타는 복사 술식 하나를 영역의 필중 효과로 지정할 수 있다.
- 나머지 복사 술식은 영역 내부의 검에 무작위로 저장된다.
- 유타도 검을 잡기 전에는 어떤 술식이 들어 있는지 알 수 없다.
- 검에 든 술식은 사용 후 해당 검과 함께 사라진다.

구현에서 반드시 보존할 정체성:

```text
필중 술식 1개 선택
+
나머지 술식이 무작위 검에 배정
+
검을 뽑아야 술식 확인
+
한 검은 1회 사용
```

원하는 술식을 언제든 자유롭게 고르는 메뉴로만 만들지 않는다. 진안상애의 불확실성과 다재다능함을 유지한다.

## 5. 영역과 리카의 관계

- 진안상애 안에서는 복사 술식을 영역의 검을 통해 사용할 수 있다.
- 리카 완전 현현의 5분 제한과 영역 내부 검 시스템은 서로 다른 접근 방식이다.
- 두 시스템을 완전히 같은 자원으로 합치지 않는다.

```text
영역 밖
- 반지 연결
- 리카 완전 현현
- 저장된 복사 술식 사용

영역 안
- 필중 술식 1개
- 무작위 검
- 검을 뽑아 복사 술식 사용
```

정확한 주력 소모와 재사용 대기시간은 `[GAME_ORIGINAL]` 밸런스 값으로 정한다.

## 7. 확정 장인 커맨드

```text
료이키 텐카이
→ 왼손 C 키로 반지 연결 유지
→ 화면 아래쪽을 좌클릭
→ 검을 뽑듯 마우스를 위로 드래그
→ C를 유지한 채 좌클릭 해제
→ 진안상애
→ 영역 발동 뒤 C 해제
```

초기 판정값:

```text
C 입력 후 드래그 시작 제한: 0.80초
위쪽 최소 이동: 190px
좌우 흔들림 허용: 100px
전체 검 뽑기 제한시간: 1.60초
```

- 메구미의 아래→옆 그림자 궤적과 반대되는 위쪽 검 뽑기 입력이다.
- 타이밍 바가 아니라 방향·거리·궤적 완성도를 판정한다.
- `[GAME_ORIGINAL]` 실제 손 장인을 그대로 재현한 것이 아니라 반지 연결과 검의 정체성을 게임 입력으로 번역한 각색이다.
