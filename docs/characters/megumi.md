# 후시구로 메구미 설정 카드 v0.1

> 상태: **사용자 검토 전 초안**  
> 기준: 후시구로 메구미 본인  
> 범위: 원작 만화 + 공식 TV 애니메이션  
> 이 문서가 승인되기 전까지 메구미는 선택 화면에서 잠금 상태를 유지한다.

## 1. 캐릭터 기준

- 이름: 후시구로 메구미
- 소속: 도쿄 도립 주술 고등전문학교
- 등급: 2급 주술사
- 생득술식: 십종영법술
- 첫 구현 형태: 스쿠나에게 육체를 빼앗기기 전의 메구미 본인
- 스쿠나(메구미 몸)는 `스쿠나(메구미)`라는 별도 캐릭터로 취급하며 이 카드에 섞지 않는다.

## 2. 핵심 설정

### [OFFICIAL_CONFIRMED] 십종영법술

- 젠인가 상전 술식
- 그림자를 매개로 식신을 조복하고 소환한다.
- 그림자 안에 물건을 보관하거나 그림자를 이동·기습에 활용할 수 있다.
- 조복하지 않은 식신을 일반 전투 기술처럼 자유롭게 사용하지 않는다.

### [OFFICIAL_CONFIRMED] 메구미가 직접 사용한 주요 식신

첫 구현 후보:

- 옥견 / 옥견 「혼」
- 누에
- 가마
- 만상
- 탈토

후순위 또는 특수 처리:

- 대사
  - 작중 파괴 이후 일반 소환 대상에서 제외
- 불지정저
  - 누에와 가마를 조합한 확장술식
- 마허라
  - 메구미가 조복하지 못한 식신
  - 일반 스킬이나 확정 필살기로 사용하지 않는다.
  - 사용자 본인까지 위험한 조복 의식·최후 수단 시스템으로만 검토한다.

### [OFFICIAL_CONFIRMED] 영역전개 — 감합암예정

- 명칭: `嵌合暗翳庭` / 감합암예정 / Chimera Shadow Garden
- 십종영법술의 영역전개
- 첫 등장: 원작 58화 / 애니메이션 23화
- 메구미가 구현한 감합암예정은 **미완성 영역**이다.
- 바닥과 공간을 유동적인 그림자로 채운다.
- 영역 안에서 식신을 다중 전개하고 그림자 조작을 확장할 수 있다.
- 메구미 자신의 그림자 분신도 만들 수 있다.
- 완전한 장벽과 필중 효과가 없으므로, 일반적인 완성형 영역과 동일하게 취급하지 않는다.
- 레지와의 전투에서는 체육관 공간을 이용해 영역을 강제로 닫고 십종영법술의 잠재력을 크게 끌어냈다.

### [OFFICIAL_CONFIRMED] 환경 의존성

- 현재 메구미는 스스로 완전한 장벽을 닫지 못한다.
- 실내 공간이나 기존 구조물을 이용해 영역을 가둘 수 있다.
- 게임에서는 감합암예정을 아무 장소에서나 완성형 영역처럼 발동시키지 않는 방향을 우선한다.

## 3. 전투 능력 카드

### [OFFICIAL_CONFIRMED] 흑섬

- 메구미의 흑섬 성공 장면은 확인되지 않는다.
- 현재 프로젝트에서는 흑섬 사용 가능 캐릭터로 열지 않는다.

### [OFFICIAL_CONFIRMED] 반전술식

- 메구미가 반전술식으로 자신을 회복하는 능력은 확인되지 않는다.
- 기본 회복 기술로 제공하지 않는다.

### [OFFICIAL_CONFIRMED] 대영역 기술

- 메구미 본인이 간이영역·미허갈롱·낙화의 정을 사용한 장면은 확인되지 않는다.
- 별도 대영역 기술을 임의로 부여하지 않는다.

### [OFFICIAL_CONFIRMED] 영역 사용 후 제약

- 일반적인 영역전개와 마찬가지로 사용 후 생득술식 번아웃 규칙을 적용한다.
- 감합암예정은 미완성이고 메구미의 부담이 크므로, 전투 구현 시 높은 주력 소모와 짧은 유지 시간을 우선 검토한다.
- 정확한 소모량과 유지 시간은 `[GAME_ORIGINAL]` 밸런스 값으로 표시한다.

## 4. 1차 구현 범위 제안

### Phase M1 — 감합암예정 장인 연습

- 캐릭터 선택에 메구미 잠금 슬롯 표시
- 음성 `료이키 텐카이`
- 메구미 전용 두 손 장인 커맨드
- 성공·실패 판정과 연습 통계
- 임시 감합암예정 화면

### Phase M2 — 기본 십종영법술

- 옥견 「혼」
- 누에
- 가마
- 탈토
- 만상
- 그림자 보관·이동의 단순화된 게임 버전

### Phase M3 — 영역 전투

- 그림자 바닥 이동
- 식신 다중 전개
- 메구미 분신
- 실내 구조물 이용 여부
- 완전한 필중 효과 없음
- 영역 종료 후 번아웃

### Phase M4 — 위험 기술

- 마허라 조복 의식
- 사용자와 적 모두에게 위험한 중립 소환체
- 일반적인 확정 승리 버튼으로 만들지 않음

## 5. 장인 커맨드 설계 전 확인할 사항

1. 감합암예정을 실내에서만 발동 가능하게 할지
2. 연습장에서는 환경 조건을 무시하고 커맨드만 연습할지
3. 첫 기본 식신을 옥견 「혼」으로 할지
4. 마허라를 최후 수단으로 포함할지, 메구미 버전에서는 완전히 제외할지
5. 감합암예정 커맨드를 실제 양손 입력으로 만들지
6. 스쿠나의 양손 커맨드와 어떻게 다른 조작감을 줄지
7. 영역의 미완성 상태를 성공 판정·화면에 어떻게 표현할지

## 6. 커맨드 방향 후보 — 아직 미확정

### 후보 A: 그림자를 펼치는 드래그 입력

```text
료이키 텐카이
→ 왼손 키 유지
→ 오른손으로 마우스를 아래 방향으로 드래그
→ 좌우로 그림자를 펼치는 짧은 궤적
→ 양손 입력 해제
```

- 장점: 그림자 정원을 바닥에 펼치는 느낌을 줄 수 있다.
- 장점: 스쿠나의 좌·우클릭 동시 입력과 확실히 다르다.
- 단점: 마우스 궤적 판정 모듈을 새로 만들어야 한다.

### 후보 B: 키보드 양손 결합 입력

```text
료이키 텐카이
→ Q와 E를 양손으로 유지
→ 마우스 아래 드래그
→ 목표 타이밍에 Q와 E 동시 해제
```

- 장점: 두 손 장인 느낌이 강하다.
- 단점: 실제 전투에서 이동키와 충돌할 가능성이 크다.

### 현재 권장

**후보 A**를 우선한다.

메구미의 장인은 두 손이지만, 스쿠나와 똑같이 키보드 한 손 + 마우스 양 버튼으로 만들면 캐릭터별 차이가 약해진다. 메구미는 그림자를 바닥에 펼치는 **마우스 궤적 커맨드**로 차별화하는 것이 좋다.

`[GAME_ORIGINAL]` 위 커맨드는 원작의 손 모양을 그대로 재현한 것이 아니라, 장인과 영역 특성을 게임 입력으로 번역한 각색이다.
