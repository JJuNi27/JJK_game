# 후시구로 메구미 설정 카드 v1.0

> 상태: **사용자 1차 검토 완료**  
> 기준: 스쿠나에게 육체를 빼앗기기 전의 후시구로 메구미 본인  
> 범위: 원작 만화 + 공식 TV 애니메이션

## 1. 캐릭터 기준

- 이름: 후시구로 메구미
- 소속: 도쿄 도립 주술 고등전문학교
- 등급: 2급 주술사
- 생득술식: 십종영법술
- 스쿠나(메구미 몸)는 별도 캐릭터 슬롯으로 취급한다.

## 2. 핵심 설정

### [OFFICIAL_CONFIRMED] 십종영법술

- 그림자를 매개로 식신을 조복하고 소환한다.
- 그림자 안에 물건을 보관하거나 이동·기습에 활용할 수 있다.
- 조복하지 않은 식신을 일반 전투 기술처럼 자유롭게 사용하지 않는다.

### [OFFICIAL_CONFIRMED] 첫 구현 후보 식신

- 옥견 「혼」
- 누에
- 가마
- 만상
- 탈토

후순위:

- 대사: 작중 파괴 이후 일반 소환 대상에서 제외
- 불지정저: 누에와 가마를 조합한 확장술식
- 마허라: 조복하지 못한 식신이므로 일반 스킬이 아니라 위험한 최후 수단으로만 검토

### [OFFICIAL_CONFIRMED] 영역전개 — 감합암예정

- 십종영법술의 영역전개
- 메구미가 구현한 감합암예정은 미완성 영역
- 바닥과 공간을 유동적인 그림자로 채운다.
- 식신 다중 전개, 그림자 조작 확장, 메구미 분신 생성이 가능하다.
- 완전한 장벽과 필중 효과가 없으므로 완성형 영역과 동일하게 취급하지 않는다.
- 기존 실내 구조물을 이용해 영역을 강제로 가둘 수 있다.

## 3. 전투 능력 카드

### [OFFICIAL_CONFIRMED] 흑섬

- 메구미의 흑섬 성공 장면은 확인되지 않는다.
- 현재 프로젝트에서는 흑섬 사용 가능 캐릭터로 열지 않는다.

### [OFFICIAL_CONFIRMED] 반전술식

- 메구미가 자신을 회복하는 반전술식은 확인되지 않는다.
- 기본 회복 기술로 제공하지 않는다.

### [OFFICIAL_CONFIRMED] 대영역 기술

- 메구미 본인이 간이영역·미허갈롱·낙화의 정을 사용한 장면은 확인되지 않는다.
- 임의로 대영역 기술을 부여하지 않는다.

### [OFFICIAL_CONFIRMED] 영역 사용 후 제약

- 사용 후 생득술식 번아웃을 적용한다.
- 미완성 영역이고 부담이 크므로 높은 주력 소모와 짧은 유지 시간을 우선 검토한다.
- 정확한 수치는 `[GAME_ORIGINAL]` 밸런스 값으로 표시한다.

## 4. 사용자 확정 사항

| 항목 | 결정 |
|---|---|
| 캐릭터 버전 | 메구미 본인 |
| 첫 기본 식신 | 옥견 「혼」 |
| 전투 환경 조건 | 실내 또는 기존 구조물이 있을 때 감합암예정 사용 가능 |
| 연습장 환경 조건 | 환경 제한 없이 커맨드 연습 가능 |
| 마허라 | 후순위 최후 수단으로 포함 |
| 영역 음성 | 모든 캐릭터와 동일하게 `료이키 텐카이`까지만 |
| 영역명 음성 | 요구하지 않음 |
| 장인 방향 | Q 키 유지 + 마우스 그림자 궤적 입력 |

## 5. 구현 단계

### Phase M1 — 감합암예정 장인 연습

- 캐릭터 선택에서 메구미 해금
- 음성 `료이키 텐카이`
- Q 키와 마우스 드래그를 사용하는 그림자 궤적 커맨드
- 성공·실패 판정과 연습 통계
- 임시 감합암예정 화면

### Phase M2 — 기본 십종영법술

- 옥견 「혼」
- 누에
- 가마
- 탈토
- 만상
- 그림자 보관·이동의 단순화된 게임 버전

### Phase M3 — 영역 전투

- 그림자 바닥 이동
- 식신 다중 전개
- 메구미 분신
- 실내 구조물 조건
- 완전한 필중 효과 없음
- 영역 종료 후 번아웃

### Phase M4 — 위험 기술

- 마허라 조복 의식
- 사용자와 적 모두에게 위험한 중립 소환체
- 확정 승리 버튼으로 만들지 않음

## 6. 감합암예정 장인 커맨드 v0.1

```text
료이키 텐카이 또는 V
→ Q 키를 누르고 유지
→ 좌클릭을 누른 채 마우스를 아래로 충분히 드래그
→ 이어서 왼쪽 또는 오른쪽으로 그림자를 펼치듯 드래그
→ Q를 유지한 채 좌클릭 해제
→ 감합암예정 발동
```

초기 판정 후보:

```text
Q 입력 후 드래그 시작 제한: 0.80초
아래 방향 최소 이동: 130px
아래 방향 판정 시 허용되는 좌우 흔들림: 80px
수평 펼침 최소 이동: 180px
전체 궤적 제한시간: 1.80초
```

설계 이유:

- Q 키는 장인의 한쪽 손을 나타낸다.
- 마우스 드래그는 그림자를 바닥으로 내리고 정원처럼 펼치는 동작을 나타낸다.
- 스쿠나의 양 버튼 동시 입력과 다른 조작감을 준다.
- 타이밍보다 방향·거리·궤적 완성도를 중심으로 판정한다.
- 이 입력은 원작 손 모양을 그대로 재현한 것이 아니라 영역 특성을 게임 입력으로 번역한 `[GAME_ORIGINAL]` 각색이다.
