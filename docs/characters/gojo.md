# 고죠 사토루 설정 카드 v1.0

> 상태: **사용자 1차 검토 완료**  
> 기준: 성인 고죠 사토루  
> 범위: 원작 만화 + 공식 TV 애니메이션·극장판에서 확인되는 설정과 연출

## 1. 캐릭터 기준

- 이름: 고죠 사토루
- 소속: 도쿄 도립 주술 고등전문학교
- 기준 형태: 성인 고죠
- 변형 캐릭터 후보:
  - 고전 시절 고죠
  - 봉인 이전/이후 연출 차이
- 변형 캐릭터는 기본 고죠 MVP가 완성된 이후 별도 슬롯으로 검토한다.

## 2. 핵심 설정

### [OFFICIAL_CONFIRMED] 생득술식

- 무하한 주술
- 공간을 세밀하게 다루는 술식
- 육안과 함께 사용할 때 주력 소비와 술식 제어 효율이 극도로 높아진다.

### [OFFICIAL_CONFIRMED] 육안

- 고도의 주력 감지와 정밀 제어를 가능하게 하는 특수한 눈
- 무하한 주술과 별개의 생득술식으로 취급하지 않는다.
- 게임에서는 패시브 자원 효율·정밀 판정 보정 후보로 사용한다.

### [OFFICIAL_CONFIRMED] 주요 파생 기술

- 무한
  - 접근하는 대상의 속도를 무한히 감속시키는 자동 방어에 가까운 운용
  - 단순 HP 보호막으로 구현하지 않는다.
  - 영역의 필중, 술식 무효화·중화, 특수 주구 등 공식 예외를 나중에 별도 처리한다.
- 술식 순전 「창」
  - 공간 수렴과 강한 인력
- 술식 반전 「혁」
  - 반전술식을 결합한 강한 척력
- 허식 「자」
  - 창과 혁을 충돌시켜 만드는 고위력 직선·광역 공격
  - 절대적인 존재 삭제 기술로 단정하지 않는다.

### [OFFICIAL_CONFIRMED] 영역전개

- 명칭: 무량공처
- 대상에게 끝없는 정보가 유입되는 상태를 강제해 사고와 행동을 멈추게 한다.
- 고죠는 한 손 장인을 사용한다.
- 0.2초 무량공처는 고급 구현 단계로 분리한다.

### [OFFICIAL_CONFIRMED] 음성 규칙

- 공통 선언: `領域展開` / 료이키 텐카이
- 게임에서는 모든 영역전개 캐릭터가 공통 선언까지만 말한다.
- 어떤 영역이 발동하는지는 선택한 캐릭터와 장인 커맨드가 결정한다.
- 영역명까지 음성으로 추가 요구하지 않는다.

## 3. 전투 능력 카드

### [OFFICIAL_CONFIRMED] 흑섬

- 사용 가능
- 확정 버튼이 아니라 타격 순간의 정밀 타이밍 시스템으로 구현한다.

### [OFFICIAL_CONFIRMED] 반전술식

- 사용 가능
- 신체 회복
- 술식 반전을 통한 「혁」 운용
- 영역 사용 후 번아웃된 술식 부위를 손상시키고 반전술식으로 복구하는 위험한 강제 초기화 가능

### [OFFICIAL_CONFIRMED] 대영역 기술

- 간이영역
- 낙화의 정

### [OFFICIAL_CONFIRMED] 영역 사용 후 제약

- 영역 종료 후 생득술식 번아웃 발생
- 일정 시간 무하한 주술 계열 사용 제한
- 위험한 강제 초기화는 고죠·스쿠나의 고급 예외 시스템으로 분리
- 반복 사용 시 뇌 손상과 영역 사용 불가 위험을 구현 후보로 둔다.

## 4. 현재 무량공처 장인 커맨드

### [GAME_ORIGINAL] 마우스 한 손 번역

```text
료이키 텐카이 또는 V
→ 우클릭 유지
→ 제한 시간 안에 좌클릭 1회
→ 수렴 타이밍에 우클릭 해제
→ 무량공처 발동
```

입력 의미:

| 입력 | 게임 속 의미 |
|---|---|
| 음성 또는 V | 영역 구축 의사 선언 |
| 우클릭 유지 | 주력 집중과 한 손 장인 준비 |
| 좌클릭 | 검지·중지 결합 |
| 타이밍 대기 | 장인 안정화 |
| 우클릭 해제 | 영역 개방 |

현재 판정값:

```text
목표 해제 시점: 0.90초
허용 오차: ±0.22초
```

사용자 1차 테스트 결과:

```text
10회 중 8회 성공
평균 해제 오차 0.123초
```

현재 수치는 유지한다.
