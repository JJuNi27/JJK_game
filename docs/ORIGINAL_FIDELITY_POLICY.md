# 원작 재현 우선 전투 설계 정책

작성일: 2026-08-21

이 문서는 `주술사 되어보기`의 캐릭터/스킬 설계에서 밸런스와 원작 재현이 충돌할 때 무엇을 우선할지 기록한다.

## 핵심 결정

이 프로젝트는 격투게임이지만, 현재 단계에서는 경쟁게임식 캐릭터 밸런스를 최우선 목표로 삼지 않는다.

```text
1순위: 원작에서 그 캐릭터가 실제로 어떻게 싸우는가
2순위: 주술회전 팬텀 퍼레이드가 그 캐릭터를 게임으로 어떻게 설계했는가
3순위: 팬텀 퍼레이드의 턴제 설계를 실시간 3D 격투게임 규칙으로 어떻게 옮길 것인가
4순위: 실시간 전투에 필요한 GAME_ORIGINAL 보완
5순위: 경쟁 밸런스
```

고죠나 스쿠나가 원작에서 강하다는 이유로 핵심 능력을 약화하거나 삭제하지 않는다.

예:

- 현대 고죠의 무하한은 자동 방어라는 정체성을 유지한다.
- 일반 공격이 단순히 강하다는 이유만으로 무하한을 통과하지 않는다.
- 영역전연, 영역 필중, 술식 무효화처럼 원작상 이유가 있어야 우회한다.
- 스쿠나의 해/팔/푸가/복마어주자는 서로의 조건과 영역 상호작용을 가능한 한 유지한다.

## 소스 우선순위

### Tier 1 — 원작/공식 설정

- 만화 완결 범위 전체 사용 가능
- 단행본 부록
- 공식 팬북
- 공식 애니메이션/극장판/공식 사이트

캐릭터의 실제 능력, 발동 조건, 제한, 시기별 습득 상태를 결정하는 최우선 근거다.

후반부 설정도 사용할 수 있으므로 신주쿠 결전 고죠, 메구미 육체 스쿠나, 헤이안 진신, 세계참 등도 해당 시기 버전에서 구현 가능하다.

### Tier 2 — 주술회전 팬텀 퍼레이드

주팬퍼는 단순 번역/명칭 참고자료가 아니다.

원작 캐릭터를 실제 게임 캐릭터로 설계한 공식 라이선스 사례로 적극적으로 참고한다.

특히 다음을 모두 본다.

```text
- 스킬 슬롯 구성
- 기술 선택
- 패시브/오토 스킬
- 주력 최대치
- 시작 주력
- 주력 소비/회복
- 상태 변화
- 버프/디버프의 의미
- 타격 수
- 대상 수
- 기술 사용 순서와 선행 조건
- 영역 사용 전후 스킬 변화
- 반전술식/회복/저항 같은 자동 효과
- 카메라
- VFX
- SFX
- 보이스
- 캐릭터별 전투 정체성
```

핵심 원칙은 다음과 같다.

```text
팬텀 퍼레이드의 턴제 캐릭터 설계
        ↓
그 설계가 표현하려는 캐릭터 특성을 해석
        ↓
실시간 3D 아레나 격투 규칙으로 재설계
```

즉 숫자와 문장을 그대로 복사하는 것이 아니라 **턴제에서 표현된 의도와 캐릭터성**을 실시간 액션으로 옮긴다.

예:

```text
턴 시작 시 피해 20% 증가
→ 턴 개념이 없는 우리 게임에 그대로 넣지 않음
→ 캐릭터 설정상 지속 강화/조건부 강화에 의미가 있는지 먼저 판단

영역 사용 뒤 스킬 변화
→ 실시간에서도 영역 전후 상태 변화로 옮길 가치가 큼

해/팔을 사용한 뒤 푸가 사용 가능
→ 실시간 전투에서도 기술 준비 상태로 번역

큰 최대 주력 + 높은 기술 소비
→ 실시간에서도 대용량 주력형 캐릭터 정체성으로 번역
```

주팬퍼의 특정 유닛 밸런스 수치나 턴제 편의 때문에 생긴 효과가 원작과 충돌하면 원작을 우선한다.

반대로 원작에서 수치화되지 않은 부분은 주팬퍼의 구조를 적극적으로 설계 참고로 사용한다.

### Tier 3 — 글로벌 한국어 클라이언트/공식 표기

화면에 보이는 기술명과 캐릭터명은 글로벌 한국어 공식 표기를 우선한다.

사용자가 실제 글로벌 한국어 클라이언트에서 확인한 명칭은 `USER_VERIFIED_GLOBAL_KO`로 기록한다.

현재 확인 예:

```text
스쿠나 R 표시명: 푸가
내부 ID: Fuga
```

### Tier 4 — GAME_ORIGINAL

원작과 주팬퍼를 실시간 3D 액션으로 옮기는 과정에서 반드시 필요한 요소만 추가한다.

예:

- 쿨타임
- 카메라용 거리 제한
- HUD 표시
- 테스트 맵에 맞춘 영역 반경
- 임시 키 입력
- 실시간 타격 간격

이 값들은 원작/주팬퍼 규칙과 혼동하지 않도록 문서에 `GAME_ORIGINAL`로 표시한다.

## 턴제 → 격투게임 변환 원칙

주팬퍼 효과를 발견하면 바로 복사하지 말고 다음 순서로 해석한다.

```text
1. 이 효과가 턴제 시스템 때문에 존재하는가?
2. 아니면 캐릭터의 원작 특성을 표현하기 위해 존재하는가?
3. 실시간 전투에서 같은 역할을 하는 상태/입력/자원/패시브는 무엇인가?
4. 원작과 충돌하지 않는가?
5. 실제 플레이에서 캐릭터가 더 원작답게 느껴지는가?
```

가져오기 좋은 예:

- 특정 술식 사용 뒤 다른 기술 해금
- 영역 전개 후 술식 성질 변화
- 반전술식 회복
- 캐릭터 고유 저항
- 주력 총량/소비 성향
- 조건부 자동 패시브
- 기술별 대상 수/타격 성격

그대로 가져오지 않는 예:

- 턴 시작 시 N턴 동안 단순 피해 증가
- N턴 후 자동 해제처럼 턴 구조에만 의존하는 효과
- 가챠 유닛 밸런스를 위한 단순 계수 증가

단, 이런 효과도 캐릭터 설정을 표현하는 의미가 있다면 실시간 규칙으로 재해석할 수 있다.

## 같은 캐릭터의 시기별 버전

**분리한다.**

STORM/Sparking 계열처럼 같은 인물이어도 시기, 육체, 습득 기술, 전투 방식이 다르면 별도 플레이 버전으로 취급한다.

예:

```text
고죠 사토루
- 회옥·옥절 각성 전
- 회옥·옥절 각성 후
- 현대 교사
- 신주쿠 결전

료멘 스쿠나
- 이타도리 육체
- 메구미 육체
- 헤이안 진신/신주쿠 결전
```

버전별로 모델/복장만 다른 스킨으로 처리하지 않는다. 실제 기술·패시브·주력·영역 운용이 다르면 별도 전투 캐릭터다.

## 밸런스 정책

현재는 캐릭터 간 승률 50:50을 목표로 하지 않는다.

```text
하지 않을 것
- 강캐라는 이유만으로 원작 핵심 능력 제거
- 모든 캐릭터의 HP/주력/기술 위력을 억지로 동일화
- 같은 회피/방어 시스템을 모든 캐릭터에 강제
```

현재 목표는 **원작 구현과 캐릭터 체험**이다.

향후 실제 PvP 경쟁 모드가 필요할 경우 캐릭터 자체를 훼손하기보다 외부 규칙을 먼저 검토한다.

```text
- 팀 편성 규칙
- 캐릭터 편성 비용
- 매치별 사용 제한
- 별도 Ranked Ruleset
```

하지만 이것도 현재 개발 우선순위는 아니다.

## 캐릭터 설계 질문

새 캐릭터/새 버전을 구현할 때 먼저 묻는다.

```text
1. 이 시기의 캐릭터가 원작에서 실제로 사용할 수 있는 능력은 무엇인가?
2. 해당 기술의 발동 조건/제약/상호작용은 무엇인가?
3. 주팬퍼의 해당 캐릭터/버전들은 이를 어떤 스킬·패시브·주력 구조로 표현했는가?
4. 그 주팬퍼 설계 중 턴제 전용 요소와 캐릭터성 표현 요소는 각각 무엇인가?
5. 실시간 3D 격투게임에서는 어떤 상태·입력·자원·패시브로 번역하는 것이 가장 자연스러운가?
6. 반드시 필요한 GAME_ORIGINAL 요소만 무엇인가?
7. 구현 결과가 '정말 이 시기의 이 캐릭터처럼 느껴지는가?'
```

## 현재 적용

- 현대 고죠: 원작 무하한/육안/창/혁/자/무량공처 규칙 + 주팬퍼 고죠들의 주력 효율/스킬 구조 참고
- 시부야 스쿠나: 해/팔/푸가/복마어주자 원작 규칙 + 주팬퍼의 주력/타격 수/기술 준비/영역 상태 참고
- 스쿠나 R 표시명은 사용자 검수 글로벌 한국어 `푸가`

이 정책은 이후 메구미, 유타, 토우지, 마히토 등 모든 캐릭터 버전에 동일하게 적용한다.
