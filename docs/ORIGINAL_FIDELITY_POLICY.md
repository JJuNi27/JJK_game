# 원작 재현 우선 전투 설계 정책

작성일: 2026-08-21

이 문서는 `주술사 되어보기`의 캐릭터/스킬 설계에서 밸런스와 원작 재현이 충돌할 때 무엇을 우선할지 기록한다.

## 핵심 결정

이 프로젝트는 격투게임이지만, 현재 단계에서는 경쟁게임식 캐릭터 밸런스를 최우선 목표로 삼지 않는다.

```text
1순위: 원작에서 그 캐릭터가 실제로 어떻게 싸우는가
2순위: 주술회전 팬텀 퍼레이드가 이를 전투게임으로 어떻게 번역했는가
3순위: 실시간 3D 액션게임에서 필요한 조작성/가독성 보완
4순위: 경쟁 밸런스
```

고죠나 스쿠나가 원작에서 강하다는 이유로 핵심 능력을 약화하거나 삭제하지 않는다.

예:

- 현대 고죠의 무하한은 자동 방어라는 정체성을 유지한다.
- 일반 공격이 단순히 강하다는 이유만으로 무하한을 통과하지 않는다.
- 영역전연, 영역 필중, 술식 무효화처럼 원작상 이유가 있어야 우회한다.
- 스쿠나의 해/팔/푸가/복마어주자는 서로의 조건과 영역 상호작용을 가능한 한 유지한다.

## 소스 우선순위

### Tier 1 — 원작/공식 설정

- 만화
- 단행본 부록
- 공식 팬북
- 공식 애니메이션/극장판/공식 사이트

캐릭터의 실제 능력, 발동 조건, 제한, 시기별 습득 상태를 결정하는 최우선 근거다.

### Tier 2 — 주술회전 팬텀 퍼레이드

계속 적극적으로 참고한다.

특히 다음을 본다.

```text
- 스킬 구성
- 패시브/오토 스킬
- 주력 소비와 회복
- 상태 변화
- 타격 수
- 기술 사용 순서
- 영역 사용 전후 스킬 변화
- 카메라/VFX/SFX/보이스 연출
```

주팬퍼는 원작 능력을 게임 규칙으로 번역한 공식 라이선스 사례로 취급한다.

단, 주팬퍼의 특정 유닛 밸런스 수치나 편의적 각색이 원작과 충돌하면 원작을 우선한다.

### Tier 3 — GAME_ORIGINAL

원작과 주팬퍼만으로 실시간 3D 액션 조작이 성립하지 않을 때 최소한으로 추가한다.

예:

- 쿨타임
- 카메라용 거리 제한
- HUD 표시
- 테스트 맵에 맞춘 영역 반경
- 임시 키 입력

이 값들은 원작 조건과 혼동하지 않도록 문서에 `GAME_ORIGINAL`로 표시한다.

## 밸런스 정책

현재는 캐릭터 간 승률 50:50을 목표로 하지 않는다.

```text
하지 않을 것
- 강캐라는 이유만으로 원작 핵심 능력 제거
- 모든 캐릭터의 HP/주력/기술 위력을 억지로 동일화
- 같은 회피/방어 시스템을 모든 캐릭터에 강제
```

향후 실제 PvP 경쟁 모드가 필요할 경우 캐릭터 자체를 훼손하기보다 다음과 같은 외부 규칙을 먼저 검토한다.

```text
- 팀 편성 규칙
- 캐릭터 편성 비용
- 매치별 사용 제한
- 별도 Ranked Ruleset
```

하지만 이것도 현재 개발 우선순위는 아니다.

## 캐릭터 설계 질문

새 캐릭터를 구현할 때 먼저 묻는다.

```text
1. 이 시기의 캐릭터가 원작에서 실제로 사용할 수 있는 능력은 무엇인가?
2. 해당 기술의 발동 조건/제약/상호작용은 무엇인가?
3. 주팬퍼는 이를 어떤 스킬/패시브/자원 구조로 번역했는가?
4. 실시간 3D 전투로 옮길 때 반드시 필요한 GAME_ORIGINAL 요소만 무엇인가?
5. 구현 결과가 '정말 이 캐릭터처럼 느껴지는가?'
```

## 현재 적용

- 현대 고죠: 원작 무하한/육안/창/혁/자/무량공처 규칙 우선
- 시부야 스쿠나: 해/팔/푸가/복마어주자 원작 규칙 + 팬텀 퍼레이드 전투 번역 참고
- 스쿠나 R 표시명은 사용자가 글로벌 한국어 클라이언트 기준으로 검수한 `푸가` 사용

이 정책은 이후 메구미, 유타, 토우지, 마히토 등 모든 캐릭터 버전에 동일하게 적용한다.
