# 시부야 전투 PASS 2~2.3 — USER VERIFIED 체크포인트

승인일: 2026-10-18 (KST). 브랜치: `feat/shibuya-combat-mvp`.

사용자가 직접 Unity Play Mode에서 PASS 2.3까지 검수를 완료했고, 현재 체술 동작에 만족한다고 명시하여 PASS 2~2.3의 체크포인트 저장을 승인했다. 이 승인은 자동 테스트 결과에서 추론한 것이 아니다.

이 문서를 포함하는 커밋이 현재 체술의 **USER VERIFIED 기준**이다. 구현 시작 전 기준 HEAD는 `0f416389c602ed601aa6447238a520f007550ef0`이며, 이번 저장에는 이후 PASS 2~2.3 변경만 포함한다.

## 승인된 범위

- PASS 2: 입력 버퍼가 있는 기본 4타 콤보, 타격별 데이터/모션/피해/판정/경직/넉백, 한글 Inspector, 콤보 취소·초기화.
- PASS 2.1: W 없이 짧게 전진하며 이어지는 체술, 직전 적중 대상만 제한적으로 추적하는 준비 구간 보정, 4타 준비 동작 및 공격자·피격자만의 국소 히트스톱.
- PASS 2.2: 공격 방향 기준 넉백과 유효 적중 후의 제한된 측면 정렬, 공격 준비·활성 중 좌우/후방 미끄러짐 억제, 회복 중 일반 이동 복귀. 기존 PASS 2.1의 반대 입력에 의한 고유 전진 취소 정책은 이 단계에서 변경했다.
- PASS 2.3: 정면/좌우/후방 및 대각선 피격의 상체·머리·팔 반응, 일반/강타 차별화, 히트스톱과 동기화된 시각 모션 및 반복 피격/종료 초기화.

사용자 승인은 현재 블록 캐릭터 체술 동작에 한정된다. 전체 게임 완성, PvP 공정성 전체, 고급 캐릭터 애니메이션, 향후 PASS 기능까지 승인된 것으로 확대하지 않는다.

## 보존할 데이터와 구조

실제 설정의 소유자는 이 커밋의 [Shibuya Combat Profile](<../unity/Assets/Shibuya/Data/Shibuya Combat Profile.asset>)과 [Dummy Stats](<../unity/Assets/Shibuya/Data/Dummy Stats.asset>)이다. 이후 명시적 변경 요청이 없다면 승인된 기준으로 보존한다.

- 사용자 설정 더미 최대 체력: **1000**. 자동 승패 테스트의 80 HP는 런타임 현재 체력만 바꾸는 fixture이며 Asset을 80으로 되돌리지 않는다.
- 1~4타 피해: **20 / 20 / 20 / 25**. 넉백 속도: **6 / 4 / 4 / 11**. 경직: **0.25 / 0.25 / 0.25 / 0.45초**.
- 준비 시간: **0.10 / 0.09 / 0.10 / 0.18초**. 4타 힘 모으기 **0.10초**는 준비 시간에 포함되며 별도 지연이 아니다. 4타 국소 히트스톱 **0.065초**.
- 입력 버퍼 **0.16초**, 회복 완료 후 콤보 초기화 대기 **0.60초**. 클릭 유지로 자동 콤보하지 않는다.
- 타격 고유 전진 최대 거리: **0.70 / 0.55 / 0.55 / 0.55m**. 원본 W/S 입력은 보존하되 아직 업/다운 분기로 사용하지 않는다.
- 추적은 직전 적중 대상, 초기 준비 구간 및 거리/각도/회전/추가 전진 상한 안에서만 적용한다. 범위를 벗어난 대상이나 다른 적을 자동으로 재획득하지 않는다.
- 피격자 정렬: 허용 측면 오차 **0.65m**, 최대 **0.20m**, 속도 **2m/s**, 최대 **0.10초**. 기본 1~3타에만 적용. 시선 강제 회전/위치 스냅/벽 관통을 하지 않는다.
- 피격 모션: 기울기 **18도**, 비틀림 **20도**, 진입 **0.035초**, 회복 **0.18초**, 일반/강타 배율 **1 / 1.8**. 회복은 남은 경직 안으로 제한한다.
- 실제 이동은 `ShibuyaFighter`의 CharacterController 한 경로에서 처리한다. 시각적 피격 자세는 실제 이동·충돌체·시선과 분리한다. 전역 Time.timeScale은 바꾸지 않는다.
- 기존 Health / DamageContext를 재사용한다. CharacterStatsProfile의 공격·방어 배율은 현재 시부야 피해 계산에 적용하지 않는다.

## 자동 검증 — 사용자 승인과 별도 근거

마지막 코드 검증은 PASS 2.3 종료 시 실제 Unity Test Framework discovery/execution 및 XML로 확인한 단일 실행 **25 PASS / 0 FAIL / 0 SKIP**이다. 이번 체크포인트 저장 단계에서는 코드를 변경하거나 테스트를 다시 실행하지 않았다.

|---|---:|
| ShibuyaPass1Tests | 2 / 0 |
| ShibuyaPass2Tests | 5 / 0 |
| ShibuyaPass21Tests | 7 / 0 |
| ShibuyaPass22Tests | 7 / 0 |
| ShibuyaPass23Tests | 4 / 0 |

이동·점프·자유 카메라·피격·승패·재도전, 개별 타격 설정, 버퍼/초기화/취소, 다중 Collider 중복 피해, W 없는 정면/비스듬한 4타, W+연타, 이탈/무적/벽/다중 전투원, 피격 방향/보간/초기화 및 국소 히트스톱 회귀를 포함한다.

최종 측정은 일반 피격 약 **17.9도** / 4타 **32.4도**, 국소 정지 약 **65.8ms**였다. 최종 컴파일·Console 오류는 0이며 기존 `Deleting invalid font reference.` 경고 2개는 남아 있었다. 모든 경고가 해결됐다고 표현하지 않는다.

## 보호와 보류

기존 Gojo/VFX, 보호된 USER VERIFIED 문서/자산, 기존 Scene/Prefab, Packages/ProjectSettings는 이 체크포인트에서 변경하지 않는다. 다른 브랜치도 변경하지 않는다.

4타 음향·VFX의 고급화는 후속 검토 대상이다. 캐릭터별 전용 애니메이션, 순간이동/위치 교환, 업/다운 콤보·공중 추격, 대시·가드·패링·잡기, 주력/술식 및 멀티플레이는 이번 승인에 포함하지 않으며 PASS 3는 아직 시작하지 않았다.
