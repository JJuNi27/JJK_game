> 상태: **기획 v1.1 / 신규 MVP 구현 전 / 새 브랜치 문서 반영 전**  
> 작성: 2026-10-17  
> 권장 저장 경로: `docs/design/SHIBUYA_COMBAT_REBOOT.md` (`feat/shibuya-combat-mvp` 브랜치 전용)  
> 최우선 목표: **고급 모델링·VFX보다 실제로 재미있게 싸우는 게임을 먼저 만든다.**

## 0. 새로운 프로젝트 방향 / 기존 작업 보호

- Unity 6 URP 기존 `JJK_game` 프로젝트를 **폐기하지 않는다**.
- 이전 방향(고죠 1인 모델링·Purple/VFX 폴리시 중심)에서 **블록형 캐릭터 기반의 플레이 가능한 자유 난전 격투** 중심으로 전환한다.
- 기존 Gojo 모델·애니메이션·Blue/Red/Purple·Unlimited Void·VFXLab·검증 기준값은 모두 보존하고 신규 구현에서는 기본적으로 사용/수정하지 않는다.
- 새 작업은 **독립적인 전투·시부야 프로토타입 씬/프리팹/데이터**로 시작한다. 기존 자원은 안전하게 재사용 가능 여부만 먼저 조사한다.
- 장기적으로 실제 캐릭터 모델과 고품질 스킬 VFX를 새 전투 구조에 다시 통합한다.
- 작업 원칙: Data-driven (`HOW = 코드 / WHAT = Data Asset`), 사용자-facing Inspector/설정 한국어, USER VERIFIED 잠금 보호.

## 1. 장르 / 플레이 루프

- 장르: Roblox 배틀그라운드 게임 계열의 **자유 시점·자유 이동 3D 주술회전 격투**. 나루티밋 스톰식 1:1 카메라 고정이 아님.
- 장기적으로 여러 명이 자유롭게 싸우는 난전, 동시 3자 영역전개 및 다른 영역 안에서의 대응 전개를 모두 목표로 한다.
- 개발 순서: **싱글플레이 대전부터**, 멀티플레이는 이후 확장.
- 전투 시작 후 **캐릭터 변경 불가**.
- **리스폰 없음**: 사망하면 그 전투가 종료된다. 재도전은 새로운 전투 시작에 해당한다.
- MVP에선 블록형 플레이어 + 더미/간단한 적 AI를 먼저 둔다. 승리·패배 시 결과 표시 후 재도전/메뉴 복귀.
- 수치 밸런스, 판정 시간, 쿨타임은 초기 임시값으로 구현한 뒤 플레이 테스트로 조정한다.

## 2. 시작 화면 / 캐릭터 선택 / 옵션

```text
시작 화면
  → 메인 메뉴 [게임 시작 / 캐릭터 / 옵션]
       ├ 캐릭터: 도감/정보 화면 (능력치, 술식, 고유 패시브 설명)
       ├ 옵션: BGM/SFX/음성 음량, 키 설정, HUD 크기 등
       └ 게임 시작: 시부야 게임 화면 진입 → 실제 플레이 캐릭터 선택 → 전투 시작
                                                  → 승패 결과 → 재도전/메뉴
```

- **메인 메뉴 캐릭터 화면**과 **시부야 입장 후 플레이 캐릭터 선택 화면**은 역할이 다르다.
- 전투 중에는 캐릭터 선택 화면을 열어 바꾸는 동작을 허용하지 않는다.
- 설정 메뉴는 전투 중에도 일시정지/ESC 등으로 접근하도록 설계하는 안을 검토한다 (정확한 메뉴 동작 미확정).

## 3. 캐릭터 / 데이터 구조

- 당장은 **로블록스 같은 네모난 블록형 캐릭터**로 체술·피격·공중 콤보를 빠르게 테스트한다. 손가락/표정/고급 리깅에 시간을 쓰지 않는다.
- 플레이어와 적이 공통 전투 인터페이스/상태를 사용하여 향후 NPC·다수 플레이어·멀티플레이를 확장할 수 있게 한다.
- 캐릭터별 데이터 항목(개별 튜닝 가능): 체력/가드 체력/최대 주력/기본 이동/공격·술식/패링·흑섬·반전술식 가능 여부/각성 지속·잠금 규칙/피격 성격 등.
- 기존 특정 고죠 모델이나 이름 문자열에 전투 규칙을 하드코딩하지 않는다.

## 4. 기본 조작 및 체술

| 입력 | 기능 | 조건 / 의도 |
| --- | --- | --- |
| WASD | 이동 | 자유 시점 이동 |
| Shift | 달리기 | 기존 입력 유지 |
| Space | 점프 | 기본 점프 |
| 좌클릭 4타 | 기본 콤보 | 4타 마무리 넉백 → 거리·주력 충전 시간 확보 |
| 평타 3타 → W + 좌클릭 | 업 콤보 | 4타째 적 공중 띄우기 |
| 평타 3타 → S + 좌클릭 | 지상 다운 콤보 | 적을 넘어뜨려 경직/기술 시전 기회 확보 |
| 업 콤보 적중 후 Space | **선택적** 공중 추격 | 누르지 않으면 상대만 공중에 남음 |
| 공중 좌클릭 연계 | 공중 체술 | 후속 연타 / 공중 내려찍기 (다운 가능) |
| 우클릭 유지 | 가드 | 별도 가드 체력 사용, 주력 소모 없음 |
| 공격이 닿기 직전 우클릭 시작 | 패링 | 체술 밀치기 연출 + 상대 짧은 경직, 이후 후속 행동 플레이어 선택 |
| 우클릭 유지 + 좌클릭 | 잡기 | 가드 무시, 짧은 사거리/실패 빈틈 제안 |
| 빠른 우클릭 2회 | 반전술식 | 사용 가능한 캐릭터만, 큰 주력 소모, Q/E/R 슬롯 사용하지 않는 별도 능력 |
| F 유지 | 주력 집중 충전 | 유지하는 동안 회복 가속, 놓으면 중단 |
| Q / E / R | 일반 술식 3종 | 각성하면 대응 각성 술식으로 전환 |
| Z | 각성 | 게이지 100%일 때 수동 발동 |
| 방향키 + C | 지상 방향 대시 | 전방 접근 / 측면·후방 회피 |
| 다운 후 대기시간 경과 + WASD + Space | 긴급 탈출 | 즉시 사용 불가, 다운에서 방향 기상·회피 |

**조작 충돌 미해결, 구현 시 반드시 플레이 테스트:**

- W/S는 이동 키이므로 4타 분기에서 `키를 계속 누르고 있는 경우`와 `3타 이후 새로 누른 경우`를 구별할지 프로토타입으로 결정한다. **아직 확정 아님.**
- 우클릭 입력은 패링/가드/더블클릭 반전술식/우클릭+좌클릭 잡기가 겹친다. 입력 우선순위와 버퍼 규칙을 구현 전 정의·테스트한다.
- 점프 / 업 콤보 추격 / 다운 탈출 Space는 상태에 따라 분리해 판정한다.

## 5. 이동·회피·기동

- 지상 `W+C` 전방 대시: 접근/추격, **무적 없음**.
- 지상 `A+C` / `D+C` 측면, `S+C` 후방 대시: **짧은 회피 무적**.
- 피격 경직 중 일반 C 대시 불가, 다운 탈출은 별도.
- 대시 연속 남용 방지를 위한 쿨타임(초기 임시값).
- **공중 대시 없음**. 공중 기동은 점프/선택적 공중 추격 중심.
- 벽 박차기/벽 점프는 **후속 고도화 후보**. 벽 달리기·벽 타기는 초기 범위에서 제외.

## 6. 가드·패링·잡기·피격·탈출

### 6.1 가드 체력

- 캐릭터마다 **가드 체력**이 별도로 존재한다. 주력과는 별도 자원.
- 일반 가드 성공 시 기본적으로 HP를 보호하고 가드 체력을 줄인다.
- **가드 파괴형 공격**이 남은 가드 체력을 무너뜨리면, 그 공격의 **원래 HP 데미지를 전부 적용**하고 가드 브레이크·경직 발생 (피해 감면 없음).
- **방어 불가형 공격**은 가드 체력과 무관하게 가드를 무시. 기술별 `방어 가능/패링 가능`은 독립 설정.
- 공격별 `실제 체력 데미지`와 `가드 데미지`는 별도 데이터로 관리.
- **가드 체력은 HUD 바에 표시하지 않는다.** 방어 시의 주력 이펙트 색/상태로 위험을 알린다. 구체 색상·회복 규칙은 추후 조정.

### 6.2 패링

- 우클릭을 **공격 적중 타이밍에 새로 눌렀을 때만** 짧은 패링 윈도가 열린다.
- 패링 실패 후 우클릭 유지 시 일반 가드로 전환. 유지·연타만으로 자동 반복 패링되지 않게 한다.
- 연출: 좀보이드 밀치기처럼 체술로 쳐내고 밀어 상대에게 짧은 경직을 준다.
- 패링 이후 자동 반격은 없고 플레이어가 콤보/술식/대시 등을 직접 선택한다.
- 패링 성공 시 일정 시간 **자연 주력 회복 속도와 F 충전 속도 증가**.

### 6.3 긴급 탈출

- **다운 상태**에서만 허용(일반 연타 피격/공중 피격 도중에는 불가).
- 다운 직후 곧바로는 사용 불가. **일정한 대기 텀 이후** `WASD + Space`로 방향 회피·기상.
- 시간·횟수·쿨타임은 실기 테스트로 결정.

## 7. 주력 / 흑섬 / 반전술식 / 각성

### 7.1 주력

- 자연 회복 + `F` 홀드 주력 집중 충전. **체술 적중에 의한 즉시 주력 회복 없음**.
- 패링 성공: 일정 시간 자연 회복 및 F 충전 효율 증가.
- 주력 최대치: 캐릭터별 다름.
- 주력 소모: 술식 및 반전술식 사용. 일반 가드에는 소모 없음.
- 주력이 0에 도달하면 **1회 탈진/짧은 경직**. 주력이 0인 매 프레임 반복 경직되는 문제 금지.
- F 중 이동/공격 제한 방식과 주력 자연 회복 상세값은 임시 구현 후 체감 조정.

### 7.2 흑섬과 존(Zone)

- 흑섬 가능 캐릭터만 사용 가능.
- 흑섬 성공 시 별도 **Zone** 상태 진입.
- Zone 중 흑섬 발생 확률 증가 / 주력 회복 강화 / 주력 효율(소모 감소) 증가.
- 흑섬 발동 조건·확률·Zone 유지 시간은 추후 검증. **각성(Z)과는 별도 상태**.

### 7.3 반전술식

- 원작 설정상 사용 가능한 캐릭터만 사용.
- 우클릭 빠른 두 번 클릭으로 발동, 매우 큰 주력 소비.
- Q/E/R 슬롯에 묶이지 않는 캐릭터 고유 회복 능력. 자동 상시 회복과 혼동하지 않는다.
- 우클릭 패링/가드/잡기와의 충돌 해결 필요.

### 7.4 각성

- 각성 게이지는 주력과 별도.
- 공격 **적중** 및 **피격**으로 증가. 같은 타격에서는 **피격자가 공격자보다 조금 더** 획득.
- 게이지 100%가 되면 `Z`로 **수동 각성**. 캐릭터별 고유 연출과 Q/E/R 각성 기술 사용.
- 기본은 **시간제 각성**. 지속 시간/특수 종료 조건에 캐릭터별 예외 허용.
- 각성 중에는 다시 게이지 충전 불가.
- 각성 종료 직후 **재충전 잠금 기간**이 있고, 시간이 지난 뒤 적중·피격을 통한 충전 재개 (롤 나르 분노 재충전 제한에서 아이디어).
- 각성 발동 시 게이지 소모/초기화. 정확한 지속 시간·잠금 시간은 임시값으로 시작.

## 8. 피격 성격 및 전투 타격감

- **동일 공격의 게임플레이 피해/경직 판정**과 **캐릭터별 시각 피격 연출**을 분리한다.
- 예: 유지처럼 아파하며 휘청이는 캐릭터 vs 스쿠나·켄자쿠처럼 한 손으로 받아내거나 여유 있는 자세를 보여주는 캐릭터.
- 스쿠나는 강타에 날아가더라도 공중제비·자세 제어로 여유 있게 표현 가능. 그러나 압도적 공격에는 실제로 크게 반응한다.
- 일반 체술 1~3타: **빠르고 경쾌하게**.
- 4타/업/다운/흑섬: 점점 묵직한 충돌, 히트스톱·사운드·피격 반응·국소 카메라 충격.
- 공통 타격 표현: 공격 예고 → 실제 적중 → 짧은 Hitstop → 피격/넉백 → 타격음/주력 섬광 → 환경 반응.
- 초기에는 간단한 히트 파티클/타격음 재사용. 고급 영웅 기술 VFX 폴리시 재개하지 않는다.
- 다인전을 고려해 `Time.timeScale` 전체 정지 같은 전역 히트스톱 방식은 기본 해법으로 쓰지 않는다.

## 9. 시부야 맵 / 환경 파괴

### 9.1 지도 범위

- 1차: **시부야 사변 분위기의 교차로 + 도로 + 건물 외관**. 싸울 수 있는 공간 확보 우선.
- 건물 내부·옥상·지하철역·복잡한 벽 박차기는 **고도화 단계**.
- 맵은 분할/모듈화하여 후속 확장을 고려하되, 첫 버전에서 모두 구현하지 않는다.

### 9.2 파괴

- **벽 바운스는 없음.** 강한 충돌에서 벽이 저항하거나 부서지는 방향.
- 체술도 공격 강도/넉백/파괴 속성에 따라 유리·얇은 벽·일부 콘크리트를 손상·관통할 수 있다.
- 술식의 직접적인 지형 파괴와 적 넉백에 따른 벽 충돌 파괴는 구분한다.
- 기본 초안: 약한 충돌=먼지/균열, 강한 충돌=일부 벽 파괴/관통, 초강력 술식=특수 파괴.
- 파괴가 발생하면 **그 전투가 끝나거나 맵이 초기화될 때까지 폐허 상태가 유지**된다. 자동 복구 없음.
- 초기엔 미리 지정한 파괴 가능 부분만 구현; 도시 전체 실시간 물리 파괴 금지.

## 10. 전투 HUD

하단 중앙에 정보를 모은 **롤식 배치 + 캐릭터 얼굴 + 우측 세로 각성 게이지**.

```text
                  [버프/디버프 아이콘 + 지속시간]
[캐릭터 얼굴]  [ Q ] [ E ] [ R ]   [각성 Z : 아래→위 충전]
              [      HP : 초록색      ]
              [      주력 : 파란색     ]
```

- **가드 체력바 없음**. 방어 이펙트의 색·균열·강도 등으로 피드백.
- 버프/디버프는 남은 지속시간을 표시.
- 각성 게이지는 디아블로 구슬처럼 **아래에서 위로 차는 세로형**. 각성 시 스킬 슬롯 전환·남은 시간 안내.
- HUD 크기 조절 가능한 옵션 제공.
- 자유 난전이므로 나루티밋/스파킹처럼 두 플레이어의 HP를 화면 상단에 영구 고정하지 않음. 적 HP를 월드 공간/타겟 순간에만 보여줄지 여부는 미확정.

## 11. MVP 개발 우선순위와 완료 기준

### 구현 순서(추천)

1. **안전 감사**: 로컬 Git 상태, 원격 대비 미커밋/미푸시 변경, 기존 Scene/Data와 신규 시스템 간 충돌 조사. 삭제·리셋·대량 변환 없음.
2. **독립 전투 씬**: 교차로 형태의 플레이 가능한 임시 시부야 블록아웃 + 블록 캐릭터 + 더미.
3. **기본 손맛**: 이동·지상 C 대시·기본 4타/업/다운 분기·공중 추격·피격·넉백·다운.
4. **대응 수단**: 가드·패링·잡기·가드 파괴·긴급 기상(임시 튜닝 값).
5. **가시적인 전투 완결성**: 초록 HP/파란 주력/필요 최소 HUD, 타격음/작은 충돌 이펙트, HP 0 패배·승리·재도전.
6. **추가 전투 깊이**: F 충전, Q/E/R 임시 기술, Zone·각성·캐릭터별 예외.
7. **후속 고도화**: 시부야 디테일·지형 파괴·고급 VFX/모델·다인 영역전개·멀티플레이.

### 첫 플레이 가능 버전의 성공 조건

- 플레이어가 시부야 도로에서 자유 이동하고 더미/적을 때릴 수 있다.
- 기본/업/다운 3분기 중 최소 핵심 콤보가 동작하며, 공중 추격은 **Space 입력을 선택했을 때만** 발동한다.
- 피격 반응·데미지·다운이 보이고, 타격음/간단한 효과로 손맛을 확인할 수 있다.
- 맞는 쪽이 적절히 행동 제한을 받고, HP가 0이 되면 전투가 끝나며 리스폰하지 않는다.
- 기존 고죠/VFX USER VERIFIED 자산은 보존된다.
- 이 단계의 성공을 **게임 완성**이나 **고급 VFX 품질 승인**으로 표현하지 않는다.
