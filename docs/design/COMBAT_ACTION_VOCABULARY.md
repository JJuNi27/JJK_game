# 시부야 공통 전투 행동 표준 명칭

2026-10-31 / PASS 4G.0. 행동명은 공통 계약이며 캐릭터별 실제 스킬에는 고유 이름을 표시한다.

| 구분 | 표준 명칭·입력 | 상태 |
|---|---|---|
| 캐릭터 고유 | 패시브 | 캐릭터별 후속 구현 |
| 지상 평타 | 기본 콤보 / 업 콤보(W 마무리) / 다운 콤보(S 마무리) | 기존 엔진 |
| 자원 | 주력 회복(F 충전) | 기존 자원·아우라 경로 |
| 방어 | 가드 / 가드브레이크 / 패링 / 반격 / 잡기 | 반격은 PASS 4G.2 범위 |
| 기동 | 대쉬(C) / 주력 대쉬 | C 구현, 주력 대쉬 미구현 |
| 지상 기술 | 스킬 1(Q), 스킬 2(E), 스킬 3(키 미정) | 캐릭터별 후속 작업 |
| 상위 기술 | 궁극기/각성(R) | 즉시 궁극기·각성·각성 후 궁극기 모두 향후 설계, 이번 구현 아님 |
| 공중 | 공중 콤보 / 공중 스킬 | 공중 콤보 기존 구현, 공중 스킬 후속 |

공격 분류(근접/원거리/특수, 체술/술식/복합, 평타/스킬/반격/궁극기/기타)는 서로 독립적이다. 실제 거리로 분류를 바꾸지 않는다. Core의 PhysicalStrike/CursedTechnique/DomainSureHit 및 DamageTraits는 기존 방어 판정 계약이며 이 메타데이터와 혼합하지 않는다.
